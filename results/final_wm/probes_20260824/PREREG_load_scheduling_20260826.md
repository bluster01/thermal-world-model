## 2. 逐项预注册

### A1 — UA ∝ ṁ^0.8（零自由参数）

- **假设**：负荷相关的慢动态来自金属热惯性 Cm/UA，而非蒸汽输运延迟。
- **三方证据**（事前已具备）：实测 Q1/Q5 峰值滞后比 **2.33**；Dittus-Boelter 零参数预测
  (492/177)^0.8 = **2.26**；文献经典 600 MW SST 模型 50%/100% 时间常数比 **2.2**。
  密度反证：ρ 随负荷 32.3→74.4 kg/m³，ρ/ṁ 只预测 **1.21**（误差 48%）→ 输运不是主导。
- **实现**：`FlowScheduledTransition` 中 α_τ 冻结为 0、α_UA 冻结为 0.8（已验证：τ 因子恒
  1.000，Cm/UA 比 2.26）。
- **预期**：若 PROMOTE，则"自由 τ 调度学到的 α_τ=1.35 是金属热惯性的代理"成立；
  若与自由 τ 臂打平，说明两条路径**冗余**，应选零参数版（可辨识性更优）。
- **反证条件**：若显著差于自由 τ 臂（≥+5%），则传热代理假说不成立，需回到输运侧另找解释。

### A2 — 纯物理初值消融（量化"神经网络买到多少"）

- **假设**：观测器的学习式初值修正对 H18 有实质贡献。
- **反向证据（事前）**：自家 O1 判决为 **learned MIXED / hybrid REJECTED**（hybrid 3/3 CI 过零），
  但那是 **v0.2 老预算 + 旧错侧记录**下的结论，需在 120/20 + v2.1 记录下复测。
- **实现**：`initial_state_mode='steady'`（纯 `initial_steady_state()` 物理解），其余不变。
- **预期方向**：**不预设**。若 steady 与 hybrid 打平 → 论文必须如实写"NN 状态修正无精度增益"，
  神经网络的价值只保留在闭包（+6%）、联合辨识（J1 +13-33%）、概率化输出三项上。
- **这条是诚实性检查，不是找增益**：结果为负也必须写入论文。

### A3 — 多项式调度 vs 幂律调度

- **假设**：调度的**函数形式**不是关键，可辨识性才是关键。
- **实现**：把 τ/UA 的调度从 θ·s^(±α)（2 参数、指数有界、符号钉死）换成
  θ·(c₀+c₁L+c₂L²+c₃L³)（Fan2021 形式，4 参数/被调参数，正性用 softplus 保护）。
- **预期**：打平（INCONCLUSIVE）。**这正是我们想要的结果**——它支撑"灰盒价值在结构约束
  下的可辨识性，不在拟合能力"，与 Fan2021 四次发散互为佐证。
- **若多项式显著更好**：说明幂律形式过于受限，需重新设计调度族（并在论文中如实说明）。
- **若多项式发散/显著更差**：复现 Fan2021 的四次发散现象，作为"表达能力有害"的直接证据。

### A4 — k 按负荷调度（Fan2021 Eq.24 的 k₁ 类比）

- **假设**：燃料→金属吸热增益 k 随负荷变化（低负荷燃烧恶化、炉温下降、效率下降）。
- **文献**：Fan2021 明确用负荷三次多项式调度 k₁；物理理由见其"nonlinearity"段。
- **实现**：子类覆写 `k_of(pm)`，改为 `k_of(pm, L)`，在现有压力干湿混合之上乘一个
  有界负荷因子 `exp(tanh(w·(L−1))·ln k_max)`，k_max=1.5（±50% 带内，不越物理规则）。
  当前 `k_of` 已是 (B,3) 输出，接口天然兼容。
- **事前定量支撑**：用单一常数水煤比 a=4.485 时，能量失配分箱均值从 **−43.1（Q1）到
  +107.2（Q5）t/h** 单调摆动 → 存在系统性的负荷相关热输入偏置。
- **冗余警告**：A4 与 A5 **经实测判定为不冗余**（水煤比仅 52.5% 方差由负荷解释），
  两臂独立评估；若均 PROMOTE 再跑联合臂验证是否叠加。

### A5 — 水煤比 / 能量失配修正（**独立臂，非条件化**）

> **2026-08-26 偏离登记**：本条原写为"条件化于 A4、预期 INCONCLUSIVE"，依据是我用
> `主蒸汽流量/未校正总煤量` 拼的代理（a=4.485）。改用 **DCS 真实水煤比测点**（全量
> 381 列第 371 列）后该判断不成立，故升级为独立臂。原代理值 4.485 亦为错值。

- **文献**：Fan2020 把吸热修正因子建在 uB/Dfw 上；Fan2021 用
  `Q₁ = k₁·rB + [m/(Ne+g)]·(Dfw − a·rB)`，失配影响在高负荷减弱。
- **DCS 真实测点**（`~/Desktop/AI/时序预测/AA数据中心/伊敏12.10/cleaned_data/all_merged_10s.csv`）：
  - 371 列 `水煤比`（tag 均值 **3.662**；用 247 列给水 / 373 列校正后总燃料量 重算 3.524）
  - 247 列 `选择后的主给水流量`、373 列 `校正后总燃料量`、248 列 `未校正总煤量`
  - 筛选运行工况（MW>160、1<水煤比<8、燃料>50）后 n=1,132,608（95.0%）
- **事前实测（三条，均与文献或我早前推断相左）**：
  1. **方向相反**：`corr(负荷, 水煤比) = +0.722`，我们机组水煤比随负荷**升高**
     （Q1 3.563 → Q2 3.472 → Q5 3.912），Fan 2021 是随负荷**下降**而升高
     → 机制成立但**系数与单调性不可移植**；
  2. **非单调**：Q2 (211-264 MW) 是最低点，Q1 回升 → 与 Fan 所述"低负荷需多给水保护
     管壁"机制**部分吻合**，两种机制（高负荷效率 vs 低负荷保护）在 Q2 附近交界；
  3. **水煤比不是负荷的函数**：负荷二次拟合仅解释 **R²=0.525**，残差 std=0.151
     （占均值 **4.13%**），箱内散布 2.83-4.84%
     → **将近一半方差独立于负荷**，是独立调度变量而非负荷的重复表达。
- **由此推出**：A4（负荷调度 k）与 A5 **不冗余**，须各自独立评估；若两臂都 PROMOTE，
  再跑联合臂检验是否叠加。
- **实现**：`_substep` 的 `metal_power` 通道注入 `w·(wc − wc_ref(L))`，其中 wc 取真实
  测点、wc_ref(L) 为负荷二次基线；权重 w 有界、符号由数据学（**不预设**）。
- **数据前置**：canonical v2.1 边界不含水煤比，需先把 371 列并入记录（对齐口径同
  `build_canonical_v2`），此为 A5 的**前置数据工作**，成本计入。

### A6 — 压力作第二调度变量

- **假设**：纯流量调度在压力与流量解耦的工况下误配。
- **事前证据**：控制流量后，压力对停留时间代理的**偏相关 +0.954/+0.956**；
  固定负荷下压力仍跨 14.0-19.5 MPa（Q3 箱内 12.9-22.5 MPa，散布 10.9%）；
  **LPV 自由 τ 臂唯一恶化的箱正是 Q3（0.503→0.568）**，与预测位置吻合。
- **实现**：调度因子扩为 `s_ṁ^(−α_τ) · (p/p_ref)^(−β_τ)`，β 同样 sigmoid 有界、符号钉死。
- **判定补充**：本臂**额外要求 Q3 分箱不恶化**（这是它的靶点），否则即使总体 −5% 也记为
  INCONCLUSIVE。

### A7 — 压降二次多项式

- **文献**：Fan2020 `g₁ = 0.01784pm² − …`、`g₂ = 0.04112pm² + 1.867pm + 10.0919`。
- **现状**：我们用 `p₀ = pm + (p_out−pm)/3`、`p₁ = pm + 2(p_out−pm)/3` 线性插值。
- **风险**：p₀/p₁ 进入 Tsat 与温度反算，改动会影响所有观测通道，**不是局部改动**。
- **优先级低的理由**：未有本项目实测支撑（不像 A1/A6 有数字），且 Fan 的系数不可移植。

### A8 — 阶次自适应

- Cui2022 指出低负荷惰性段**阶次上升**（不只是参数变）。我们固定 3 段。
- 结构性改动，成本高、与 v0.6 其他工作冲突，**排最后**。

**结论（写入 §5 偏离/发现记录）**：
1. **"双重补偿"假设被否决**。钉死 τ=80s 后 α_τ **饱和到 2.418（cap 2.5）** 仍只能把

2. **三个慢参数在共同代偿同一个缺失动态**：τ_mix 700s（先验 80，×8.8）、

   这是弱可辨识的物理根源，也支持"τ_mix 实际承担金属热惯性通道"的解释。
3. **α_UA 第四次不被采纳**（0.016 / 0.046 / 0.046 / 0.050，四次独立训练一致），

4. **Q3 恶化复现**（0.503→0.568，自由臂），与压力-流量解耦分析预测的位置一致，
