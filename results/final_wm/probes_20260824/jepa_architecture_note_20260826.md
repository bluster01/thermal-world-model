# JEPA（LeCun 世界模型架构）对本项目的启发与边界

> execution-side 设计备忘，2026-08-26。用户问：参考 JEPA 的"预测 latent"思想，对我们的
> 架构有什么启发；最终目标是实现世界模型的 **state** 与 **prediction** 两部分。
> 本文件只做架构分析与可预注册提案，不改代码、不写 verdict。

---

## 0. 两套架构的结构对照

| 组件 | JEPA（LeCun） | 本项目 final_wm |
|---|---|---|
| 编码器 | Enc_x(过去) → s_x；**Enc_y(未来) → s_y（target encoder，EMA/stop-grad）** | `ProbabilisticObserver`（GRU，96 步）→ 初始状态后验 μ/σ |
| 状态 | 学习式 embedding，**不可解释** | **11 维物理态**（3 焓 + 3 金属温 + 燃料滞后 + 2 液滴质量 + 2 输运滞后）+ 可选潜态块 |
| 预测器 | P(s_x, z) → ŝ_y，学习式 | **物理 ODE（UDE）**，34 个有物理量纲的参数 |
| 潜变量 | **z 吸收不可预测信息** | 无显式 z；`latent_dim` 块曾试过 |
| 解码器 | **无**（非生成式） | `output_temperatures`：g(x,b)，**纯物理、无可学习头** |
| 损失位置 | **embedding 空间**（能量/回归 + 防塌缩正则） | **观测空间**（5 点温度的 NLL） |
| 塌缩风险 | 中心问题（需 stop-grad / EMA / VICReg） | **结构性免疫**（见 §2.1） |

## 1. JEPA 的核心动机在本问题上不成立（先说不适用的部分）

JEPA 的立论是：像素空间含大量**不可预测且无价值**的细节（纹理、树叶位置），生成式
重建会把容量浪费在这些细节上，所以应当在 embedding 空间预测、并让 z 吸收不可预测部分。

本项目的观测空间是 **5 个温度测点**：
- 维度极低（5 vs 10⁵-10⁶ 像素）；
- **它们本身就是目标量**（主汽温是被控量，不是达成目标的中间表示）；
- 不存在"无价值的高熵细节"——温度的每一度都有工程意义。

**结论**：JEPA"避免浪费容量在不可预测细节"的核心论证在这里几乎没有增益空间。
把预测目标搬到 latent 空间**不会**带来 JEPA 在视觉任务上的那类收益。

## 2. 反过来，我们的架构在两个 JEPA 难题上天然占优（应当写进论文）

### 2.1 表示塌缩免疫

JEPA 最大的工程难题是防塌缩（若 Enc 输出常量，embedding 空间的预测损失可为零）。
我们的解码器 `g(x,b)` 是**固定的物理映射**，损失定义在实际温度上：状态塌缩会直接
导致温度预测错误，**没有平凡解**。这意味着我们不需要 stop-grad、EMA target、
VICReg 这一整套机制。

### 2.2 状态可解释性 = 今天所有发现的来源

今天的整条发现链——τ 先验 80 s 学到 365-757 s、Cm 漂 2-5 倍 → 指向延迟失配 →
UA ∝ ṁ^0.8 → 接线缺陷 33%——**全部来自"读学到的物理参数"**。JEPA 的 latent 明确
放弃可解释性；若把状态改成 embedding，这条诊断通路会**整体消失**。

**故基本立场**：**不把预测目标搬进 latent 空间**。JEPA 应作为**状态估计器的辅助
塑形机制**引入，而非替换物理预测器。

---

## 3. JEPA 的三个机制正好对着我们的真实痛点（应当借鉴的部分）

### 3.1 潜变量 z ↔ 未观测热输入（我们试过弱版本并失败了）

我们的未观测驱动：炉膛辐射分布、烟气侧温度分布、氧量、吹灰、结渣、磨组合、煤质。
这些正是 JEPA 中 z 要吸收的"预测未来所必需但输入中不存在的信息"。

**我们已有的失败证据**：T1 判决 `latent4` **REJECTED**（best_val 1.345/1.412/1.412，
CI 全过零；对照 closure_cons 1.369/1.324/1.345）。

**JEPA 视角下的失败诊断**（可检验的解释，非结论）：我们当时的 latent 只是多加了几维
状态、由**同一个** observer 从**同一段历史**驱动，缺三样 JEPA 认为必需的东西：
1. **信息不对称**：z 的推断路径必须能看到预测器看不到的信息（训练时看未来）；
2. **防塌缩/防退化正则**：否则 latent 维会退化成噪声或常量；
3. **随机性与先验/后验分离**：训练用 q(z|未来)、推断用 p(z|历史)，二者 KL 对齐。

**含义**：latent 被否决**不等于"未观测驱动不需要表示"**，而可能是"我们用的表示方式
太弱"。这是一个值得重做的方向，但必须按上面三条重做，且**优先级低于 v0.6 的
①再热汽温作边界**——因为直接测量总优于潜变量代理。

### 3.2 层次化 / 多时间尺度（H-JEPA）↔ 延迟 > 预测窗口

**我们的实测困境**：二级阀→末温峰值滞后 **240-560 s**，而 H18 窗口只有 **180 s**；
窗内相当部分由**窗前在途状态**决定。同 span 分层铁证：同样温度变动幅度下，t=0 前
阀门动过的窗误差是安静窗的 **2.2 倍**，技巧分从 +0.48 翻转到 −0.38。

我早前提的解法是**显式延迟线状态**（600 s / 10 s ≈ 60 维缓冲）。H-JEPA 提供了更经济的
替代：**学习式粗粒度慢状态**——一个低维、低频更新（如每 6-18 步）的慢潜态，承载
"在途焓剖面 + 金属温度场"的摘要，与快物理态并行。

**这是 JEPA 对本项目最实质的启发**：不是"预测 latent"，而是**"用学习式粗粒化替代高维
显式缓冲"**，把 60 维延迟线压成 2-4 维慢状态。

### 3.3 EMA target encoder ↔ 观测窗辅助损失（最便宜、可立即试）

**可立即实现的借鉴**：在保留物理损失的前提下，**增加**一项辅助损失——用一个 EMA
target encoder 编码**未来观测窗**，让当前物理状态（经一个小投影头）去预测该 embedding。

- 不动物理解码器、不动预测目标；
- 梯度只用于**塑形状态估计器**，让 11 维物理态承载"慢/在途"信息；
- 正对 O1 判决暴露的弱点（learned MIXED / hybrid REJECTED = 学习式初值修正无显著增益）；
- 与 §2.1 不冲突：主损失仍在观测空间，辅助项塌缩不会带来平凡解。

## 4. 与"最终目标 = 实现 world model 的 state 与 prediction"的对照

LeCun 的世界模型系统含四块：**encoder / predictor / cost / actor(planner)**。本项目现状：

| 模块 | 现状 | 评价 |
|---|---|---|
| **predictor** | 物理 ODE（UDE），34 参数 | **强项**：可解释、方向持证（frac_neg=1.000 全负荷箱）、可消融归因 |
| **encoder / state** | GRU observer → μ/σ | **弱项**：O1 判决 learned MIXED / hybrid REJECTED；在途剖面过不了状态瓶颈 |
| **cost** | 未建 | 用户已提的 CVaR / IAE / ITAE / 超温积分就是这一块的雏形 |
| **actor / planner** | 未建（MPC 对比仅作评测） | 待建；受"动作通道弱因果"制约 |

**判断**：我们的 predictor 已经比 JEPA 式学习预测器**更适合本问题**（物理约束 + 可辨识 +
可审计）。真正的短板在 **encoder/state**——而这恰好是 JEPA 三个机制能帮上的地方。
**所以借鉴方向应当是"JEPA 强化 state，物理保留 prediction"，而不是两者都换。**

## 5. 可预注册提案（B 系列，排在 A 系列之后）

| ID | 改动 | 借鉴自 | 主假设 | 成本 |
|---|---|---|---|---|
| **B1** | 未来观测窗 EMA-target 辅助损失 | JEPA target encoder | 塑形后的物理状态承载更多在途信息 → H18 高负荷箱改善 | 2.5 h |
| **B2** | 低频慢潜态（2-4 维，每 6-18 步更新） | H-JEPA 多时间尺度 | 替代 60 维显式延迟线，缓解 延迟>窗口 | 3 h + 实现 |
| **B3** | CVAE 式 regime 潜变量 z（q(z|未来) / p(z|历史) + KL） | JEPA 潜变量 z | 表示未观测热输入；**预期收益体现在段级偏置而非窗内 MAE** | 3 h + 实现 |

**判定规则沿用 A 系列**：ΔH18 ≤ −5% 且分箱极差恶化 ≤ +10% 且 **frac_negative = 1.000**
（方向证书是硬门）。B3 额外要求：**报告段级/日级偏置指标**，因为其预期作用点不在窗内。

**优先级说明**：B 系列全部**排在 A 系列之后**，且 B3 排在 v0.6 ①（再热汽温作边界）之后
——直接测量优于潜变量代理，这是先验判断，不是实验结论。

## 6. 诚实标注的风险

- JEPA 的实证记录集中在视觉/机器人，**在工业闭环过程控制（含安全约束）上无成熟先例**；
  整体移植是跃进，只有 §3 的具体机制可迁移且可检验。
- B3 与我们"closure 动作盲"的保护设计有潜在冲突：若 z 的推断路径看到未来动作，会污染
  动作通道的因果证据。**约束**：z 的编码器输入**禁止包含未来动作**，或 z 只进入非动作路径。
- 增加 latent 一律面临 T1 已有的负面先例，需先复现基线再引入变体（本轮教训）。
