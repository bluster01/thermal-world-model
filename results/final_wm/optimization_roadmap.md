## 1. 主线（矩阵判决后第一优先）：参数状态依赖（参数 MLP）

核心诊断：参数自由度不够。UA/k/th/tau 分段常数 + pm 单维 blend，自由度差一个量级。

设计（嵌套三臂，同 T1 判别逻辑）：
- A 臂（null）：`log(UA_i) = log(UA_i0) + α_i·(D-D0) + β_i·(pm-pm0) + γ_i·(rB-rB0)`
  ——指数仿射，正性保证，可解释（系数可对现场知识验证）
- A+δ 臂（推荐甜点）：仿射 + 残差 MLP（8-16 隐层），δ 初始化为 0、收缩惩罚，
  UDE 哲学原样搬到参数层
- 自由 MLP 臂（上界参照）：警惕 T1 latent4 教训（无约束容量 = 负贡献）

纪律：
- 回归子分通道选：上游（sh1_in/sh1_out）用 D/rB/pm/Tfw；喷水下游（sh2_out/final）
  必须带 W 与 **varphi(v)**（用现成阀特性映射，不裸喂阀位）
- 无量纲群输入 (D/D0, pm/pm0, rB/rB0)；包络外 δ→0 退化仿射（外推安全）
- UA(D) 单调性约束；σ(x) 状态依赖打包一起做
- action 不进 k/UA 回归子（防动作依赖走私，R1 红线）；先验向常数收缩

预期：H1 final 3.1 → ~1.5-1.9（分箱天花板兑现 70% 口径），H18 同步。

## 2. 误差地板（三锚点推导，H1 口径）

- 锚点 A 快慢分解（10min 中值滤波）：σ_fast = final 0.86 / sh1_out 1.44 / sh1_in 1.61 /
  sh2_out 1.66 / sh2_in 1.81 → MAE 地板 0.68-1.45
- 锚点 B 去工况 within-bin σ：工况全吃掉 → final 1.49 / sh2_in 2.18 / sh2_out 2.28 /
  sh1_in 2.34 / sh1_out 9.90
- 锚点 C 模型 learned σ（上界）：final 1.9 / sh2_out 1.5 / sh1_in 8.8（上游通道大量结构
  误差被丢进噪声项 → headroom 证据）

分通道地板结论：final ~1.2-1.5、sh2_in ~1.8、sh2_out ~1.8-2.3、sh1_in ~1.9-2.4；
**sh1_out 例外**（σ=11.6、between ratio 0.27）——不是工况偏差是喷水瞬态动力学滞后，
参数 MLP 无效，需喷雾动力学结构升级（见 §3 末条）。

不确定性：within-bin σ 混有空间集总误差（需 5 段消融分离）；H18 地板待完整残差复算。
以上是"参数优化后可达水平"的估计，非定理。
