# 首轮发现与 1/3 数据下一轮

## 先保留什么思路

首轮回传 `059af64`：11/11完成，seed11、1/10训练窗口、6epoch。下表均为主汽温度累计MAE，单位°C；H32=320秒，H128≈21分钟，H512≈85分钟。

| 模型 | H32 | block H128 | block H512 | native H512 |
|---|---:|---:|---:|---:|
| 黑箱 SSM | **0.8232** | 1.4468 | 1.8091 | **1.8746** |
| direct | 0.8398 | 1.4401 | 1.9864 | 不适用 |
| R4+MLP | 0.8750 | **1.4281** | **1.7120** | 1.9097 |
| R4 | 0.9464 | 1.5358 | 1.7625 | 1.9454 |
| direct + R4 anchored_hold | 0.9330 | 1.5445 | 2.0916 | 2.0198（混合） |
| AIT | 0.9439 | 1.6658 | 1.9917 | 14.3070 |

1. **保留SSM的参考预测能力。** H32误差最低，动作变化最大的四分之一报告窗口中H32也最好（0.9501°C）。60秒温差MAE=0.4323°C、相关性0.5868，也优于其他首轮模型。但原生+3个百分点阶跃的平均主汽末端响应为阀1 **+0.1151°C**、阀2 **+0.0735°C**，方向需要改。预测能力和动作通路应分别借鉴。
2. **保留R4+MLP的信息提取与响应结构。** 相对R4，H32从0.9464降到0.8750，block H512从1.7625降到1.7120；原生110方案中预动作响应、不可达通道响应、单向动作反向比例均为0（数值容差内）。+3个百分点阶跃末端为阀1−0.1145°C、阀2−0.1232°C，响应非零。
3. **把“刷新参考预测”和“保留动作状态”拆开。** R4+MLP在block重编码后不可达通道最大差值3.1093°C，单阀单向场景的平均反向比例12.63%；native对应均为0。响应图里block阶跃衰退、脉冲尾部翻向，说明重编码让动作进入了新的参考分支。下一轮直接试参考分块更新、动作carrier始终保留。
4. **强预测器与R4直接相加仍需适配。** anchored_hold的H32比direct差约11.1%，动作活跃子组更明显（1.2139 vs 1.0260°C）。固定hold名义计划改变了预测器原本使用的未来动作条件；“名义计划处保持预测”不等于“记录动作下保持精度”。因此下一轮比较免训练拼接、联合适配、加预测teacher三种做法。
5. **暂不把token交错当作主要增益来源。** 等参数attention_concat的H32=0.8606，AIT=0.9439；AIT native长程明显漂移。先给全部深度模型更多数据，再判断。此处是紧凑AIT实现的结果，不代表完整CEDAR复现。

完整逐模型、逐模式和动作活跃子组表：[DIAGNOSIS.md](round1_analysis/DIAGNOSIS.md)。原始曲线和指标在 `results/action_predictor_bench_20260919/screen_seed11`。以上用于提出假设，单seed不作稳定排序结论。

## 六个响应消融

全部以新1/3训练得到的SSM与R4+MLP为父模型，拒绝混用1/10父权重。候选动作与名义计划分开，名义计划固定为预测起点的末端阀位保持值。没有新增框架或调参搜索。

| 名称 | 新增训练 | 回答的问题 |
|---|---|---|
| r4_protected | 无 | R4+MLP参考按32步刷新，carrier不中断，能否保留其长程精度与响应形态？ |
| ssm_protected | 无 | SSM保持阀位参考 + 连续R4+MLP响应，未经适配的代价多大？ |
| ssm_continue | 6epoch | 只继续优化原SSM，作为额外训练预算对照 |
| ssm_soft_response | 6epoch | 原SSM增加R4响应蒸馏，软约束能否改善动作而保住预测？ |
| ssm_r4_joint | 6epoch | SSM参考和结构化R4响应联合适配真实轨迹，能否弥合免训练拼接的精度差？ |
| ssm_r4_teacher | 6epoch | joint额外匹配冻结原SSM的记录动作预测，能否进一步保护精度？ |

四个拟合臂：统一lr=.0003、Adam重置、每轮完整遍历同一1/3样本、相同顺序、960新增更新；都在固定selector上按H32主汽MAE选checkpoint，并允许保留初始化epoch0。只选准确率有意用于观察响应改善是否稳固，响应指标不参与模型选择。总成本包含父模型训练，另记新增训练秒数与updates，不把复用权重当免费训练。

软响应约束每batch取前8个训练样本，循环2阀×正负3pp×起点0/8/24步×阶跃/斜坡/脉冲共36种扰动，越界样本排除。匹配冻结R4+MLP的候选−保持响应，以0.1倍训练温度标准差归一化、权重1；教师提供结构偏置，幅值不是额外真实干预标签。预测teacher只在训练集记录动作上使用，权重0.25；保留与真实五温度的原损失。

结构组合直接读取R4的`action_response_C`，加到独立参考上，不用相减两个约550°C轨迹来获得小响应。block模式只刷新名义参考，carrier从同一起点连续推到终点；native模式两个分支均连续。两列明确分开，不能把新block说成与原“全模型重编码”完全相同的推演机制。动作差应不受参考刷新影响，这项有110场景行为测试。
