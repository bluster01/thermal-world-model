## 1. 诊断 (D4, 不设硬门槛)

1. **实测执行机构动态**: 指令→阀位 拟合一阶 τ_a + 速率限制 (|Δpos| 95分位/10s), 报告 R²
2. **真实干态闭环响应**: 干态段 SP 阶跃事件 (|ΔSP|≥0.5°C, 持续) → 事件研究归一化曲线, 锚点 60/120/180/300/420/600s, 报告事件数
3. **真实干态开环形态**: 干态阀位阶跃事件 (|Δv2|≥2% 持续) → (T_main−T0)/Δv2 堆叠曲线

## 2. 修复试验: 实测执行机构动态进仿真环

模型 qnal seed0 + 分状态 k_w (FIX3 拟合) + 实测 (速率限制, τ_a) 的阀门执行机构:
- D1: 干态耦合闭环 norm600∈[0.8,1.2] 且 tail_std≤0.05
- D2: 湿态耦合闭环同门槛 (不退化)
- D3: 湿/干耦合阶跃 main 末值 < 0 (免疫保持)

裁决: D1∧D2∧D3 = PASS → 干态阻塞解除, 控制嵌入全工况可用; D1 FAIL → 用 D4 的模型vs实测干态响应对比判定: 模型太快(→残差动态化方向) 或增益太高(→W子模型方向)
