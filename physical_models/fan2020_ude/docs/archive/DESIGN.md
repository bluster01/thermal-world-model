## 1. 目的

验证一句话：**Fan2020 的守恒骨架（分段集总焓 ODE + 喷水混合 + 物性闭合）能否在伊敏闭环 10s 数据上、以阀位为动作接口，让 5h 递归 rollout 同时达到"误差不差于 v2、物理一致性不差于 v2o"。**

ad-hoc 1 已证明：约束的"药在结构不在特征"（v2o 顺序约束 rollout 3.81→3.00、带外 0.0%）。本实验把"loss 级约束"升级为"结构级守恒方程"，是 Phase 4 RQ2 的最小可行性预检。

预期（来自 08-15 分析）：**状态闭合和物理一致性的解药，响应幅值识别的半副药**——结构可行、动作通道可能学不到（闭环方向污染，ad-hoc 1 §2.2 两轮证据）。

## 2. 判决标准（预注册，执行前冻结，执行后不得改）

对象：主汽温（末级过热器出口汽温），5h = 1800 步递归 rollout，测试段，每 seed 单独判 + 汇总判。

| 判据 | 门槛 | 参照（ad-hoc 1 单种子点估计） |
|---|---|---|
| P1 | rollout RMSE ≤ **2.48** °C | v2 = 2.48（全组最优） |
| P2 | 带外占比 ≤ **0.5%** | v2o = 0.0%，v2 = 0.4% |
| P3 | 5 对联合顺序违例步占比 ≤ **1%** | v2o = 0.3%（联合 viol_any，非单对指标——ad-hoc 1 §6 已注明单对恒 0 无区分度） |

- seed 通过 = P1 ∧ P2 ∧ P3；总判 = ≥2/3 seeds 通过 且 3-seed 汇总均值通过。
- 附加通道判据：动作通道活跃 = rollout 期间 Dsw1+Dsw2 均值 ≥ 0.5% × 主蒸汽流量均值（典型喷水量级下限）。

**三级判决：**
- **FULL PASS**：总判通过 且 动作通道活跃 → 结构 + 动作双可行，RQ2 赌注落地。
- **CONDITIONAL PASS**：总判通过 但 动作通道不活跃（θ₁+θ₂→0）→ 结构可行、阀位动作通道不可辨识（坐实"半副药"预期，仍是 Phase 4 的重要边界信息）。
- **FAIL**：任一 P1–P3 不达标 → 结构级守恒在闭环 10s 数据上不可行，Phase 4 Gate 0 需重新设计。

次要诊断（报告不计判决）：maxerr、5 个沿程温度逐点 RMSE、单步 RMSE、学得参数物理自洽表（符号/量级）、τ 是否被推向采样周期。

## 4. 模型结构（Fan2020 骨架最小化）

### 4.1 拓扑（P 级假设，依据为 ad-hoc 1 顺序约束成立率，待 P&ID 核实）

```
分离器出口 ──[段0 加热]── 一减入口 ──(spray1 混合)── 一减出口
   (pm,Tm)      M0,UA0,Cm0      T_sh1_in         θ1·v1          T_sh1_out
                                    └──[段1 加热 M1,UA1,Cm1]── 二减入口
                                                                 T_sh2_in
                                          ──(spray2 混合 θ2·v2)── 二减出口 T_sh2_out
                                              └──[段2 加热 M2,UA2,Cm2]── 主汽温 T_main
```

拓扑假设：一减/二减出口 = 喷水混合后测点（与 T_sh1_out < T_sh1_in 成立率仅 66.2% 兼容：喷水全关时近似相等 + 噪声）。若 e0 对两个入口/出口温度系统性错配，**诊断为拓扑假设错误**——不改变主汽温判决（P1–P3 只看主汽温），但必须如实记录并附错配图。

### 4.2 方程（h 空间，IAPWS-IF97 物性闭合）

**外生边界（rollout 时喂真实未来值）：**
- D = `主蒸汽流量`（t/h→kg/s 常数缩放）
- uB = `未校正总煤量`；制粉一阶滞后：`τ_B · drB/dt = −rB + uB`
- h_sep = h(pm, Tm)，pm = `分离器出口压力`，Tm = `分离器出口温度`
- h_sw = cp_w · T_fw（cp_w = 4.18 kJ/kg·K，T_fw = `省煤器出口给水温度`；喷水取水点 P 级，敏感性见 §7）
- v₁, v₂ = `一级减温调节门阀位`, `二级减温调节门阀位`（归一化 0–1）
- p_out = `末级过热器出口压力`（物性闭合用）

**动作通道（P 级代理，不得声称 kg/s——伊敏40列_vs_Fan模型变量对照.md §3.1）：**
- Dsw_i = θ_i · v_i，θ_i ≥ 0（线性阀特性；`减温水总流量` 只作总量校准锚点，见损失项）

**三个加热段（i = 0,1,2；蒸汽焓状态 + 金属蓄热状态）：**
```
M_i  · dh_i/dt  = D·(h_in,i − h_i) + Q_i            # 质量驻留 + 金属传热
Cm_i · dTm_i/dt = k_i·rB − Q_i                      # 烟气吸热 − 向蒸汽放热
Q_i = UA_i·(Tm_i − T_s,i)，T_s,i = T(p_i, h_i)
h_in = [h_sep, h_m1, h_m2]；p_i：pm→p_out 线性插值（P 级）
```
**两个喷水混合点（代数，Fan20 式）：**
```
h_m1 = (D·h_0 + Dsw1·h_sw)/(D + Dsw1)  →  T_sh1_out = T(p, h_m1)
h_m2 = (D·h_1 + Dsw2·h_sw)/(D + Dsw2)  →  T_sh2_out = T(p, h_m2)
```
**输出链：** T_sh1_in = T(p,h_0)，T_sh1_out = T(p,h_m1)，T_sh2_in = T(p,h_1)，T_sh2_out = T(p,h_m2)，T_main = T(p_out,h_2)

**学习参数（全部 softplus 保正）：** M_0..2, UA_0..2, Cm_0..2, k_0..2, τ_B, θ₁, θ₂ = 15 个；每窗状态重置（h_i 由观测温度反算，Tm_init = T_s + ΔTm_i，ΔTm 可学习 ×3）≈ 18 参数，对 5,989 样本高度可辨识。

**损失：** 加权 MSE（5 输出，主汽温 ×2，同 ad-hoc 1）+ λ_cal·(θ₁v₁+θ₂v₂ − κ·减温水总流量)²（校准项，λ_cal=0.1，κ 单位换算常数）。Adam lr=1e-3，batch 256，≤60 epoch，早停 patience 8，种子 0/1/2。

**物性：** `iapws` 包（IAPWS-IF97，纯 Python，pip 装进 Alloftime env）。若安装受阻 → 降级方案 e0t：恒 cp 温度空间等效式（注明差异，不改变判决门槛）。
