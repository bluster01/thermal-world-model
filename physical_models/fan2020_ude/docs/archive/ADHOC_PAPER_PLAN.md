## 3. 证据链主干（论文 A 叙事骨架）

### 3.1 灰盒辨识（"物理骨架在闭环数据上是否立得住"）
- e0 修复后：窗口内 5-10min 结构性漂移（湿态 sh1_in −16°C/主汽 +17°C，段0 欠热 + k 线性分配）
- 干态 = 最大缺口（分层消融）：rollout 17.11 vs 黑盒 2.44（干态层）
- 根因：跨模态共享 pm 斜率外推错误（b0 符号反：+0.011 vs 需求 −0.046）

### 3.2 残差机制（F1/F2 两发现）
- **F1 残差动作污染**：闭环数据中阀门从不随机动（confounding by indication）→ 残差学非因果捷径"v2↑→注热"→ 开环反事实暴露。证据链：e0 −0.047 → qh +0.073 → qnaw −0.191（三步对照）
- **F2 跟踪-控制保真张力**：残差=隐式闭环控制器。证据：① FIXC τ_res 学得 95s 数据自证残差该慢 ② 三向探针 e0 140s/qnal 50s/qslow 10s ③ 门控实验：9% 权威仍 τ63=20s（结构性）④ 湿态段1-2 残差=阻尼（去掉塌回 40s）
- 论文落点：六实验全映射表（qh→qnaw→qnal→qslow→qgate→qstate），每配置一个可量化行为

### 3.3 控制嵌入可行性（修复链 + 协议）
- F3 动态响应域协议：点wise RMSE 3°C 的模型，阶跃形态对了就够控制用；金标准锚点
- 湿态闭环：收敛 ✓、τ63 320s 进原 G2 ✓、G1 形态门槛未过（rate-only 前中段超/τ_a 中后段超）
- 执行机构身份：快伺服（10s 内到位）+ 0.14%/s 实测速率约束；883s=慢指令（湿 817/干 504）
- TF 包：autograd 精确线性化（14 维局部状态空间 ×6 工况点，R² 0.990-0.996，特征值 0.966-0.975 全稳定）
- 路线 A（MPC 替代 PID，阀位通道）离线可验证；路线 B（前馈调 SP）需在线

### 3.4 审计方法学贡献
- 预注册门槛 + 逐数字 commit 回溯 → 10 分钟定位 FIX4 bug
- 审计抓出的三类问题：门槛漂移（G1 从未复测）、参数生效条件 bug（τ_a 上界）、文档事实错误（种子数）——全部如实记录，零豁免

### 3.5 物理本质回归（完成：蒸发干燥 + qnav 平衡突破）
- FIXB：液滴状态 + 壁面供热 + 干燥度门控进灰盒本体。B1 湿态 sh1_out 偏差 21-25→3.07°C（物理本体首次修复两相病灶）；B4 干态正确退化
- qnav（残差上蒸发底座）：E1-E5 全 PASS——湿 τ63=480s 进窗、rollout 2.463 历史最佳、前 3 G1 锚点首过、两相偏差保持
- qnavlag 反证：τ_res 是钝刀（rollout 崩 11.33）——qnav 无滞后即最优
- Q32 第一性原理筛查（Codex 独立审计）：logged-future 精度优势依赖读 W 与非守恒净注热；h_now 仅是动作权限更干净的候选，物理可用性须由 Q32-R/Q32-S 继续验证；double_w 只作条件精度上界
- Q32-R 残差反馈归因（Codex 审计执行）：16点全为干态；live 四组方向正确率 2/8、8/8、2/8、2/8，replay 四组均恢复8/8。支持 residual feedback 机制，但 half/freeze 非单调且折依赖，不能定位单一载体，也没有跨湿/干证据。
- 剩余局限：湿 G1 中段（300s Δ0.34/420s Δ0.30）；干态闭环折分裂（F0 收敛/F1 冻结阀饱和）独立于已归因的符号翻转
