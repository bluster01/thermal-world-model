# Phase 2 最终结果审查 (2026-08-05)

> **核心判断: MPC 与 PID 在当前实验框架下不具备可比性。**
>
> 两层根因:
> 1. **仿真对象同构**: "被控对象"本身是世界模型 (神经网络), MPC 预测模型与之同架构 → 不具备外推有效性
> 2. **动作通道弱因果**: 世界模型中阀位对温度的控制作用弱 (工况主导), MPC 阀位几乎不动 (<10%) 但温度仍与 PID 持平 → "控制对比"前提不成立, RMSE 不显著 = 测不出来而非持平
>
> **§25.6 已裁定**: 放弃"虚拟世界控阀"主线, 转向"世界模型预测驱动 + 现场监督模式"。本审查为该决策提供数据支撑。

---

## 1. 根本问题 (两层)

### 1.1 仿真对象同构

```
被控对象 (plant) = WorldSim(M0+M8+M9 集成)   ← 神经网络
MPC 控制器       = MPCController(M5 或 M7)   ← 同架构神经网络
PID 控制器       = PIDController(kp=40, ki=8) ← 线性反馈
```

MPC 和 PID 都在控制一个**神经网络模拟的锅炉**。这不是仿真精度问题, 而是可比性前提问题:

- **MPC 的预测模型与 plant 同构**: M5/M7 和 M0/M8/M9 都是 DirectWM, 同架构、同训练数据、同特征集。即使实例不同 (P0-B 契约), 模型类完全匹配 → MPC 面对的动态在其预测模型的能力范围内。
- **PID 为真实锅炉调参**: kp=40, ki=8 是对物理过程的工程整定。世界模型可能不保留真实锅炉的全部动态特征 (执行器非线性、传感器噪声、未建模扰动), PID 在世界模型上的表现**不能代表**其在真实锅炉上的表现。
- **结论**: MPC vs PID 的 RMSE/TV 差异反映的是"在同构神经网络上的控制性能差异", 不具备向真实锅炉的外推有效性。

### 1.2 动作通道弱因果 (§25.6 核心发现)

§25.6 从 case 图层面独立发现了更根本的问题:

- **MPC 阀位几乎不动 (<10%)**, 但温度仍与 PID 持平 → 评测世界里动作通道对温度控制作用弱, **工况主导**
- 与 exp_083/领域知识一致: SP→温度 180s 仅 1% (工况主导)
- **含义**: RMSE 不显著不是因为"两者精度相当", 而是**在这个世界里阀位动作根本测不出控制效果** — 控制对比的前提不成立
- TV 优势是"不作为"的副产品 (不动自然平滑), 不是工程优势

### 1.3 两层根因的关系

| 层次 | 问题 | 影响 |
|------|------|------|
| 第一层 (§1.1) | 仿真对象同构 | 外推有效性丧失 |
| 第二层 (§1.2) | 动作通道弱因果 | 即使在仿真内部, 控制对比也无意义 |

第一层使结论无法外推到真实锅炉; 第二层使结论在仿真内部也不 solid。§25.6 的决策基于第二层 (更根本), 本审查的数据问题 (§2) 进一步佐证。

## 4. TV 优势的归因问题

TV 降低是 S1 中唯一在两场景一致的发现 (0.17-0.31 vs 0.53)。但这**不是世界模型的贡献**, 有三重解释:

1. **MPC 框架结构性优势**: MPC 有预测视野 (H_PLAN=18), 可预见 SP 变化提前缓慢调整; PID 是纯反馈, SP 变化时必须快速反应
2. **cost_d 显式惩罚 TV** (w_tv=0.01): MPC 优化目标里直接含 TV 项, PID 没有
3. **§25.6 发现: "不作为"副产品**: 动作通道弱因果 → MPC 阀位几乎不动 (<10%) → 不动自然平滑, TV 低是"不作为"的结果而非工程优势

**关键检验**: S6 公平对比下, 线性 MPC 的 TV (0.139-0.143) 甚至比深度 WM MPC (0.181-0.183) 更低 → TV 优势与深度 WM 无关。

**结论**: TV 优势不能作为深度 WM 或 WM-MPC 的价值主张。
