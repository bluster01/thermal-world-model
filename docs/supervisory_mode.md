## 架构决策: 走监督模式 (Supervisory Mode)

来源: 工业自控指南IAC《先进控制如何与PID系统"无缝对接"? 无扰切换全攻略》

**监督模式**: 先进控制做"外挂大脑", 输出最优设定值 (SP) 给底层 PID, PID 仍是阀门直接操控者。
- MPC 输出 = **idx 36 二级减温调节阀设定** (主汽温 PI 回路的设定值)
- 执行链: MPC(监督层) → SP → 现有 PID → 阀位 → 导前温度 → 出口汽温
- **无扰切换 = 设定值跟踪法**: APC 在线计算但输出跟踪当前本地 SP → 切换瞬间 SP 不变 (偏差=0) → 以速率限制斜坡调整到优化目标; 切除时反向同理
- 与"直接输出模式" (APC 直接算阀位, 需 4~20mA 输出跟踪) 相比: 监督模式更成熟, DCS PID 块原生支持 (RemoteSP + 设定值斜坡)

### 为什么直接控阀 (路线A) 与现场对不上
1. **时间尺度**: 现场副回路 SP→阀位秒级 (1.6x), 路线A 的 M_STEP=6 (60s 执行块) 慢一个数量级 — 快扰动 (蒸汽压力/流量突变) 60s 内无响应
2. **扰动谱盲区**: 论文评测只测 σ0.3 自相关 0.9 的慢随机游走, 恰好避开副回路存在的意义 (快扰动) — 虚拟世界"直接控阀有效"在快扰动下不可外推
3. **结构缺失**: 串级前提 = 副变量可测且变化早于主变量 (导前温度), 路线A 控制链里没有这一层

### 串级控制要点 (工业自控指南IAC《一个PID管不住快慢两个过程》)
- 主回路定目标 (温度), 副回路快执行 (导前温度/流量), 副回路必须明显快于主回路 (时间尺度分离)
- 主要扰动应先作用在副回路 → 副回路在主 PV 明显变化前压住
- 先副后主整定; 方向/量程/限幅/跟踪/故障退化逐层检查
- 副变量可测、可信、变化早于主变量 (导前温度满足)
