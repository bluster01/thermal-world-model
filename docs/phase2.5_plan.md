# Phase 2.5 计划 — 论文先进性补强 (nature-review 驱动)

**来源**: nature-review 三大共识 (R1-M1 自证循环 / R1-M2+R2-M1 基线不足 / R3-M1+M2 无统计鲁棒性)

## 任务 1: WM 保真度验证 (解决自证循环) — 最高优先
- **目的**: 证明"WM 虚拟世界"有物理锚点: 同动作序列下 WM 闭环预测 vs 真实温度, 误差随 horizon 累积曲线
- **实现**: 50 条轨迹, 真实阀位动作 + WM 闭环预测温度 (PID-WM, 已有 sim_pid_wm) vs 真实温度
- **输出**: 误差累积曲线 (10/30/60/120 步 MAE/RMSE), 与 WM 单步预测误差 (0.295°C) 对比
- **验收**: 120 步闭环 MAE ≤ 2°C 且增长亚线性 → 虚拟世界可信

## 任务 2: 线性 MPC 基线 (N4SID) — 确立深度 WM 增量
- **目的**: 证明深度 WM 比经典线性 MPC 有增量
- **实现**: 
  - 子空间辨识 (N4SID, python: slycot/sysidentpy 或 numpy 自实现), 输入=阀位动作+历史, 输出=温度
  - 线性模型 MPC (QP/梯度, 同 H=10, α=0.5, M_STEP=6)
  - 公平评测: 线性 MPC 也在 WM 闭环世界 (PID-WM 协议) + 真实数据开环对比
- **输出**: RMSE/std/TV 对比表 (DWM-MPC vs LTI-MPC vs PID)
- **风险**: N4SID 对非线性/大时延系统可能拟合差 → 报告诚实差距

## 任务 3: 统计显著性 (50 条)
- **目的**: paired Wilcoxon signed-rank test (RMSE/std/TV), 置信区间
- **实现**: scipy.stats.wilcoxon, 输出 p 值 + 中位数差异
- **验收**: p < 0.05 且效应量明确

## 任务 4: M_STEP 扫描 + 鲁棒性
- M_STEP ∈ {1, 3, 6, 12} 主评测 → 时标对齐敏感性曲线
- 鲁棒性: WM 预测加噪声 (σ=0.1/0.3/0.5°C) / 动作扰动, MPC 性能退化曲线
- **验收**: 退化平缓 → 鲁棒性论证

## 顺序
任务1 → 任务2 → 任务3 → 任务4 (每任务: 设计→留痕→跑→分析→commit)

## 预计
任务1: 0.5h | 任务2: 2-3h | 任务3: 0.5h | 任务4: 1.5h
