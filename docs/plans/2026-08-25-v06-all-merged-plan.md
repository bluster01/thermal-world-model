## 0. 资产实测结论

- **规模/对齐**：1,192,329 行 × 377 列，10s 采样整齐（p99=10s，>20s 占 0.00%），
  时间覆盖 2025-12-24 → 2026-05-11，**完整包住 canonical 82.6 天**；同一锅炉
  级文件同时服务侧A/侧B（镜像减温侧，无需第二文件）。
- **候选 57 列质量**：全部 100% 非空。死列剔除：`A/B侧反应器入口烟气流量`
  （100% 冻结=0）。冻结率高但语义正常的保留：给煤机瞬时煤量（停机=0 是物理
  真值，非传感器冻结）、主汽压力设定/滑压设定（阶梯设定值）。
- **关键可用信号**（canonical 41 列全都没有）：
  - `校正后总燃料量`（均值 264，4.7% 冻结）——**真实热输入代理**，治愈
    "coal_command 是指令非实际热输入"这一 sh1_inlet 首要病因；
  - 磨×8 高温炉烟温度/流量（动态良好，冻结 0.3-13%）——**磨组合硬信号**；
  - 给煤机瞬时煤量×8——磨启停状态可由 >0 阈值直接判定；
  - `三选后A/B烟气含氧量`、`烟气含氧量`、总二次风量、A/B 侧二次风量；
  - 立式/水平低温再热器入口烟温 ×4——**炉膛出口烟温场代理**（TODO 行63 优先级①）；
  - `选择后左/右侧一过喷水减温器入口/出口温度`——**一级减温级前后温差实测**，
    闭包喷水混合项的直接监督信号（TODO 行63 优先级②，比流量测点更强）；
  - 再热器进/出口汽温×4 + 再热压力——再热侧状态（优先级⑤的输入前提）；
  - 水冷壁/屏壁温 ×10——结渣/积灰退化的辅助诊断目标。

## 1. 分阶段规划

- **产出**：`results/final_wm/probes_*/mill_switch_event_study.{py,json}` + 一页结论。
- **裁决作用**：若磨组合变更解释 sh1_inlet 残差方差显著份额 → v0.6 扩边界立项
  坐实；若不显著 → 降级为"烟气侧主导"，调整通道优先级。**先于任何模型改动**。
- 工作量：本地 0.5 天；不动模型、不动 canonical。

### Phase 1：canonical v2 管道（D0-v2，数据工程）

- **新增边界通道（boundary 7→14，全部 oracle 可得）**：
  | 通道 | 物理角色 | 针对病灶 |
  |---|---|---|
  | 校正后总燃料量 | 实际热输入 | sh1_inlet 主因 |
  | 磨组合状态向量(8→聚合2-3维) | 炉膛热分布 | sh1_inlet |
  | 烟气含氧量(三选后A/B) | 过量空气/燃烧工况 | sh1_inlet/主汽温 |
  | 总二次风量 | 配风强度 | sh1_inlet |
  | 立式低温再热器入口烟温(A/B) | 炉膛出口烟温场 | sh1_inlet 直接代理 |
  | 再热入口/出口汽温(左/右) | 再热侧耦合 | 次要 |
- **新增监督（不进 obs，辅助损失）**：一过喷水减温器级前后温差（左/右）→
  闭包一级混合项直接监督；过热器减温水总流量校验既有 spray_flow_total。
- **观测通道不变**（5 目标通道不动——保住与已冻结证据链的可比性）。
- **工程质量门**：沿用 D0 审计口径（缺失/冻结/量纲/单位逐列审计），canonical

- 工作量：设计侧 1-2 天 + 契约测试；执行侧构建 ~1h。

## 3. 风险与纪律

- **口径漂移**：v2 通道集下的一切数字与 v1 冻结证据链不可直接比——分列报告。
- **磨传感器野值**：3号炉烟流量 min=−24（反号野值），7号温度 min=10°C（停机
  环境温度）——入模前需物理量纲清洗规则入 D0 契约。
- **给煤量零值语义**：0=停磨是物理真值，启停状态应显式编码（>阈值）而非
  连续值直接入模。
- **过热度通道** `汽水分离器出口过热度` min=−43（湿态段负值合理）——可作
  干湿态判别特征，服务 A3 门控。
