# AB 双侧预测与阀门幅度：训练规划和验收 spec

日期：2026-09-22；实施更新：2026-09-23。状态：**双侧 runner 已在本地实现并完成八臂小检查；正式训练尚未运行。** 数据已逐窗口验收并统一换算精度，自然事件检测/匹配已修正。执行入口和口径说明见 `experiments/action_predictor_bench_20260919/BILATERAL.md`，正式训练仍由用户在 Linux 执行。

**目标：** 在固定 1/3 数据、充分训练和共同评价口径下，检验补齐四阀及两侧温度能否改善动作响应；找出保护版幅度变小的来源，同时约束两侧、多步、自由推演和负荷变化期的预测精度。

**架构：** 保留现有小型 SSM，逐项增加另一侧历史、四阀未来输入、AB 双输出；同信息下比较连续可训练 R4 与 SSM＋R4。先检验现有结构的能力，不在本轮同时引入新的 JEPA、Mamba 或大型物理求解器。

**技术栈：** 现有 NumPy mmap/NPZ、PyTorch、训练与续训工具、matplotlib；复用已有模块，不增加实验平台或配置框架。

## 1. 先把当前结论说准确

本文件中的 **SSM-B** 是旧 focused 实验的模型代号，**温度侧 B** 是右侧温度链，二者不是一回事。旧 SSM-B、D 都只输出温度侧 A 的五个温度。

### 1.1 保护版的幅度确实更小，但谷底尚不是实测幅度

旧权重、实际未来边界回放、原阀位轨迹上加 3 个百分点，观察 128 步（21.33 分钟）。以下是每个窗口各自的冷却峰值再取平均，每组 8 个起点：

| A 链二级阀 u2B 开大 3pp | SSM-B 连续递推 | D 连续 R4 响应 | D / SSM-B |
|---|---:|---:|---:|
| 前 128 步升负荷 | 0.4216°C | 0.0975°C | 23.1% |
| 前 128 步降负荷 | 0.4750°C | 0.1048°C | 22.1% |
| 冷却方向面积：升负荷 | 286.65°C·s | 68.20°C·s | 23.8% |
| 冷却方向面积：降负荷 | 320.92°C·s | 68.93°C·s | 21.5% |

这不是只挑一个瞬时点才出现的差异；峰值与面积都缩小。但当前没有同一起点的实测两种动作结果，不能认定任一模型的幅度是真值。

三个不能忽略的现象：

1. 一级阀升负荷时，SSM-B 连续模型的“逐窗谷值均值”为 −0.1610°C，而“均值曲线谷值”只有 −0.0137°C；降负荷对应 −0.1761°C 和 −0.0432°C。不同窗口的谷底时间、符号和回升并不一致，逐窗挑最深点会掩盖这些差异。
2. 二级阀 SSM-B 分块均值谷底约在 340s，接近 320s 重编码边界；连续模型升负荷谷底在 1070s，降负荷谷底恰在 1280s 观察末端。前者需要检查计算边界敏感性，后者属于右截断，不能称已到稳态。
3. 事实预测中，SSM-B 连续模式的 60s 温变幅度比约 0.976，比 block 的 0.782 更接近 1；但 H128 主温 MAE 为 1.2083°C，比 block 的 0.9789°C 更差。**较大幅度本身不等于较准确。**

允许把中段冷却峰值作为重要指标，也允许暂不把初始反向/晚期回升设为硬淘汰条件；仍须保留它们、固定取值区间，不在看完结果后删去不合意片段。阶跃还在时的回升与撤销脉冲后的恢复分开评价。

本轮已经补做**同权重 H512＋移动重编码间隔**。二级阀+3pp的16个起点全程合法，以下为先平均曲线再找谷值；两组名称只描述前128步负荷，不代表后85分钟持续升/降：

| 协议 | 原升负荷8窗：H512谷值/时刻 | 原降负荷8窗：H512谷值/时刻 |
|---|---|---|
| SSM-B 连续 | −0.4726°C / 2030s | −0.5483°C / 4190s |
| 每16步重编码 | −0.1035°C / 990s | −0.1641°C / 3940s |
| 每32步重编码 | −0.2291°C / 340s | −0.2698°C / 340s |
| 每64步重编码 | −0.5437°C / 3210s | −0.3979°C / 5120s |
| D 连续保护 | −0.0904°C / 2420s | −0.1245°C / 2590s |

谷值没有简单随分块边界线性移动；可以确认**强推演协议敏感性**，不能宣称已证明全部是边界伪影。同16窗事实H512主温MAE：SSM-B连续2.2075、block16为2.2532、block32为2.1116、block64为2.1744、D连续2.4496°C。这里只是固定小样本诊断，不替代256窗总体排名。

移动分块32与原forecast H512逐点相同，原H128及长推演前缀复核最大差3.41e−13°C。原始数组、负动作、完整五温度及逐窗统计见 `horizon_curves.npz` / `horizon_metrics.json`。

### 1.2 R0—R4 已经恢复了什么

R1—R4 是从 R0 出发的不同分支，不是逐层累加。R0 去掉显式反弹项后，原固定边界探针方向改善，但一级阀远端响应大量接近零。R4 将传输载体和读出增益分离，恢复了可达下游的非零响应：原三级种子、每种子 64 起点的 +3pp 探针，一级阀 H128 平均响应约从 R0 的 −0.0464°C 变成 R4 的 −0.0929°C，近零比例从 62.5% 降为 0。

因此，**R4 解决过“路径存在、方向受限、下游不消失”的问题；尚未证明增益和时延等于现场真实响应。** 旧 D 冻结了旧 R4 的全部参数，它没有机会通过本轮双侧数据重新学增益。不能把 D 的结果解释成所有结构保护必然压幅。

代码层面的保证要分四层：

| 层次 | 要检验的含义 | 当前判断 |
|---|---|---|
| 动作隔离 | 相同历史、边界，动作开始前输出一致；结构定义的上游路径无直接影响 | R4/D 已有对应机制和探针 |
| 相对固定基准的方向 | 相对固定参考开度，非负动作偏移经正传输、正增益产生非正温差 | R4 结构支持，须保留适用前提 |
| 两个任意变化计划的排序 | 如果一个计划逐点更开，是否每一步都更冷 | **不能由上一条推出**；R4 增益/时常可依赖候选自身载体状态 |
| 幅度与时延正确 | 曲线与可比的现场事件相容 | 尚需校准证据；零反号不能代替 |

冻结权重不会冻结随候选动作变化的增益/时常轨迹。可在同一权重下增加“基准轨迹计算系数、所有候选共用系数”的诊断，定位排序反转是否来自系数调度；该诊断自身也不是真实物理性的证明。

### 1.3 已定位：旧 D 的弱主温响应主要落在末端读出，不是信号尚未到达

本轮进一步拆开同一 D 的载体和增益。16起点H512末60s，单阀+3pp：

| 路径 | 配对载体变化 / 标准化输入变化 | 基准读出系数°C/pp |
|---|---:|---:|
| 阀1→二级喷后T4 | 1.024 | 0.40251 |
| 阀1→末级主温T5 | 0.999 | 0.02360 |
| 阀2→二级喷后T4 | 1.002 | 0.25955 |
| 阀2→末级主温T5 | 1.025 | 0.02944 |

主温载体已接近完整传递，但主温读出系数只有对应T4的约5.9%/11.3%。这些系数是独立读出参数，**不是沿管路实测的能量传递比例，也不是模型总导数**。

全16窗均值曲线的谷值：阀1→T4，D为−1.4925°C、SSM-B连续为−0.6038°C；阀2→T4，D为−0.9018°C、SSM-B为−0.7625°C；阀2→主温，D为−0.1066°C、SSM-B为−0.4356°C。因此应把“保护把整条响应压没”修正为“该保护模型的末端读出明显更小，局部喷水响应并不弱”。

按每条路径 `R=−Kc`，配对精确分解为 `ΔR=−K_base·Δc−ΔK·c_candidate`，全部六路径加回完整D预测差的最大误差1.13e−13°C。阀2+3pp末60s主温：自身载体项−0.09116°C，增益调制项−0.00585°C，加另一个阀主温路径的交叉项+0.00196°C，总约−0.09505°C。载体已到、读出偏小，是**模型内部压幅位置**的证据，尚不是现场应有多大幅度的证明。

相反，SSM-B一级阀+3pp会在10s使上游T1预测差约+1.492°C；D为0。SSM的末级谷底有吸引力，但其整条动作路径还不能整体认可。需要用局部事件验证直接喷水路径，并区分共同扰动/闭环关联。

## 2. 可用数据与共同接口

详细字段和核对数字见 [双侧数据笔记](2026-09-22-bilateral-data-notes.md)。训练实现以本 spec 的损失、归一化、回写规则为准；笔记中的候选方案不是另一份运行配置。

### 2.1 固定起点，不能因补 B 侧而偷偷缩小数据

沿用旧 `screen_A_33pct_h128.npz` 的 train/selector/evaluation 起点：**20,371 / 128 / 256**。两侧同步抽取，train/selector 长度 64+128，evaluation 长度 64+512。禁止 A/B 独立随机抽窗后按数组行号拼接。

这些起点 B 侧都有有限值。若要求四阀反馈都在 [0,1]，只剩 13,473 / 70 / 174 个窗口；失败全部来自物理 u2A 的轻微负反馈，最大负值约 −0.89pp。主协议明确采用已有 canonical 可参考的 **raw-feedback 容忍带 [-0.02,1]**，保留原值与全部旧起点；另外单列四阀全在 [0,1] 的 strict 子组和近闭位子组。这是显式协议变化，不伪称旧 strict 不变。

负反馈是测量读数，不是物理负开度或负喷水。首轮 SSM/R4 使用原始反馈坐标和同口径的偏移，不在某一臂单独 clip。动作探针必须同时满足原始反馈容忍范围和共同支持条件；跨近闭位零点的探针单列为传感器/死区敏感性，不能当成已知有效喷水增量。若后续引入非负流量映射，闭位校准及其消融另列。

新 B 通道尺度只由训练数据拟合；原 A 通道沿用旧 train mean/scale，所有新臂共享同一组归一化文件并记录哈希。训练窗口有重叠，统计不把窗口数等同独立事件数。

### 2.2 十温度、四阀、共同工况

| 温度链 | 一级阀 | 二级阀 | 五个观测 |
|---|---|---|---|
| A＝左 | u1A | **u2B** | 一级喷前、一级喷后、二级喷前、二级喷后、末级出口 |
| B＝右 | u1B | **u2A** | 同上五个独立右侧测点 |

四阀顺序固定 `[u1A,u1B,u2A,u2B]`，输出固定 `[A_T1..A_T5,B_T1..B_T5]`，不要用模型代号 B 或旧 Phase35 side 字符串猜映射。

联合历史基础是 21 维：10 温度＋4 阀位＋5 公共边界＋2 出口压力。去掉旧旁路里重复的 B_T1/B_T5，再加原来的 9 个历史旁路，合计 **30 个唯一通道**。现旁路含 A 侧氧量和左链控制设定，属于不对称观测；首轮所有臂使用同一套已存在旁路，不顺手补另一侧设定而引入额外变化。

未来输入为四阀和七边界（五公共＋左右出口压力），没有未来真实温度、未来旁路或未来 MW。为保持消融清楚，**所有新臂都提供七边界**，包括 S0-A/S0-B；S0 因而是本轮共同接口下重训的单侧参照，不是旧 SSM-B checkpoint 的逐位复现。五公共边界不能复制成两份侧别蒸汽流量。

动作/边界使用 H+1 行共同时间轴：t 时刻控制驱动 t+10s 温度，回写预测温度时拼接 t+10s 的控制/边界行，避免一个采样点的错位。负荷变化诊断先回放完整煤量/蒸汽流量/压力等一致轨迹；当前不能只改一个未来MW数值就称完成了加减负荷指令模拟。

当前动作是阀位反馈轨迹，未认证为最终执行器指令；没有四阀独立喷水流量。首轮结论限于“给定未来反馈阀位与工况的条件预测”。喷水引起的流量/压力变化、控制器再调另一阀，未包含在固定其他未来输入的配对探针中；不把它等同完整闭环机组模拟。

## 3. 训练矩阵：先做两参数定位，再完整训练七个主臂

### 3.0 优先小诊断 G2：只重新标定旧 D 的两个末端增益

新增 **1次小拟合**，与固定旧D配对：冻结旧D的背景、传输、时常、增益调度以及其他四个读出参数，仅优化 `path_gain_raw[3]` 与 `[5]`（两个阀到主温的路径）。它们只影响末端读出，不反馈至载体/记忆/背景，因此能明确定位，不需要新网络。

沿用原1/3 A数据、H128事实温度损失及相同A-short/A-balanced选模规则；使用原D的block32背景＋连续响应部署路径训练和评价，保证除两参数外行为相同。旧D在同协议下重新评价作对照。主温损失前32/后96步各半；其余温度不变，保留全通道核对。调度/停止采用下表规则，报告实际轮数和优化参数数。事件曲线只作独立检查，不再加事件辅助损失、不把SSM谷底当teacher、不设强制增益下限。

必须验证T1–T4预测、载体、参考轨迹和时常与旧D保持一致；同时报告两个主温载体的共线性，防两增益互相补偿后被误称分别识别。

G2若同时改善主温精度与有数据支持的响应区间，支持“旧D末端标定不足值得修正”。若增益放大但MAE恶化，不能叫恢复成功；若增益仍小，不能硬拉大。**G2单独不能证明保护的精度代价就来自末端增益**：若要作这个归因，再加同旧D/H128起点、只续训背景而固定响应的 `D_bg128` 对照，区分背景误差补偿。

首轮计划因此是 **1个两参数诊断＋7个完整双侧主臂＝8次新增拟合**；`D_bg128` 是有明确触发条件的第9次，不暗中加入或替换。G2不具备双侧信息，成功也不取消用户要求的完整双侧矩阵；它的重复优化不能冒充三个独立训练种子的完整模型。

### 主矩阵

主矩阵先统一 seed=11，全部使用上述 1/3 起点和 H128 监督，到共同 plateau 规则。**七臂全部完整回传后**再决定三种子复验对象。旧九类完整基线仍保留在历史精度表；本轮是解释双侧输入和保护代价的定向实验，不宣称重新覆盖了所有模型家族。

| 臂 | 历史信息 | 未来动作 | 监督目标 | 回答的问题 |
|---|---|---|---|---|
| S0-A | 原左链核心＋原历史旁路 | u1A,u2B | A 五温 | 相同 H128、新预算的单侧精度标尺 |
| S0-B | 右链核心＋同九旁路＋A_T1/A_T5 | u1B,u2A | B 五温 | 右侧独立精度标尺，避免只看 AB 平均 |
| S1 | S0-A 补齐另外侧温度/阀位历史 | 仍 u1A,u2B | A 五温 | 补齐另一侧历史是否有帮助 |
| S2 | 与 S1 相同 | 四阀 | A 五温 | 给定相同历史，另外两阀未来是否是遗漏信息 |
| S3 | 与 S2 相同 | 四阀 | AB 十温 | 双侧联合监督是否额外改善状态辨识 |
| R3 | 与 S3 相同 | 四阀 | AB 十温 | 同数据预算下双链 R4 能学到多大幅度 |
| P3 | 与 S3 相同 | 四阀 | AB 十温 | SSM 背景＋可训练连续 R4 能否兼顾精度和响应 |

S0-A 原来就有两个 B 温度历史旁路，不能把 S1 写成“第一次看到另一侧”。S0-B 的控制旁路并非完全镜像传感器配置，这一点在结果中保留说明。

SSM 臂保留 48 维递推状态和现有小型驱动网络；S2/S3 的状态更新、历史编码、动作输入完全相同，S3 增加 B 读出和监督。共同模块使用配对初始化、相同样本顺序，报告有效输入及参数数量；不把参数差异藏在“相同模型”里。

R3/P3 将旧 R4 响应扩成按映射的两条温度链，结构直接路径允许各链一级阀到 T2..T5、二级阀到 T4..T5。参考/共有状态可读双侧历史和公共边界；直接喷水响应按已核对路径路由。对侧远期真实影响仍可能经边界、母管和控制器产生，不能把结构设为零后再宣称现场跨侧效应为零。

P3 的名义背景在固定参考阀位下推演，候选动作不能经背景重编码绕过响应通路；R4 响应跨 block 连续。**R3/P3 的响应参数均重新训练，不能冻结旧 D 的小增益作为主比较。** 新主矩阵从头训练、同预算，不把某臂额外预训练的收益算成结构收益。旧 B/D/P0 保持权重固定，另作历史曲线参照。

### 3.1 监督与调度

每侧沿用温度通道权重 `[0.125,0.125,0.125,0.125,0.5]` 和训练尺度归一化 MSE。每侧时间损失固定为 `0.5×mean(前32步)+0.5×mean(后96步)`。

单侧为 `L_A` 或 `L_B`；联合为 **`L_A + L_B`**，保持 A 梯度系数不变，不用 `0.5×(L_A+L_B)` 后把 A 梯度减半当成纯多任务结果。报告两侧各自损失和共享层梯度范数作为诊断；不根据报告集调 λ。若出现冲突，λ 的调整只能成为后续单列消融。

这里保持的是 A 损失的显式系数，不能说 A 的实际参数更新不变：共享梯度、范数裁剪和 Adam 仍会影响更新。

| 项目 | 主矩阵固定规则 |
|---|---|
| 历史/监督 | 64 / 128 步，10s/步 |
| batch | 128；约 160 updates/epoch，末 batch 按统一规则处理 |
| 优化器 | Adam，初始 lr=1e-3，下限 1e-4 |
| 最少/最多 | 12 / 90 epochs，实际 plateau 即停止 |
| 学习率 | 相应 selector 有效改善 0.002°C 清 stale；连续4 stale减半，floor后6 stale判 plateau；复用现有调度精确定义 |
| 续训 | 保存/恢复 Adam、LR、epoch、随机状态、stale、best，不以重启优化器冒充续训 |
| 随机性 | 首轮11；候选及其直接对照追加23、37，所有结果保留 |

到 90 轮仍未 plateau 的标记 `budget_limit`，完整回传学习曲线和 best/last；不能写“充分收敛”，也不能仅因早期落后而删掉。是否继续由尚未稳定的趋势决定，先看全臂反馈。

每轮另记录固定训练事件上的响应峰值/面积和R4增益、时常分布，作为响应是否还在变化的诊断，不据报告探针调整模型或挑best。事实selector的plateau不能被写成“物理幅度已经收敛到真值”。

### 3.2 checkpoint 与 block 回写不得混入新优势

所有输出A的模型保存 A-short、A-balanced（A 主温 native-H32、native-H32/block_context_fixed-H128等权）用于 S0-A→S1→S2→S3 的 A 侧比较。只输出 B 的 S0-B 使用对应单侧 B selector。联合模型另存 **AB-balanced** 部署候选：两侧主温各占一半，每侧 native-H32 与 block_joint_refresh-H128 等权。该 checkpoint 在报告集同时评价 A/B，不为每一侧临时挑不同权重。训练调度在单侧使用本侧 selector，联合使用 AB selector；披露这一预算分配差异并报告训练轮数。

S2→S3 以 **native H32/H128/H512 为首要比较**，候选计划连续推进隐状态，禁止回写任何未来真实温度。它排除了额外B输出回写的优势，但主矩阵仍比较“增加B监督＋双侧调度”的组合效果，不能称精确隔离了损失项本身。只有该组合有希望且需要进一步归因时，才补固定学习率日程/相同更新预算的S2/S3配对，不先扩大主矩阵。

另给 S1/S2/S3 共同的 `block_context_fixed`：A 模拟温度按相同规则回写，另一侧温度始终作为起点历史摘要，不因 S3 有 B 输出就额外刷新它；两侧共有历史旁路同样固定。保持 S2/S3 相同的 A 状态更新和历史编码规则，B 读出不额外进入 A 递推。

S0/S1 未提供的另两阀未来值，在推演与回写历史中都不能读取记录值：它们保持起点阀位或固定起点历史摘要。只有 S2/S3 才按四阀计划回写。否则 S1 会从第二个block起偷拿S2的信息。

`block_context_fixed` 只用于A侧归因，B侧长程部署MAE统一用native或 `block_joint_refresh`。不要每块将B输出重新锚定到最初温度，再把这种人为拼接算成B长程精度。

S3/R3/P3 再评价部署用 `block_joint_refresh`：可用**两侧预测温度**刷新相应历史，绝不回写真实 B 温度。此模式单列为“联合监督＋双侧状态刷新”，不拿它与 S2 的单侧回写差值声称纯监督收益。R4 的响应载体在两种 block 协议中都连续，不随背景重新编码清零。

若 H128 的 S0-A 明显劣于旧 H32 参照，先补 **S0-A/S3 配对 H32**，判断长监督权衡，不把监督长度变化归因于双侧建模。旧 Round2 已做过短预算联合/蒸馏，Round3 已做过 H128/名义动作变体；本轮新增价值是完整双侧信息、充分训练、局部响应验证，不将这些旧尝试重命名成新思路。

## 4. 精度 spec：两侧、多步、变化率、外推共同看

主表每个 checkpoint/模式固定报告以下项目，不能只发最佳单项：

| 指标 | 分辨什么 |
|---|---|
| A/B 每通道、各侧主温 H32/H128 MAE | 5.33/21.33 分钟多步预测，防主温权重掩盖局部喷后误差 |
| block 与 native 的 H512 MAE | 85.33 分钟推演；两种算法分表 |
| H129–512 单独 MAE、各 128 步区间 MAE | 超出训练监督长度的**时间外推**，不能被前128步平均稀释 |
| 60s 温度增量 MAE、相关、RMS幅度比 | 是否把动态变平，或用更大振荡换取假幅度 |
| A/B 共模 `(A+B)/2` 与差模 `(A−B)/2` 误差 | 共享工况与侧别差异诊断，不等同已去除共因 |
| 升/降/变化/稳态，负荷反转，负荷速率分位组 | 查看动态工况退化；MW 仅用于事后分组 |
| train 工况支持内/外分组 | 区分时间长度外推与运行工况外推 |

工况外推分组在 train 上固定边界：至少 MW、实际 MW 差分、蒸汽流量和四阀范围/变化率的 1%/99% 分位；报告哪个维度超出和样本数量。这只是操作性支持分组，不能称完成任意 OOD 验证。已有单独 extension/test 分区不在本轮随意消耗；若未来启用，单列新评估协议。

“精度不损失”采用预先声明的 **2% 相对 MAE 非劣工程界限**，不是数学零损失：部署候选 A 与 S0-A、B 与 S0-B 配对；结构代价 P3 另与同信息 S3 配对。主温 H32/H128、部署 block-H512、native-H512及 H129–512 均列为共同关心项，不能仅用 AB 平均过关。十通道与负荷组逐项公开，若关键组退化则不得宣称全面保精度。

报告仍区分“点估计改善”“点估计轻微退化但满足工程界限”和“不确定/未通过”；即使+1%落在2%界限内，也不能改写成严格零损失。响应更合理但精度下降的臂保留为取舍结果，不包装成同时胜出。

首种子只做方向性筛选；至少3种子后用**按日期/不重叠事件分块的配对重采样**给95%误差差异区间，同时给每种子的原始数。在冻结候选、未参与选择的确认时间块上，各主项差异区间上界不超过2%，才作正式非劣确认；现256开发窗口达到同标准只能叫“开发集上的非劣证据”。区间跨界写“不确定”，不是自动通过。样本稀少组只描述、不伪造保证。

现 256 报告起点已被用于多轮想法选择，是开发反馈集，不能因本轮重写 spec 就变成全新盲测。保留这个标签。若需要最终确认，可在未参与选择的验证时间段预留一批事件块，先检查与训练、selector、报告窗口的时间重叠并冻结；不足则明确仍属开发性结论。

## 5. 响应 spec：不把“全负”或“更深”当唯一目标

### 5.1 配对定义及探针人群

所有模型使用同起点、同历史、同边界、同基准动作计划，计算 `ΔT = F(u+δ,d|history) − F(u,d|history)`。同时评价 held-action 基准与 recorded-action 基准；分别报告 held-boundary 和 recorded-boundary，不把前者的结构保证套到后者。

先在训练支持内固定、按负荷和开度分层的32个开发探针起点（保留旧32起点作为历史对照）；每种剂量/时长使用所有模型共同合法起点。必须保存起点ID、有效/排除数、排除理由。比较 H128/H512 时用 H512 共同合法人群再做 H128 截断，另报原 H128 人群，防样本变化伪装成响应变化。

四阀×十温度的**全部40条路径**都保存，按直接可达、上游、另一侧画矩阵。局部喷水效应优先核对一级 T2−T1、二级 T4−T3 的变化，再看下游 T3/T5；不只看末级主温。

40条路径适用于联合十输出臂。单侧模型缺少的另一侧输出标为“不适用”，不得填零参与精度/路径统计；未接收某阀未来输入的臂，也不能把其数值零响应算成已识别的正确路径。

### 5.2 首轮探针覆盖，控制计算量

| 轴 | 主探针 | 扩展诊断 |
|---|---|---|
| 幅度 | 四阀各 ±1/±3/±5pp | 以训练动作覆盖报告局部剂量排序，不追求越大越好 |
| 形状 | 持续阶跃；160s缓变；120s脉冲 | 30/60s脉冲、平滑波、双阶跃/反向动作 |
| 时间 | 评分窗前、评分起点、640s中期、1280s后期 | 31/32/33、63/64/65步附近动作，分辨切块位置影响 |
| 组合 | 单阀；同级左右同向/反向 ±3pp | 两级同向/反向，检验非加性及串扰 |
| 递推 | native、block32，H512 | block16/block64 同权重诊断、H128共同人群截断 |
| 工况 | 实际升/降/变化/稳态边界 | 实际负荷反转、held边界；重新按动作开始后的工况分组 |

不做所有轴的笛卡尔积。第一张主表统一单阀、±3pp、起点阶跃、H512；剂量/形状/时点各自单因素扩展。中后期动作先保留一致的动作后128步观察；若要比较动作后512步，另取有相应长度的共同窗口，不拿短观察冒充长程稳定。

评分窗前动作沿用旧探针的32步共同推演预热，在预热第8步改变候选动作，到第32步后才评分；两支都从更早的同一真实历史启动。不能只改历史阀位而沿用未经该动作演化的同一个末端隐状态，再把差异叫窗口前响应。

H512 已有真实未来输入；H1024 只在确有相应记录/窗口时做事实评价。额外 held 工况合成超长推演可检验数值稳定性，但不能写成现场长程 MAE。

### 5.3 每条曲线固定保存的量

- 0–60、60–180、180–600、600–1280、1280–5120s 的固定时间段均值与正负面积；初始反向最大值及持续时间独立列出。
- 逐窗冷却峰/升温峰的中位数和四分位区间、对应时刻；同时给“先平均再找峰”的结果，不混用两种聚合。
- 末端、末60s均值、末段斜率、到达观察边界的谷底比例；未稳定不叫稳态增益。
- 在有期望方向峰的窗口中，`(末端有符号响应−谷底)/(-谷底)` 描述从谷底返回多少；明确右截断。脉冲撤销前后分别记。
- ±动作不对称、局部剂量排序和相邻剂量增益；不同 seed、起点、工况的稳定性。
- 动作前差值、规定不可达的直接上游响应、另一侧短时串扰；自相关时间打乱/提前动作作为负对照。
- 两阀组合响应与单阀响应之和的差值，反映模型交互；不能把交互重复加到已条件化的总差值上。

对初始反向和后续回升不预设“一出现就错”：终端温度可能叠加工况、传播及闭环反馈；但在固定其他未来轨迹的模型配对中，逆响应仍必须有可核对的局部路径/状态解释。不要用“可能有热惯性”一句话把任何形状合理化。

## 6. 怎样判断哪一段更接近真实，而非模型互相投票

### 6.1 用可解释的自然动作事件校准

先在 train 及其时间分块内提取事件，不依据哪个模型吻合来挑。起始候选规则：目标阀60s内改变≥2pp，其他三阀同段各≤0.2pp；事件间合并重叠，只保留一个起点。再按其他阀变化强度、负荷/煤量/流量趋势分层。若严格事件数量不足，公开数量，将放宽门槛作为**单列敏感性**，不能偷偷改到有利结果。

为每个事件找同一侧、相近初始阀位/温度/历史温度斜率/负荷/煤量/流量的未动作片段，匹配特征只用动作之前的信息。报告动作前趋势与平衡差异；优先估计0–180s局部喷前喷后变化，再看180–1280s下游传播。另三阀同期稳定属于“孤立动作场景”的资格条件，可能选择特定控制状态，不能称随机化；长段中后续其他阀动作和负荷变化必须显示。

同时画实际各阀、煤/流量、两侧五温度和模型响应。提早动作的 placebo、错误侧阀的近场 placebo、共享变化与侧差变化都要看。A−B 不会自动消除不同侧的炉膛扰动、传感器时延及控制器差异。

得到的是**观察数据支持的局部响应区间**，仍可能受未观测闭环扰动影响，不能直接命名干预真值。当前没有每阀喷水流量，不能把阀位百分比直接换算成已标定热量。若四阀缺少独立激励或可比事件很少，输出“该工况幅度无法裁定”；这本身能指导补数，而不是靠增大模型投票决定。

### 6.2 “幅度恢复”的判据和具体定位

| 结果 | 支持的解释 | 下一步 |
|---|---|---|
| S1改善、S2/S3无额外收益 | 另一侧历史帮助预测状态 | 保留有用历史，勿宣称未来阀门效应已识别 |
| S2相对S1改善局部动作路径/剂量规律 | 遗漏另两阀未来是一个解释 | 看共动/孤立事件及其他阀固定时能否复现 |
| S3相对S2在native也改善 | 联合监督及双侧调度有额外收益，不能只用B回写解释 | 保留双输出，再单列双侧回写；需要纯监督归因时补共同优化日程 |
| P3保精度，R4增益变大且更符合局部事件 | 旧冻结响应校准不足值得优先解释 | 使用可训练连续响应，检查增益跨工况稳定 |
| P3和R3仍弱，S3更符合局部事件 | 受限响应表达/参考拆分可能不足 | 单因素放松增益调度、时间常数或参考计划；不先堆新损失 |
| SSM谷底随分块/窗口长度显著漂移，局部测点不支持 | 谷底不足以作为物理幅度证据 | 保留完整曲线、修推演一致性，不能谷底蒸馏 |
| 回放系数消除任意计划反转 | 候选依赖系数影响排序 | 比较共享系数与自由系数精度和事件吻合，不自动认定前者正确 |
| 事实精度接近，单阀响应分歧且事件支持不足 | 当前数据仍不足以定幅度 | 明确未决工况，寻找更有区分度的自然事件或后续小扰动数据 |

本轮不预设结构路线赢，也不预设自由 SSM 的最深谷底赢。只有**精度、局部路径、幅度/时延区间、剂量稳定性共同相容**，才写“这部分响应得到支持”。
