## 1. 已确认事实

最终融合指本轮按冻结门保留的 `fusion_gru_norew`，不是 M7，也不是其他线程的 JEPA/R4 或 steamwater 模型。
原对照是 GNR1 `greybox_steady_none_norew`。二者：

- 共用 `RichFusion -> FinalWorldModel -> Fan2020UDETransition`；transition 配置完全相同：10 s / 2 s 子步、action-driven spray、no-rewet、latent=0、启用金属稳态偏移。
- 共用物理温度输出公式。`ObservationModel.head` 只预测 sigma，不是温度均值残差头；不把它误认为响应差异的直接输出修正。
- 初始化都由同一稳态函数生成，但函数依赖各自辨识参数；GRU 另对四个慢状态做有界历史修正。
- GRU 有保守功率闭合；GNR 没有。GNR 与 GRU 的物理参数是分别训练的，不相等。

## 2. 三种可选路线与推荐

**推荐先做 A：同核固定权重对照。** 从 GRU 每个已选 seed 的 checkpoint 提取同一个物理核心，关闭观察器修正及功率闭合，不拟合。它在推理上是纯物理模型，但参数由融合联合训练获得；命名为“hybrid-derived physics core”，不能称独立辨识基线。原 GNR1 完整保留。

B：用 GRU 物理参数 warm-start 后重新拟合纯灰箱。这会同时引入新的训练选择，参数也可能重新偏离；若先做，仍难解释变化来自哪里。留作 A 的因果路径诊断之后单独注册，不默认追加。

C：以流量/现场增益证据约束灰箱辨识。这才可能建立实际校准，但需要可靠量测和新的数据/损失合同。不能根据当前模型曲线凭空设增益下限，不在本轮直接做。

## 3. A 的最小诊断矩阵（已确认并实现）

在每个 GRU seed 的**同一组物理参数**下做 2×2 固定权重推理：

| 编号 | 初态 | 功率闭合 | 身份 |
|---|---|---|---|
| C00 | 此物理参数生成的稳态锚点 | 关闭 | 提取的同核纯灰箱 |
| C10 | 同一锚点 + 该 seed 的 GRU 修正 | 关闭 | 观察器开启对照 |
| C01 | 同一稳态锚点 | 该 seed 原闭合网络 | 闭合开启对照 |
| C11 | 锚点 + 原 GRU 修正 | 原闭合网络 | 原 GRU，必须重放一致 |

C00 与 GNR1 的差异包含不同物理参数及参数依赖的稳态锚点；不能叫“只交换动力学参数、初态不变”。
C00/C10/C01/C11 的设计可以定位在固定联合训练参数下的组件依赖和交互，不等同重新训练的析因实验。
GNR1 仍是独立训练基线；不能将 C00 结果较好就静默替换掉 GNR1。

所有三 seed 都执行，不按 MAE/符号再选。复用原 256 预测 / 64 响应索引、W96/H18、原 23 维历史合同、训练归一化、IAPWS 指纹、oracle 预测/hold-last 探针、+0.05 剂量及 support mask。test 不进入诊断。
预测与两条动作分支使用同一个模型配置；一个反事实对的初态由同一历史一次确定，不让扰动动作回流改初态。关闭闭合只传 None，不更改物理公式；关闭观察器直接用锚点，不重初始化物理参数。

## 4. 保存内容与判定边界

- 固定源提交、父 identity/indices/checkpoint SHA、源/目标物理张量逐项相等检查、no-rewet pinned 检查、无网络调用的 C00 合同。
- 全 H1…H18 主汽温累计 MAE、逐窗口响应、实际剂量、支持域、零动作身份、逐日/逐 seed 结果；原始数组和失败均保留。
- 记录每个分支的初态，以及 target spray / lagged spray / 各段状态温差，定位响应沿哪条路径变弱；这些是模型内部量，不是真实状态标签。
- C11 必须复现原 GRU；GNR 原样参考必须复现既有 GNR。失败即停，不更换索引、source hash 或阈值。
- 温差级数值验证单独注册并保存：不只比较约 500°C 的绝对输出。若使用更高精度，应原样保存 float32 结果与差异，不把新精度偷偷变为旧成绩。
- 此阶段没有“幅值越大越好”的通过门。任何负向/非零都不构成现场增益校准；未恢复也如实保存，不自动触发 B/C。

注册已固定差分重放工程门 atol=1e-4°C、rtol=1e-4，原绝对输出重放沿用1e-5/1e-5。必须同时报告实测最大误差；该工程门不是微小灰箱现场增益精度认证，不在本包混入新精度或步长搜索。
