## 一、模型结构：4 状态非线性系统

### 1.1 状态变量

| 状态 | 符号 | 物理含义 |
|---|---|---|
| x₁ | rB | 炉膛内燃料量 (kg/s) — 制粉动态 |
| x₂ | pm | 汽水分离器出口蒸汽压力 (MPa) |
| x₃ | hm | 汽水分离器出口蒸汽焓值 (kJ/kg) |
| x₄ | Tj₁ | 受热管出口金属温度 (°C) |

### 1.2 输入

| u₁ | uB | 燃料量指令 (kg/s) |
| u₂ | Dfw | 给水流量 (kg/s) |
| u₃ | ut | 汽轮机调门开度 (0-1) |

### 1.3 输出

| y₁ | pst | 主蒸汽压力 (MPa) = pm − Δp |
| y₂ | hm | 分离器焓值 |
| y₃ | Ne | 发电功率 (MW) |

## 二、完整状态方程（原文 Eq. 27）

### 制粉系统
```
dx₁/dt = −(1/c₀)·x₁ + (e^{-τs}/c₀)·u₁
```
c₀ = 121s（研磨惯性时间），τ = 167s（纯滞后）

### 分离器压力
```
dx₂/dt = [(hfw − d₁)/c₁]·u₂
       + [(d₁ − λ·x₃)/c₁]·f(x₂ − g(x₂), λ·x₃)·u₃
       + [k₁·(x₄ − Tst)·fⁿ(x₂ − g(x₂), λ·x₃)/c₁]·u₃ⁿ
```

### 分离器焓值
```
dx₃/dt = [(hfw − d₂)/c₂]·u₂
       + [(d₂ − λ·x₃)/c₂]·f(x₂ − g(x₂), λ·x₃)·u₃
       + [k₁·(x₄ − Tst)·fⁿ(x₂ − g(x₂), λ·x₃)/c₂]·u₃ⁿ
```

### 金属温度
```
dx₄/dt = (k₀/c₃)·x₁
       − [k₁·(x₄ − Tst)·fⁿ(x₂ − g(x₂), λ·x₃)/c₃]·u₃ⁿ
```

### 输出方程
```
y₁ = x₂ − g(x₂)                          # pst = pm − Δp(pm)
y₂ = x₃                                  # hm
y₃ = k₂·(λ·x₃ − hfw)·f(x₂−g(x₂), λ·x₃)·u₃   # Ne
```

## 三、关键物理函数（从 1000MW 机组数据辨识）

### Δp 函数（过热器压降）
```
Δp = g(pm) = 0.04·pm^{1.065}
```

### 蒸汽流量函数（调门特性）
```
Dst = f(pst, hst)·ut
f(pst, hst) ≈ 5145·pst^(−0.743)·(−854 + 13.47·pst + 0.4·hst − 0.003·pst·hst)
```

旧版把乘法、压力幂和括号误抄成了 `5145.854 + ...`；实现前必须再按原文公式与单位表做回归测试，不能直接复制本文常数到伊敏机组。

### 传热量（金属 → 蒸汽）
```
Q₂ = k₁·Dstⁿ·(Tj − Tst)     其中 n ≈ 0.757
k₁ = 5198.755（从稳态数据回归）
Tst ≈ 586.94°C（近似常数）
```

### 燃料发热量
```
Q₁ = k₀·rB
k₀ = 1.948·rB² − 364.56·rB + 32500  （负荷相关）
```

### 给水焓值（负荷相关）
```
hfw = 575.276·pm^{0.24566}
```

### 汽轮机增益（负荷相关）
```
k₂ = 0.0003638·pm^{0.153246}
```

### 过热器焓升比
```
λ = hst/hm = 1.2886  （600-872MW 范围内近似常数）
```

## 六、与 thermal-world-model 的精确对照

### 6.1 状态对应

| Fan 2017 状态 | 伊敏 40 列数据 |
|---|---|
| pm（分离器压力） | 有 `分离器出口压力` 候选列；单位和测点仍需核实 |
| hm（分离器焓值） | 需从 T_m, p_m 反推 |
| rB（燃烧/煤流量状态） | 给煤量列仅是候选代理；与 `uB` 不等价，需辨识制粉滞后 |
| Tj（金属温度） | 当前未观测的 latent state；不能假设有同位置管壁温度测点 |

### 6.2 可直接借鉴的结构

1. **四状态非线性状态空间**：`dx/dt = A(x) + B(x)·u`，A 和 B 都是状态的函数。这比线性状态空间强得多。

2. **物理函数的负荷调度**：k₀(rB)、k₂(pm)、hfw(pm) 都是二次或幂律函数——**不是纯数据驱动，而是先做非线性回归得到解析形式，再嵌入模型**。

3. **参数的物理可解释性**：`c₁/c₂/c₃` 参与压力、焓和金属蓄热方程，但其可解释性依赖单位、状态缩放和耦合；应通过局部线性化和可辨识性分析，而不是直接比较数值。

### 6.3 物理分支升级路线（基于原文）

```
当前 A1phys:   g(x,a) = K(x)/(τs+1) × a               （一阶惯性，标量增益）

Fan 2017:      dx/dt = A(x) + B(x)·u                   （4 状态非线性 ODE）

中间方案:      g(x,a) = MLP_phys(x) ⊙ [Fan_structure]  （用神经网络学习 Fan 模型中的
                                                         d₁, d₂, k₀, k₁, λ 等参数，
                                                        但保持状态方程结构）
```

### 6.4 关键差异：输入层级与输出对象不同

Fan 2017 明确需要三条输入轨迹 `uB`、`Dfw`、`ut`，并预测 CCS 的压力、焓和功率相关输出；它不直接建模 SST 或喷水。当前 A1phys 的 `a=ΔSP` 位于监督控制层，Fan 输入位于 plant/CCS 边界，二者 estimand 不同。

因此不能把 Fan17 写成“不需要动作的 free path”。Phase 4 的保守用法是：

- 以 Fan20 作为 SST plant 主干；
- Fan20 已有制粉迟延/惯性，只把 Fan17 的**显式金属蓄热状态**作为可开关候选，并重推分段能量方程以避免双计；
- 通过显式 controller/actuator 模型把 supervisory ΔSP 接到阀位/喷水；
- 在相同 plant action 定义下做组件消融，不把不同输入层级放在同一排行榜。
