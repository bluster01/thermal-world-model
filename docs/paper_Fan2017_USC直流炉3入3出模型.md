# Fan et al. (2017) — USC 直流炉 3 入 3 出动态模型

> Fan H, Zhang YF, Su ZG, Wang B. "A dynamic mathematical model of an ultra-supercritical coal fired once-through boiler-turbine unit." *Applied Energy*, 2017, 189, 654–666.（97 引用）
> DOI: 10.1016/j.apenergy.2016.11.074

---

## 一、定位：系列开篇

这是 Fan 课题组三篇系列论文的**第一篇**，首次建立了完整的 USC 直流炉机理模型。2020 和 2021 版都是在此基础上的扩展。

**适用条件**：超超临界、干态运行（dry operating conditions）。

---

## 二、模型输入/输出

### 输入（控制量）
| 符号 | 含义 | 执行机构 |
|---|---|---|
| u_B | 燃料量 | 给煤机转速 |
| D_fw | 给水流量 | 给水泵转速 |
| u_T | 汽轮机调门开度 | 调门液压执行器 |

### 输出（被控量）
| 符号 | 含义 | 单位 |
|---|---|---|
| N_E | 发电功率 | MW |
| p_st | 主蒸汽压力（汽轮机入口） | MPa |
| h_m | 汽水分离器出口焓值（中间点焓值） | kJ/kg |

### 为什么选这三个输出
- **N_E**：电网调度指令直接需求
- **p_st**：机组安全边界，超压危险
- **h_m**：中间点焓值是直流炉特有的关键状态——它反映水冷壁出口的工质状态，是"微过热"控制的依据。h_m 过低→水冷壁出口带水→汽轮机水冲击；h_m 过高→管壁超温

## 三、模型结构

### 3.1 物理分段
```
给水 → [省煤器] → [水冷壁] → [汽水分离器] → [过热器] → [汽轮机]
  D_fw              ↓            ↓  (h_m 在此)        ↓           ↓
                   吸热Q_B      相变完成              再热        p_st, N_E
```

关键假设：
- 省煤器和水冷壁合并建模（简化为一个加热段）
- 过热器作为独立容积环节
- **集总参数法**：每个换热段只用一个温度/压力/焓值代表

### 3.2 核心方程（简化的物理逻辑）

**水冷壁质量守恒**：
```
d(ρ_m·V_ww)/dt = D_fw - D_sh_in
```

**水冷壁能量守恒**：
```
d(ρ_m·V_ww·h_m)/dt = D_fw·h_fw - D_sh_in·h_m + Q_B
```
其中 Q_B ∝ u_B · η_boiler（燃料量 × 锅炉效率）

**过热器质量守恒**：
```
d(ρ_st·V_sh)/dt = D_sh_in - D_st
```

**过热器能量守恒**：
```
d(ρ_st·V_sh·h_st)/dt = D_sh_in·h_m - D_st·h_st + Q_SH
```

**汽轮机功率**：
```
N_E = η_turb · D_st · (h_st - h_exhaust)
```

**调门流量方程**：
```
D_st = u_T · f(p_st)   （调门开度 × 压力-流量特性）
```

### 3.3 参数辨识

物性参数（ρ, h 对 p 和 T 的偏导数）从水蒸气表拟合得到。经验参数（传热系数、阻力系数）通过运行数据的非线性回归 + 优化算法辨识。

## 四、与 2020 版的对比

| 维度 | 2017 | 2020 |
|---|---|---|
| 输出数量 | 3（N_E, p_st, h_m） | 3（N_E, p_st, T_st）或 4 |
| SST 建模 | **无** | **有**（喷水 + 给水双重调节） |
| 中间点变量 | h_m（焓值） | 保留 h_m 但焦点移到 T_st |
| 应用场景 | CCS 仿真和控制算法测试 | CCS + SST 联合仿真 |
| 复杂度 | 较简洁 | 增加了喷水支路和 SST 物性耦合 |

2017 版更**干净**——如果你要提取状态空间结构作为物理分支的骨架，从这篇入手比 2020 容易。变量少一个（无 T_st），方程更紧凑。

## 五、对 thermal-world-model 的启发

1. **状态空间骨架**：2017 的 3 状态模型（N_E, p_st, h_m）可以直接写成 `dx/dt = f(x, u)` 的形式，是物理分支升级的起点
2. **h_m 是关键**：你 40 列数据中如果能找到或计算出分离器出口焓值，就能建立类似的三状态物理约束
3. **三个时间尺度**：u_T（秒级）→ N_E/p_st；D_fw（分钟级）→ h_m/p_st；u_B（分钟级）→ 全局。这种多时间尺度结构天然适合 Multi-scale 建模
4. **可微分实现**：守恒方程中的偏导数 ∂ρ/∂p, ∂ρ/∂h 可从水蒸气表（IAPWS-IF97）的解析近似中获取，整个模型可端到端微分
