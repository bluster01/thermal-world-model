> 归档时间: 2026-08-09

## 归档论文

### 1. 曹振乾, 印江, 张津华. 基于改进粒子群算法的主蒸汽温度系统辨识[J]. 系统仿真学报, 2021, 33(10): 2411-2419.
- **文件**: `docs/papers/cao2021_msts_pso_identification.pdf` (9页, 完整)
- **DOI**: 10.16182/j.issn1004731x.joss.20-0609
- **对象**: 山西某电厂 350MW CFB 锅炉, 第三级左侧喷水减温
- **核心方法**: 直接闭环辨识 (无需开环扰动试验) + 改进PSO(收缩因子) 最小化
  Q = Σ[ŷ(kT)−y(kT)]²
- **模型结构**: 传递函数 G(s) = K·e^(−τs)/(Ts+1)^n, 大惯性大迟延有自平衡对象 n=1
- **分段**: 导前区 W2(s) = 阀门开度→减温器出口温度θ2; 惰性区 W1(s) = θ2→主蒸汽温度θ1
- **数据**: DCS 3s 采样 6000 点, 前 3000 辨识后 3000 验证; 预处理 = 滤波去漂移 + 零初始值
- **参数区间**: K1,K2 ∈ [−20,20]; T1 ∈ [5,10]s(导前快), T2 ∈ [50,100]s(惰性慢); τ 区间寻优
- **结论**: 辨识模型与实际曲线基本吻合, 验证有效
- **对我们**: 提供了导前/惰性分段的完整操作规范; 闭环数据直接辨识是行业标准做法

### 2. Luca Brolese. Steam Temperature Control System for a Water Tube Boiler[D]. Politecnico di Milano, 2022.
- **文件**: 全文缓存 `~/.hermes/cache/web/www.politesi.polimi.it-51c9e3b308.md`
  (PDF 下载被 Cloudflare 拦截, 已用 web_extract 提取全文)
- **对象**: BONO 水管锅炉 4 种构型 (单/双过热器 × 喷水/面式减温器)
- **核心物理**: 喷水减温器是**代数混合块** (无自身动态):
  T_sout = α·T_sin + (1−α)·(c_w/c_s)·T_w
  K_ATTSPR = q_sin/(q_sin+q_w)² · (T_w·c_w/c_s − T_sin)  (**负增益**, 喷水→降温)
- **动态来源**: 减温器动态由阀门低通滤波 1/(1+sτ) 施加, τ=1s (T_settle=5s)
- **惰性区** (过热器): FOPDT, τ_outer≈150s/5=30s, k_outer≈0.5 (温度比例)
- **阶跃辨识法**: 稳态后施加 +1%~+5% 阶跃 → k=g2/g1, τ=settlement/5
- **对我们**: 减温器本身无动态是重要物理先验 — 导前区 τ 应小 (秒~数十秒量级);
  惰性区 T 是主导时标 (30s+)

## 方法学要点 (与我的旧方法对比)

| 维度 | 旧方法 (事件方向率) | 论文方法 (FOPDT 分段辨识) |
|---|---|---|
| 模型 | 无参数, 仅符号判断 | K/T/τ 三参数传递函数 |
| 时标 | 固定 600s 窗口 | 参数化: 导前区快/惰性区慢 自动拟合 |
| 数据 | 只取阶跃事件 | 闭环运行数据直接辨识 (无需事件) |
| 物理先验 | 无 | 减温器=代数混合 (负增益), 动态在金属蓄热 |
| 输出 | 方向率 (0-100%) | 增益符号+幅度+时滞+时间常数 (可工程验证) |

## 对伊敏数据的映射

```
物理链 (交叉布置, 用户确认: 左=A, 右=B, A阀→B侧温):
  A阀位 → 右二过喷水减温器出口 (导前区 W2, 快) → 右末级过热器出口汽温 (惰性区 W1, 慢)
  B阀位 → 左二过喷水减温器出口 (导前区)        → 左末级过热器出口汽温 (惰性区)

数据列 (all_merged_10s.csv):
  导前区输入: 过热器二级减温器A/B侧喷水调节门阀位反馈
  导前区输出: 选择后右侧/左侧二过喷水减温器出口
  惰性区输出: 选择后右侧/左侧末级过热器出口汽温
  中间设定:   过热器二级减温器A/B喷水调节阀设定 (温度SP, 560-571°C)
```

## 下一步实现 (seg_ident2)

1. **导前区 FOPDT**: A阀阶跃 → 右二过出口; B阀阶跃 → 左二过出口 (交叉配对)

2. **惰性区 FOPDT**: 右二过出口扰动 → 右末过; 左二过出口 → 左末过
   - 用全时段闭环数据直接辨识 (论文方法, 非仅事件)
3. **对照**: 同数据同代码对非交叉配对 (A→左, B→右) 重复, 比较拟合优度/增益合理性
