# Phase 3.5 审计回应④：SP 事件模型对照实验（2026-08-09）

> 回应问题：A1phys "100% 方向正确"的结论能否保持？
> 实验：在 SP 干预事件（60sV 层，A train+val，n=45）上喂 logged valve 给模型，
> 对比模型预测方向/幅度 vs 经验响应。
> 判决：**方向同向（82-89% vs 73%），幅度差 ~70 倍（中位 0.05°C vs 3.53°C）——
> "方向正确"只能保持为符号约束，不能升级为"模型复现了物理响应"。**

## 1. 动机

42-run 重跑显示模型方向率 1.000（A）/0.992（B），但该数字是 A1Phys 架构符号约束
（constant-valve 零干预 + 长期开阀增益非正）的必然产物，不是学习证据。审计 §4 原话：
"证明符号约束/pilot 信号在修复后仍存在，不是独立物理验证"。

要检验"模型是否复现了观测物理响应"，正确姿势是在**方向干净的事件通道**（SP 干预）
上做对照：SP 事件方向率 73-83%（数据真实值基础），模型若真的学到了响应，应同量级。

## 2. 实验设置

- 事件：SP 事件 60sV 层（60s 严格 + 一级阀≤1%），剔除 |ΔSP|>3°C 大突变
- split：A train+validation（排除 test 52 个，审计 P0-2 要求），n=45（train 44 + val 1）
- 模型：A_absolute_identity_s0 checkpoint（validation 预测最优）
- 输入：事件窗口 logged valve 轨迹（extract_windows，window=96/horizon=60，10s cache）
- 模型输出：干预分支 effect（constant-valve 反事实温度增量）
- 经验参照：1s 数据 SP 阶跃后 600s 温度变化（dT_post_600）

## 3. 结果

| 指标 | 数值 |
|---|---|
| 经验方向率（SP vs ΔT600） | 73.3%（33/45） |
| 模型方向率 @h6 | 88.9%（40/45） |
| 模型方向率 @h18 | 88.9%（40/45） |
| 模型方向率 @h30 | 82.2%（37/45） |
| 模型方向率 @h60 | 82.2%（37/45） |
| 模型效应幅度 \|effect@h60\| | 均值 0.253°C / **中位 0.051°C** |
| 经验响应幅度 \|ΔT600\| | 均值 **3.53°C** |

## 4. 解读

**方向层面**：模型与经验同向（82-89% vs 73.3%），未出现反向。但此一致性
仍可由符号约束解释（SP↑→阀位↓→模型输出温度↑），不能独立证明学习成功。

**幅度层面**：模型效应中位 0.05°C vs 经验 3.53°C，**差 ~70 倍**。
模型方向对但剂量几乎为零——与 G3 参数塌缩（gain near-zero 50-80%、τ 推上界
1070-1190s）和 exp_201 under-gain（λ=0.15 校准 ×60 才达 ~80% 真值）三方一致。

**判决**：A1phys "100% 方向正确"只能保持为**符号约束保持**；
不能写作"模型复现了观测物理响应"。若模型真正学到 SP 干预响应，
效应幅度应与观测同量级（~3.5°C），现状差 70 倍证明干预分支实质塌缩。

## 5. 对 gate 账本的影响

无变化：E3 FAIL（方向率 0.32/0.06 < 0.60）、E4 BLOCKED、E5 INCONCLUSIVE、
G3 FAIL（参数塌缩）、G4/G5 HOLD。本实验不产生新候选，不打开 test。

可发表的表述上限："模型在符号层面与观测一致，但 plant-level gain 在
观测闭环数据中不可辨识（干预分支参数塌缩 + 效应幅度较观测低 ~70 倍）"。
