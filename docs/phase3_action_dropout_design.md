# 实验设计稿：ΔSP 动作通道强化训练 (exp_098, 2026-08-05)

> 背景: exp_097 诊断 — M5-DSP 对 ΔSP 扰动响应仅 0.05°C (物理杠杆 ~0.63°C/°C@180s 的 2.7%),
> 方向正确率大动作层 59%≈随机。原因: 状态捷径 — 模型用状态预测温度轨迹 (MAE 0.30°C 已够好),
> ΔSP 响应是小修正项, MSE 梯度小, 动作编码器权重未被逼出。
> 物理基准 (exp_093, 另一台机): SP 通道杠杆≈1 (600s 跟随率 92%, 时标 240s) → 180s ≈63%。

## 实验: 动作 dropout 训练 (action masking)

### 动机
训练时随机把 ΔSP 动作序列整序列置零 → 模型必须同时学会两条路径:
- ΔSP=0 时: 纯状态驱动的温度基线
- ΔSP=real 时: 基线 + ΔSP 引起的增量
迫使动作编码器编码"ΔSP→温度"增益, 消除状态捷径。

### 协议 (同 exp_096, 仅训练输入改动)
- 结构: M5DSP (DirectWM 确定性, RevIN+PerVarTCN+VarAttn, 动作编码器 1维 ΔSP)
- 数据: 同 exp_025 (train 495407 / test 106159, 10s)
- 训练: MSE, 100 epoch, LR 1e-3, WD 1e-5, BS 256, Adam
- **改动**: 每 batch 以 P=0.4 概率将整条 ΔSP 动作序列置零 (非逐元素)
- 保存 best test MAE checkpoint + metrics.json

### 评测 (训练后自动跑, 同 exp_097 事件集 134)
1. **动作增益测试 (新增, 判定核心)**: 134 事件, pred(真实ΔSP) vs pred(ΔSP=0) 的末点温差
   - 响应幅度 mean (物理基准: 1.31°C = 0.63°C/°C × 2.07°C)
   - 响应方向正确率 sign(响应)==sign(ΔSP)
2. 原指标: 全事件/分层 MAE、方向正确率 (对比 exp_097 基线 0.301/87%)

### 判定标准
- **PASS (学到增益)**: 响应幅度 ≥ 0.40°C (物理的 ~30%) 且方向正确率 ≥ 80%
- **GOOD**: 响应幅度 ≥ 0.65°C (物理的 ~50%)
- **FAIL**: 响应 < 0.40°C → 加 B 方案 (exp_093 杠杆物理校准叠加, 灰盒)
- 回归检查: 全事件 MAE 不劣于 exp_097 (≤ +0.05°C, 确保 dropout 未伤预测精度)

### 风险
- dropout 可能降低 MAE (训练噪声) → 回归检查线已设
- 共因混杂无法完全消除 → 模型学到的是条件均值差, 仍可能低于物理杠杆;
  这是客观限制, FAIL 时如实报告并走 B, 不硬撑
- 单 seed (与 exp_096 一致)
