## 0. 设计原则

1. **公平对比**: 同一协议、同一轨迹集、多 seed, 严禁 "先定结论再设计协议"
2. **综合指标**: 不只看 RMSE — 加入超温时间、超温积分、综合代价 J_total
3. **机制验证**: 不只看数字 — 每个结论必须有机制解释 + 验证实验
4. **诚实边界**: 主动测试自己结论的失效条件

## 1. 核心实验: M5 vs M7 公平重判 (推翻循环论证)

### 问题
exp_094 的 M5 切换依据是 RMSE-only 成本下 M5 优于 M7 — 这是循环论证 (先决定不用 σ, 再发现不带 σ 的模型更好)。

### 实验 S1: 多成本函数 × 多 seed × M5 vs M7 全面对比

**协议**:
- 模型: M5 (MSE) 和 M7 (β-NLL), 各训练 3 seed (42/7/13)
- 成本函数: 4 种
  - (a) RMSE-only (L1=L2=0, 当前定稿)
  - (b) RMSE + 超温惩罚 (W_OVER=5.0, 超温区 575+ 重罚)
  - (c) RMSE + CVaR 风险 (RISK_LAMBDA=2, RISK_SIGMA_ADD=0.69, 仅 M7 有 σ)
  - (d) 综合代价 J_total = RMSE + 0.1·超温积分 + 0.01·TV (工程实际关心的多目标)
- 评测: 150 轨迹 × 3 起点集, 扰动 DIST_AMP=0.3, H_PLAN=10, M_STEP=6, hard5
- 指标: RMSE / 超温时间(s) / 超温积分 / TV / J_total / 配对 Wilcoxon

**预期结果与解读**:
| 成本 | 预期胜者 | 解读 |
|------|---------|------|
| (a) RMSE-only | M5 可能胜 | 当前结论, 但不代表 M5 更好 — 只是 σ 没用武之地 |
| (b) RMSE+超温 | M7 应胜 | σ 提供超温预警 → 1s vs 110s |
| (c) RMSE+CVaR | M7 应胜 | CVaR 主动压超温, M5 无 σ 无法用 |
| (d) 综合代价 | M7 应胜 | 超温权重使综合指标偏向 M7 |

**判定标准**:
- 如果 M7 在 (b)(c)(d) 中胜出 → M5 切换是循环论证, M7 恢复为主模型
- 如果 M5 在所有成本函数下都胜 → 确实 M5 更优, 但需要解释超温 110s vs 1s 的安全代价
- 如果 M7 仅在 (c) 胜 → 概率 WM 的价值仅在风险规划, 论文叙事需调整

**关键**: 成本函数 (d) 的权重 [0.1, 0.01] 应来自工程实际, 不是调出来的。火电主汽温超温 1°C·10s 的代价 ≈ RMSE 增加 0.1°C 的代价 (经验值, 可标注)。

### 实验 S1b: M5 借用 M7 σ 的混合方案

**动机**: 如果 M5 均值更准但缺 σ, 能否用 M5 的 μ + M7 的 σ?

**协议**:
- 推理时: μ = M5(x), σ = M7(x) — 两个模型分别提供均值和不确定性
- 成本函数: (c) RMSE + CVaR(用 M7 的 σ)
- 评测: 同 S1

**判定**:
- 如果 M5μ+M7σ 优于纯 M7 → "确定性均值 + 概率安全感知" 是更优架构
- 如果不优于纯 M7 → M7 的 μ 和 σ 是联合训练的, 拆开用会损失校准

## 2. H_PLAN 定论: 最终协议下 H=10 vs 18

### 实验 S2: 最终协议 H_PLAN 扫描 (150 轨迹 + Wilcoxon)

**协议**:
- 模型: M7 (主线模型, S1 确认后)
- H_PLAN: 6, 10, 14, 18
- 固定: M_STEP=6, DIST_AMP=0.3, hard5, KF+SMA6, 成本函数用 S1 确定的最优
- 评测: 150 轨迹 × 3 起点集, 配对 Wilcoxon
- 指标: RMSE / TV / 超温 / J_total

**判定标准**:
- RMSE 差异 p>0.05 + TV 差异显著 → 选 TV 更低的 (exp_053 逻辑)
- RMSE 差异 p<0.05 → 选 RMSE 更低的
- 超温差异显著 → 超温更低的优先 (安全优先)

**注意**: 这次用 150 轨迹 (vs exp_053 的 10 轨迹), 统计功效大幅提升。如果 150 轨迹下 H=18 RMSE 显著优于 H=10, 则 exp_053 的 "噪声级" 结论被推翻, 可以用 H=18。

## 3. 因果方向边界量化

### 实验 S3: MPC 闭环动作幅度分布 + 翻转阈值扫描

**问题**: §24 说 "MPC 小幅动作不受影响", 但没量化 "小幅" 的边界。

### S3a: MPC 闭环动作统计

**协议**:
- 从 S1/S2 的 150 轨迹 MPC 闭环中提取所有动作
- 统计: 每步 |Δa| 分布, 连续同方向动作长度, 累积动作幅度
- 对比: 首步扰动测试 (±10%, 方向正确) vs 持续阶跃测试 (+10%, 方向翻转) 的边界

**关键指标**:
- P(|Δa| > threshold) — MPC 动作有多大比例超过 "安全幅度"
- 连续同方向动作的累积幅度分布 — 是否进入翻转区

### S3b: 翻转阈值扫描

**协议**:
- 固定一个代表性起点
- 阀位阶跃幅度: +1%, +2%, +3%, +5%, +7%, +10%, +15%, +20%
- 持续保持该阶跃, 测 t12 (120s) 的 ΔT 方向
- 找到方向翻转的临界幅度

**判定**:
- 如果翻转阈值 > +10% → MPC 实际动作 (通常 <5%) 远在安全区, §24 结论成立
- 如果翻转阈值 ≤ +3% → MPC 动作可能进入翻转区, 需要重新评估主结果
- 绘制 "幅度-方向" 相图, 论文可放

## 4. 线性 MPC 崩溃机制验证

### 实验 S4: 线性 MPC 扰动崩溃根因诊断

**问题**: 线性 MPC 无扰动 0.713 (很好), 扰动 5.555 (崩溃 ×7.8)。是模型发散还是规划器选错?

### S4a: 开环预测对比 (M7 vs ARX, 扰动下)

**协议**:
- 取 10 条扰动轨迹
- 每步记录: M7 预测 μ vs ARX 预测 vs 真实温度 (含扰动)
- 统计: 逐步预测误差分布, 预测发散起点

**判定**:
- 如果 ARX 预测本身发散 (误差累积放大) → 模型问题, 线性近似在扰动下失效
- 如果 ARX 预测还行但规划器选了坏动作 → 规划器问题, 需要检查 MPC 框架

### S4b: 线性 MPC 加 offset-free 补偿

**协议**:
- 线性 MPC 加 EMA 偏差补偿 (同 exp_027 的 OFFSET_GAIN 机制)
- 重新评测 150 轨迹扰动

**判定**:
- 如果加补偿后线性 MPC 显著改善 (如 5.555→3.0) → 崩溃部分是可补偿的偏差, 不是线性模型根本缺陷
- 如果改善有限 → 线性模型确实在扰动下有结构性局限
- **论文诚实性**: 如果改善后线性 MPC 变强, 主结果 "深度 WM 优势" 数字要更新, 但故事不变 (非线性仍然更优)

## 6. 扰动谱敏感性

### 实验 S6: 多扰动谱主协议评测

**问题**: 当前仅测 σ0.3 自相关 0.9 随机游走 (低频), 高频/大幅未测。

**协议**:
- 扰动谱: 4 种
  - (a) σ=0.3, ρ=0.9 (当前, 低频随机游走)
  - (b) σ=0.3, ρ=0.0 (白噪声, 高频)
  - (c) σ=0.8, ρ=0.9 (大幅低频)
  - (d) σ=0.8, ρ=0.0 (大幅高频)
- 模型: M7 (主线) + PID + 线性 MPC
- 评测: 50 轨迹 × seed 42, 成本函数用 S1 确定的最优
- 指标: RMSE / 超温 / J_total

**判定**:
- 如果 M7 在所有扰动谱下优于 PID → "扰动鲁棒性" 结论稳健
- 如果 M7 在高频扰动下优势消失 → 诚实报告边界条件
- 如果线性 MPC 在某些扰动谱下不崩溃 → 诚实报告 (线性模型不是所有情况都崩)

## 9. 论文叙事线 (S1 结果驱动)

### 如果 S1 确认 M7 胜出 (预期):

> **主贡献**: 概率世界模型实现火电主汽温的精准控制 + 超温安全感知
> - 精度: M7+MPC 扰动 RMSE 显著优于 PID (p<1e-10)
> - 安全: M7 超温 1s vs PID 289s vs 线性 MPC 1682s — σ 提供风险感知
> - 鲁棒: 扰动下线性 MPC 崩溃, 深度 WM 保持 (S4 验证机制)
> - 因果: 首步扰动方向正确, 持续阶跃有边界 (S3 量化)
> - 诚实: RL 策略扰动下失效 (S5 公平验证), 高频扰动边界 (S6)

### 如果 S1 确认 M5 胜出 (意外):

> **主贡献**: 深度世界模型的扰动鲁棒性 — 确定性 WM + MPC vs 传统方法
> - M5 为主模型, M7 的 σ 用于安全扩展 (z-score 检测 + CVaR)
> - 需要解释: 为什么 β-NLL 在 MPC 闭环下不如 MSE
> - 超温故事弱化 (M5 110s vs PID 289s, 仍优但不如 M7 的 1s)

### 如果 S1b (M5μ+M7σ) 胜出:

> **主贡献**: 解耦均值-不确定性的世界模型控制架构
> - 确定性模型提供精准均值, 概率模型提供安全感知
> - 新颖性最高, 但需要更多验证
