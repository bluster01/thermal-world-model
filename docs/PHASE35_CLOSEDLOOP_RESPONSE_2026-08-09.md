# 物理闭环响应基准 — SP 外生干预 (2026-08-09)

> 核心目标 (用户定案): 交叉喷水结论不再验证 (A→右, B→左); 解决物理闭环响应识别。
> 方法: 串级结构 (SP→主调PI→r2→副调PI→阀位→喷水→T2→Tm), SP 为唯一外生干预源。
> 数据: all_merged_10s.csv, SP held-step 事件 (|ΔSP|≥1.5°C + 前300s安静 + 后600s保持)。

## 1. 核心结果: SP 干预 → 温度的物理闭环响应 (E3 的答案)

| 通道 | 响应 | 30s 方向率 | 60-120s 方向率 | FOPDT (up/down) |
|---|---|---|---|---|
| A→右 | T2 (导前) | **80.1%** | 78.5% | K=+0.80, T=5.8s, τ=1.5s, R²=0.41 |
| | Tm (惰性) | 76.6% | **80.7-83.5%** | up: K=+2.54 **R²=0.89**; down: K=-2.44 **R²=0.75** |
| B→左 | T2 | **71.3%** | 69.9% | K=+0.40, T=1.0s, τ=1.8s |
| | Tm | 73.8% | **82.2-85.9%** | up: K=+2.40 **R²=0.96**; down: K=-2.62 **R²=0.78** |

- **方向链成立**: SP↑→T2↑→Tm↑ (方向率 70-86%, 分方向 FOPDT R²=0.75-0.96)
- **双向响应**: up K>0 / down K<0 符号正确
- **时标分离**: 导前区 τ≈1.5-2s, T≈1-6s; 惰性区 τ≈5-19s, T≈9-25s
- **跨块稳健**: dev(231/342)/val(46/65)/rob(44/25) 方向率全部 70-88%

## 3. 阀位内生性坐实

- SP↑→阀位↓ 反向率 **81.3% (A) / 86.1% (B)** — 阀位是 PID 对 SP 的响应, 非外生动作
- 这解释了为何阀位事件方向率 45-55% (5D) 而 SP 事件 70-86%

## 4. 关键混杂: 双侧 SP 联动

- A 事件中另一侧 SP 变化中位 **2.0°C** (比 A 自身 1.5°C 还大); 仅 6.2% 事件另一侧安静
- B 侧: 3.9% 事件另一侧安静
- **含义**: 方向率 (双侧效应叠加) 可靠; 单侧配对面积被联动污染
- 互斥子集 (另一侧≤0.3°C): A=20, B=17 — n 不足, drop 方向率噪声主导 (35-41%),
  Tm 方向仍交叉侧占优 (70%/59% vs 50%/53%) — 仅 exploratory
- **单侧归因的干净验证需现场预注册单侧试验**

## 5. 串级结构验证

- 主调输出 ↔ 二过出口温度 r=+0.989 → 主调输出即副调设定 (二过温度设定)
- SP↔主调差分 r=+0.187@0s → 主调即时响应 SP
- PI 参数全时段拟合 R²≈0 → 闭环误差无激励, PI 不可直接辨识 (经典闭环辨识限制)

## 6. 结论与边界

**结论**: SP 外生干预 → 温度响应可识别: 方向率 70-86%, 双向充足, 110+/日块,
跨 dev/val/rob 稳健。这是当前最强的物理闭环响应基准, 替代不可识别的阀位事件通道。

**边界**:
1. 这是**闭环响应** (含控制器), 不是开环 plant 传递函数 — 反解 plant 需控制器参数
   (闭环误差无激励, 当前数据不可行)
2. 双侧联动使单侧归因仅 exploratory; 严格单侧证据需现场预注册试验
3. 交叉配对 (A→右/B→左) 按用户现场知识定案, 不依赖配对面积检验
