# exp_107 DiD 真值评测复核 + 架构决策 (2026-08-05)

结论: **"B1glb 夺冠 CFI=0.979" 不成立**。换成跨时程聚合评分后排名完全翻转,
冠军是 `A1phys`。且 n_ev=15 下所有排名差异均在噪声内, 当前不能宣布任何冠军。

---

## 1. 致命问题: n_ev = 15

14 个评测条目的 `n_ev` 全为 15。

- `sgn_pair` 分辨率 = 1/15 = 0.067 → 0.87/0.93/0.80 之间只差 1~2 个事件翻转
- `sgn_ceiling` 本身仅 0.60~0.87 (15 事件 split-half 估计), 而
  `sgn_norm = (sgn-0.5)/(ceil-0.5)` 是**两个噪声量相除**。B1glb 在 300/420/600s
  拿 `sgn_norm=1.000` 纯因 `sgn_pair == sgn_ceiling` (都是 0.667) — 天花板塌了, 不是模型好
- `B1flat` 的 `best_mae` 与 `best_causal` 数值完全相同 (同为 ep28) → 两 ckpt 是同一个。
  故 "FlattenHead 不稀释动作, 推翻 doc 假设" 是单 seed + 单 ckpt 巧合, n=15 下不可分辨

**CFI 差 0.006 (0.979 vs 0.973) 是纯噪声。**

冠军模型**前 60s 动作响应符号是反的**, 120-180s 只有真值 1/3, 靠 600s 末点对齐拿满分。
`ttp_err=+6` (27 vs 21 步), `mono 1.69 vs true 1.47` → 学到的是"末点幅度对, 动态过程错"。

## 3. best_causal ckpt 选择 = 在 15 个事件上过拟合

| 变体 | best_mae ep | best_causal ep | MAE 代价 | 180s SGN |
|---|---|---|---|---|
| A1mlp | 5 | 16 | 0.869→0.899 | 0.60→**0.47** (低于随机) |

典型 selection-on-noise: CFI 用的就是评测那 15 个事件, 选择集 = 测试集。
只有 A1phys 系列两 ckpt 方向率一致 — 响应被物理结构约束, 没有自由度过拟合。

## 4. A1 系列 best_mae 都在 ep 2-5

A1* best_mae 在 ep 2~5, B1* 在 ep 28~36。A1 极早收敛后 MAE 不再改善:

- `f_free` 迅速吃掉大部分可预测方差 (SP 可由状态预测) → `g(x,a)` 梯度饥饿
- MAE 与 CFI 明确 trade-off → 两分支**争抢同一份信号**, 残差分解未真正解耦

这是 A1phys gain 卡在 0.65 的根本原因: **free path 提前吸收约 35% 干预效应**。

## 5. 精度: 缺少基线行, 无法定论

MAE 落在 0.843-0.928, 最优 B1glb/best_mae = 0.8428。但表里**没有 M5-DSP / M9DSP /
DirectWM 基线行**。历史 0.349/0.361 是不同口径 (H=18、不同事件集), 不可直接比。

## 6. 代码级 bug

- `exp_107_did_eval.py:91-94` `gt[f'onsets{H // 10}0']` 对 H=18 会取 `onsets10` (不存在);
  与 `exp_108` 的 `gt_key = H` 写法不一致

- `causal_eval.py` 算了 `gain_ceiling` 但 `cfi()` 从未使用。gain 应按 `gain_ceiling` 归一化,
  否则分不清 0.65 是模型欠增益还是 DiD 噪声衰减

# 调整方案

## P1 — 先修度量 (无需重训, CPU 即可)

1. **CFI 改跨时程聚合**: 对 120/180/300/420/600s 求平均, 早期符号翻转加硬惩罚;
   gain 按 `gain_ceiling` 归一化。30s/60s 的 `resp_true` 仅 0.03 (≈噪声底), gain 比值不可用,
   只做符号检查不进分数
2. **每个指标出 bootstrap CI**, 表里不写没有 CI 的数字。n=15 下大概率全部重叠 →
   诚实结论是"不可分辨"
3. **ckpt 选择集与评测集分离**: 用 val 区间 [n_train, n_val_end) 选 ckpt,
   test 区间只用于最终报告

## P2 — 扩样本量 (最高性价比)

- **放宽事件筛选**: `THR_DSP 1.0→0.6`、`SP_HOLD 0.3→0.5`、`LOAD_STABLE 3.0→5.0`,
  ΔSP 幅度改作分层变量而非硬门限 (顺带得到 HET 指标)
- **val+test 合并做评测集** (配合 P1-3)
- **K-fold 时间切分** 3 折滚动, 报告折间方差 — 比多 seed 更能反映真实不确定性

目标 n_ev >= 60, 届时 `sgn_ceiling` 才有意义。

## P3 — 稳定性/可解释性主线: `A1phys`

唯一同时满足 shape=1.00 / ttp_err=0 / mono 匹配 / 增益剖面平坦 / 双 ckpt 一致的变体。
唯一缺陷是统一欠增益 0.65, 三个修法:

- **A. 干预分支优先训练**: 前 N epoch 冻结 `f_free` (或加大其 dropout), 强迫 `g(x,a)`
  先吃动作信号。直接针对"free path 抢信号"根因
- **B. 增益校准损失**: `L_gain = |mean_k[g(x,a)_k] / R_true_k - 1|`, 用 DiD 真值**直接监督
  反事实差**。这是 `g(x,0)≡0` 恒等式带来的独有能力, 别的架构做不到
- **C. 对 `f_free` 屏蔽 SP/ΔSP 输入通道**: 架构上切断 free path 获取动作信息的途径

`A1physcs` (+cumsum) gain 跨度 0.182 为全场最小 → **增量累积输出对剖面平滑有效**,
值得作为 A1phys 默认配置再验。

## P4 — 精度: 补基线, B1glb 只作精度对照

- exp_107 加 **M5-DSP / M9DSP / DirectWM 三行基线**, 同一 DiD 口径与事件集
- B1glb MAE 0.8428 最优但前 60s 符号反、gain 跨度 0.76 → 定位为**精度上界参照**,
  不作因果主线模型
- 既准又因果的候选: **A1phys 的 free 分支换 TimeXer 主干**, 干预分支保留物理结构
  (A3+B1 组合, 未跑过)

**优先级: P1 → P2 → 再决定 P3/P4。** P1/P2 均无需 GPU, 可用现有 14 个 ckpt 重算。

# 四个决策问题的答复

## Q1. phys 用一阶惯性, 真实物理至少三四阶, 有影响么?

先澄清: `InterventionPhysics(n_lag=2)` 是默认值, **现在跑的是二阶** (两级一阶惯性级联)。

用 exp_104 的 DiD 真值 R_true (7 个报告点) 拟合 n_lag=1..5, 每阶自由拟 K 与 tau:

| n_lag | K | tau (步) | RMSE | max err | 30s (真 0.0299) | 60s (真 0.0289) |
|---|---|---|---|---|---|---|
| 1 | 1.409 | 79.7 | 0.0447 | 0.0739 | 0.052 | **0.103 FAIL** |
| **2** | **0.785** | **15.2** | **0.0218** | **0.0316** | 0.019 | 0.057 |
| 3 | 0.717 | 9.0 | 0.0236 | 0.0364 | 0.008 | 0.036 |
| 4 | 0.688 | 6.6 | 0.0309 | 0.0440 | 0.004 | 0.025 |
| 5 | 0.670 | 5.3 | 0.0372 | 0.0574 | 0.003 | 0.018 |

- **n_lag=2 最优, n_lag=3 几乎并列** (0.0218 vs 0.0236, n=15 噪声下不可分辨);
  **n_lag>=4 反而变差**
- **一阶明显不行**, 且错法很具体: 60s 处给 0.103 而真值 0.029 — 一阶无初始零斜率,
  无法表达真值 `30s→60s 平台 (0.0299→0.0289)` 的纯迟延。**级联 2 级即足够复现死区**,
  兑现了 docstring 里"级联得 S 形等效纯迟延, 无需显式 delay 参数"的设计
- **`tau_init=18` (按 exp_099 反推) 实测拟合值 15.17** — 初始化选对了

"真实三四阶"的直觉在本数据上不成立, 原因是**采样率与观测噪声限制了可辨识阶数**:
10s 采样、H=60、n=15 事件、7 个报告点, 分辨不出 3 阶与 4 阶。过参数化的高阶级联只会
引入不可辨识方向 (各级 tau 可互换), 训练更不稳。

**行动项**: 默认值不改, 但把 `n_lag ∈ {1,2,3}` 作为论文消融跑一遍。该消融把"阶数由数据
选出"变成实证结论而非超参拍脑袋, **一阶失败的方式 (初始斜率过大、无死区) 是最好的论据**。

## Q2. 还需要概率预测么? 需要先把 A1phys 优化到最好才能写论文?

### 概率头: 留, 但必须加一个确定性损失的对照

`probabilistic=True` 下 sigma 头只由 free 分支产生, 不影响 `g(x,0)≡0`, 架构上无害。

**但 NLL 损失本身可能就是欠增益 0.65 的元凶之一。** 机制: `SafeBetaNLL` 的
`nll = 0.5*(lv + (tgt-mu)^2/v)` 会对误差大的样本自动降权, 而 SP 阶跃事件恰是误差最大的
样本 → sigma 膨胀 → 这些样本被降权 → **干预分支梯度被系统性削弱**。
这是缺陷4 "梯度饥饿" 的一条额外通路 (原 doc 未记)。`beta=0` 无 beta-NLL 反向补偿,
风险是实打实的。

**行动项**: 加 `--loss {nll,mae,huber}` 开关, 跑 `A1phys x {nll, mae}` 对照。若 MAE 损失下
gain 明显上升, P3 三个修法都可省。**这是当前性价比最高的单点实验** (一个开关, 一次训练)。

论文定位: 不确定性量化是 MPC 下游需求, 加分项非主线。正文用确定性版本做因果主线,
附录给概率版本。

### 论文时序: 不要等 A1phys 调到最好

- **已可发表 (不依赖模型好坏)**: 协议 bug 发现与影响分析 (L0) + DiD 真值方法与主汽温
  干预响应曲线 (L1) + CFE 评测框架 (L2/L3)。Q1 拟合出的 `n_lag=2, tau=15.2, K=0.785`
  本身即可引用的物理辨识结果
- **还不能写**: 架构对比结论。n=15 下无任何可信排名

**正确顺序**: (1) 先做 P1+P2, 仅需 CPU; (2) 同时写方法章节 (L0/L1/L2 框架 +
`g(x,0)≡0` 恒等式推导 + 物理分支形式) — 这部分已冻结, 不因实验结果变化;
(3) P2 出结果后再决定是否投入 P3。

**先写方法、后补实验, 而不是先调模型、后写论文。** 现在优化 A1phys 等于在一个测不准的
指标上做梯度下降。

## Q3. 目前动作都在 TimeXer 基础上, 之前的架构被抛弃了?

否 — 恰恰相反, **A1phys 就长在旧主干上**。见 `causal_arch.py:195-199`:
`ResidualCausalWM` (所有 A1* 变体) 用的编码器是
**RevIN + PatchEmbedding + PerVariableTCN + VariableAttention**, 即 Phase 1 的 M5/M7 主干,
完全不含 TimeXer。docstring 明确写了"保证与 M5/M7-DSP 的编码器同条件, 差异只在动作注入
路径 → 消融可归因"。

只有 `TimeXerCausalWM` (B1glb / B1flat) 是 TimeXer 系, 其存在目的是**当对照组**:
复现 M9DSP 的 FlattenHead vs 强制 GLB 瓶颈, 验证"动作被内生旁路稀释"假设。

准确说法:

- **保留**: Phase 1 编码器 (VarAttn 主干) — A1phys 的骨架
- **换掉的是动作注入方式**: "cat 拼接 / cross-attn 到 glb + 加性残差" → "残差分解 +
  物理结构化干预分支"
- **降级的是 M9DSP 作为主模型的定位** (该结论本就建立在失效的二阶差分数字上)
- **仍需 M5-DSP / M9DSP / DirectWM 作为基线行** (P4), 否则 MAE 0.84 无参照

若要兼顾精度: A1phys 的 `f_free` 换 TimeXer 主干、干预分支保留物理结构 = A3+B1 组合。
**新旧两条线可合并, 不是二选一。**

## Q4. 叙事主体转向物理因果先验?

赞成, 且比原叙事更稳。

原叙事"因果作为世界模型主线"的问题: 论据全是数值指标 (方向 89%、响应比例 0.17),
而这些数字刚因协议 bug 全部作废过一次。**指标驱动的叙事, 指标一动叙事就塌。**

物理先验叙事的论据是**结构性的**, 不依赖某个数字赢多少:

- `g(x,0) ≡ 0` 是架构恒等式 (bias=False + GELU(0)=0), 非正则项非训练结果 — 永远成立
- 干预分支输出 = 反事实差, 可**直接与 DiD 观测真值对齐**, 消灭 objective mismatch
- 一阶惯性级联给出**可读参数** K(x)、tau(x), 可画成负荷的函数与 DiD 分层真值逐箱对比 —
  `physics_params()` 接口已就绪但尚未使用, **这张图是论文最有说服力的一张**
- 响应剖面稳定性 (gain 跨度 0.18-0.32 vs TimeXer 0.76-0.93) 是**先验的必然结果**,
  非调参所得

Q1 的拟合给叙事额外支点: **二阶级联是从观测因果响应中辨识出来的, 不是假设的**。
K=0.785、tau=15.2 步、一阶被数据否决 — 完整闭环:
观测数据 → DiD 因果响应 → 物理阶数辨识 → 架构先验 → 模型响应剖面。

不熟悉控制不影响: 该叙事核心是"世界模型是否满足物理先验"这一可验证性问题, 非控制性能。
MPC 缩为最后一节的下游 demo, 不承担主要论证责任。

**诚实性提醒**: 论文应写"一阶惯性级联的灰箱先验 (gray-box prior)", 不要写"物理模型"。
我们没有能量守恒、没有质量平衡, 只有一个被数据支持的 LTI 结构 + 状态相关参数。
审稿人会抓这个词。
