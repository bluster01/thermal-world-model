## 2. 1c 动作因果敏感性的真实状态（核心缺陷）

### 2.1 已确立的事实

- 绝对阀位 >> 差分阀位（敏感性 ×32–130，exp_012）
- 滞后动作历史 [0,3,6,9]（30-90s）是唯一解锁响应的输入结构（exp_016 全矩阵，L0/L6 均失效）
- 符号正则（单步 ∂T/∂a<0）**是伪物理**：把 120s 滞后压缩成 10s 伪响应，且翻转真实长程降温（事件研究推翻，见 §4）

### 2.2 未证实的关键问题

1. **因果 vs 共因未在模型层面分离**：无正则 L3 的 t1=+0.186 是共因拟合（开阀时温度在升），不是因果。MPC 用 10s 响应决策会得到"开阀升温"的错误指令
2. **长程幅度不足**：无正则 L3 t12=−0.275°C，事件研究真值 120s 趋势校正 −0.59°C——只学到真值幅度的 ~46%，物理量级未学对
3. **评测时标错误**：敏感性一直在 t1/t3（10-30s）上评，物理在 60-120s。exp_012–016 的"敏感性达标"全部建立在错误时标上
4. **训练-物理错配**：K=5 只监督 50s，物理响应在 120s+。训练窗口根本没覆盖响应区（exp_017_B K=12 在验证，但 2026-08-01 才发现）

### 2.3 正确做法（已验证的路径）

- 评测时标：t≥8（80s+），对照事件研究真值曲线（模型响应 vs 数据响应直接对比）
- 正则时标：只约束长程（t≥8），短程自由（exp_017_C 设计）
- 监督时标：K≥12 覆盖 120s（exp_017_B 设计）

## 4. 方法论反思（比技术缺口更重要）

1. **"先数据后模型"铁律被违反**：exp_013→016 符号正则线（5 实验，~3 天算力）建立在"开阀→10s 降温"的错误直觉上。先做事件研究（30 分钟）就能省掉全部 5 个。**物理先验必须来自数据本身（事件研究/互相关），不能来自直觉**
2. **被反直觉结论带偏**：exp_013 "单步内编码预期降温"当时视为洞见，实为模型迎合正则的伪物理。违反 2026-07-31 工作风格警告（不要用自认为有趣的反直觉结论覆盖真实问题）
3. **评测指标自证陷阱**：敏感性只在模型自身上测，无数据真值对照。**模型响应曲线 vs 事件研究响应曲线**的直接对比应成为标准动作
4. **早停/正则生效状态未纳入检查**：exp_015 best@17<warmup20 导致"未受正则的模型"被当成正则结果分析
