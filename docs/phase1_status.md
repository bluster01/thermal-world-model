## 3. 关键结论（论文叙事）

1. **Direct 多步 > 自回归**：免误差累积 + 动作条件化保留 + σ 校准自然正确。自回归滑动窗口（0.767）被全面超越
2. **输入信息量决定精度**：40列 vs 13列 = 0.528 vs 0.789（+49%）。前馈先导变量（AGC/煤量/风量/升速率）是免费预测器
3. **单目标合理**（TD-MPC2 task-oriented 哲学）：只预测主汽温，容量集中，多目标为 future work
4. **有敏感性 ≠ 有物理**：LSTM 敏感性更强但全程共因方向；世界模型的滞后结构学到因果
5. **评测范式必须透明**：Exp-0 是 direct 无累积，自回归模型不能直接比 avg MAE
6. **GRU 判死是评测 bug**：GRU 分支从未被训练（训练走 direct decoder），正确训练后 0.983 可用
7. **物理真值来自事件研究**：开/关阀对称的 60-90s+ 大滞后；符号正则（单步/长程）都与数据统计冲突，换监督信号才是正路

## 4. 方法论教训（保留）

1. 先数据后模型：事件研究（30min）应先于任何物理先验约束设计（exp_013-016 的 3 天算力白费）
2. 反直觉结论先怀疑自己的代码：GRU 死亡、符号正则修正方向，两个都是假结论
3. 评测指标要对照数据真值：模型响应 vs 事件研究曲线的直接对比成为标准动作
4. 多 decoder 路径必须验证每条都受过梯度：exp_002-010 GRU 评测的教训
