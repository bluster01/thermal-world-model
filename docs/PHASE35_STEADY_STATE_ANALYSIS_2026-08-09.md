# Phase 3.5 稳态层修正分析（2026-08-09）

> **状态：探索性分层记录。** 60/180 s 阈值与交集来自同一批数据的结果后筛选，不是独立
> cross-validation；全量统计还包含已暴露的 event test。正式证据须在冻结规则后使用新时间块。

## 背景

审计 §10-1 曾得出"1s 数据 365 个 SP 事件中严格稳态 S 层 n=1——稳态事件在伊敏数据上不存在"。
本次分析验证该结论的成立范围，发现：**"不存在"是 600s 前窗+残缺协变量条件下的产物，
修正定义后可获得可用的稳态层样本**。

## 事件数据

- 来源：6.6G 秒级 CSV（7000 万行，2025-12-23~2026-03-15）
- SP 阶跃检测：|ΔSP|≥1.0°C + 60s 保持 + 600s 最小间隔 → 365 个候选
- 事件前窗口 range：60s / 180s / 600s / 960s 四档（负荷/压力/温度）
- 事件后响应窗口：600s

## 关键发现 1：600s 前窗的瓶颈不是温度，是压力

600s 窗口下单项门槛通过数：负荷≤5MW 过 26、压力≤0.2MPa 过 **5**、温度≤1°C 过 6。
中位数：负荷 17.2MW、压力 0.838MPa、温度 3.86°C——**三个变量中位数全部超标 3-4 倍**，
但压力最紧。只放松温度（到 8°C）联合也仅 n=5，瓶颈在压力。

## 关键发现 2：窗口缩短是主杠杆

| 前窗 | 门槛(负荷/压/温) | n |
|---|---|---|
| 600s | 5/0.2/1 | 1 |
| 180s | 5/0.2/1 | 38 |
| 180s | 10/0.5/2 | 133 |
| 60s | 5/0.2/1 | 170 |

60s 内温度 range 中位数仅 0.53°C——"温度波动大"是 600s 尺度现象，60s 尺度不存在。

## 关键发现 3：协变量污染——一级减温阀是主要污染源

S 层定义（审计 §P2）要求"无同期大幅煤量、给水、其他阀门或控制模式切换"，
但 sp_events_1s.py 只实现了负荷/压力/温度三项。补算 6 个协变量 60s/180s range 后：

| 条件 | n | 方向率(SP→阀位异号) |
|---|---|---|
| 180s中等(10/0.5/2) 基准 | 133 | 66.9% |
| +煤量≤20 | 126 | 65.9%（无影响） |
| +给水≤100 | 133 | 66.9%（无影响） |
| +AGC≤10 | 119 | 66.4%（无影响） |
| **+一级阀≤2%** | **39** | **76.9%** |
| **+一级阀≤1%** | **15** | **100%** |
| +二级中间设定≤2°C | 52 | 73.1% |

物理解释：一级/二级减温回路耦合，一级阀动作通过汽温扰动污染二级 SP 事件响应。

## 关键发现 4：60s vs 180s 交叉验证

| 子集 | n | 方向率 | 天数 |
|---|---|---|---|
| 60sV(60s严格+一级阀≤1) | 52 | 75.0% | 34 |
| 180sV(180s中等+一级阀≤2) | 39 | 76.9% | 28 |
| **交集 (60sV∩180sV)** | **24** | **83.3%** | 18 |
| 仅60sV | 28 | 67.9% | 21 |
| 仅180sV | 15 | 66.7% | 14 |

两层共同确认的事件方向率 83.3%，显著高于任一层——稳态定义具有正交信息，
60s 和 180s 各自会放进对方能识破的假稳态。

## 关键发现 5：15 个大突变事件（|ΔSP|>3°C）全部为异常

01-26 单日 6 连发（+6.6~+12.6°C）、01-15 双发（+15~16°C）等 15 个事件，
SP 台阶跳变 10°C+ 但阀位/温度几乎无响应，特征为**模式切换/设定装载/DCS 异常**，
不属于 S 层也不属于 D 层。抽查 SP 原始更新点确认大阶跃本身一步到位（检测无问题），
是事件性质异常。处理：|ΔSP|>3°C 直接排除或单独归档。

## 结论与建议

1. 稳态层定义修正：**主层 60sV（60s 严格 + 一级阀≤1%）n=52** 或
   **180sV（180s 中等 + 一级阀≤2%）n=39**，交集 24 个作 robustness 核心
2. 事件检测本身无问题（大阶跃一步到位），无需改 SP 检测
3. E3 匹配仍需 caliper（审计 §10-2），本机 cache 已就位
   （`~/Desktop/AI/时序预测/AA数据中心/伊敏12.10/phase3_5_cache/cache_A.npz`），
   42 checkpoint 完整，可重跑 validation event evaluation
