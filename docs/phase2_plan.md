## 1. 主方案：可微分世界模型 MPC（DWM-MPC）

### 1.1 世界模型（已就绪）
- **Direct WM 40列单目标**（exp_023）：`[40列历史 96步 ‖ 未来动作 H步] → 一次前向 → 18步主汽温`
- 0.096→0.528（×5.5），二级阀敏感性 −0.382@120s（物理方向 ✓）
- **可微分性**：整个前向是连续可微的（TCN+Attn+MLP），对动作序列求梯度成立
- 这是与 DiffMPC 的 `fθ(s_t, a_t, ε)` 类似的可微转移，但我们一次输出 H 步（direct），非单步滚动

### 1.2 规划（inference-time 动作优化）
**主路线 A — 梯度优化动作序列**（DWM 式）：
```
初始化动作序列 a⁽⁰⁾（上一时刻最优解 warm-start）
循环 e = 1..E:
  1. 轨迹 = WM(历史 ‖ a⁽ᵉ⁾) → 主汽温预测 ŷ₁..ₕ
  2. 目标 J = Σ wₜ·(ŷₜ − T_set)² + λ₁·ΣΔa² + λ₂·Σ(a−a_last)²
  3. ∇J/∇a → 梯度上升更新 a⁽ᵉ⁾  (Adam, lr=η)
执行: a₁（只执行第一步）
```
- 依赖：WM 可微 ✓（exp_023 架构天然支持）
- 风险：目标函数多峰 → 局部最优。缓解：warm-start + 多起点采样（CEM 初始化）

**对照路线 B — 采样规划（CEM）**：与 A 同目标函数，但用 CEM 采样 200 条 + 精英加权 + σ_min=0.05。A/B 对比回答"可微梯度 vs 采样"在火电主汽温上的优劣。

### 1.3 终端价值
**第一版（对照实验 T1）**：启发式终端项
```
J_terminal = α · (ŷ_H − T_set)²    # 最后一步预测偏差 × 系数
α 从 {0, 0.5, 1.0} 扫
```
**第二版（后续）**：轻量 Q 网络（从"当前状态+动作 → 剩余偏差期望"回归），TD 训练。依据：TD-MPC/DiffMPC 都用 γ^H·Q。

### 1.4 参数
- **视野 H = 10**（100s）主跑；H=15（150s）对照——物理延迟 60-120s，H≥10 才覆盖阀效应；diffMPC 证明 H∈{5,10} 差距不大
- 步长 η ∈ {0.01, 0.05}，内层步数 E ∈ {10, 30}
- 温度目标：T_set = 各样本窗口主汽温均值（或 571°C 典型值，实验定）
- 约束：540 ≤ T ≤ 575（软惩罚），|Δa| ≤ 5%/step（硬 clip）
- 状态重置：每步用真实观测重构建历史窗口（receding horizon）

## 2. 评测（反事实仿真 vs PID 真实轨迹）

### 2.1 主评测（图3素材）
- 取 test 集 50 条轨迹，每条 120 步（20min）
- **PID 组**：真实阀位序列（数据里的）→ 真实主汽温轨迹 = 基准
- **WM-MPC 组**：每步 MPC 给出最优 a₁ → 喂给真实环境（用数据中对应时刻的真实状态推进）→ 累计主汽温轨迹
- 指标：温度 RMSE vs T_set、超温次数、总变差 TV、|Δa| 违规次数

- MPC 生成动作序列的响应 vs 事件研究真值（H=8-12 时标），确认 −0.382 方向在新动作分布下保持

## 3. 可微分性验证（DWM 特有的实验）

- **梯度检查**：有限差分 vs 解析梯度（∂J/∂a），验证 backprop 正确
- **规划收敛**：J 随内层迭代 E 的下降曲线
- **多起点**：5 个随机起点 → 最优 J 分布（评估局部最优严重度）
- **对动作幅度的响应**：MPC 动作 vs 数据中 PID 动作的分布对比（是否更平滑/更激进）

## 5. 诚实边界（Discussion 素材）

- 反事实仿真 ≠ 在线闭环：仿真中每步用真实状态推进，但动作是模型生成的——模型误差仍会经状态传导；真实执行还有执行器延迟/噪声
- 共因残留：训练数据是闭环 PID 数据，长程统计仍可能带 PID 行为模式；MPC 学到的最优策略可能偏保守
- 可微梯度 vs 采样：火电主汽温目标函数接近凸，梯度规划可能直接可行；若局部最优严重，以 CEM 为最终方案
- 单目标局限：只约束主汽温，不约束其他变量（减温器出口温度等）——多目标扩展为 future work
