# 方向决策记录 (2026-08-09)

## 决策

1. **交叉喷水结论以现场知识为准，不再验证**：
   左=A 侧、右=B 侧；A 阀/设定 → B(右)侧汽温，B 阀 → A(左)侧。5D V0-V4 已证明
   现有观测数据不足以统计确认，但物理布置由现场确认，直接作为信号配对输入，
   不再花费算力验证真假。

2. **核心目标转向：解决物理闭环响应识别**（对应 E3/E4 卡点）。
   即：在闭环 PID 数据上，可靠识别"阀位动作 → 温度响应"的方向/时标/幅度/剂量，
   使世界模型的动作通道获得可验证的经验基准。

## 已知约束（从 5C/5D 沉淀）

- 导前区（阀位→二过出口）事件窗 FOPDT 可识别：A→右 K≈-2.1°C/%、T≈16s、τ≈40s
- 惰性区（二过出口→末过）被共因污染；全时段 ARX 自回归主导（R²=1.0 假象）
- 严格门禁下 held-step 事件不足（A=7/B=6），双向 common support 不存在
- SP→主调→阀位→二过出口 60s 内相位一致（PID 链同步已证）
- SP 事件数远多于阀位事件（held-step 后 760/900），且 SP 是运行人员外生干预

## 解决方向（候选）

1. **间接闭环辨识**：SP→温度的闭环传递函数 T(s)/SP(s) 已知（可测），PID 结构已知
   （PI，参数可由 SP→阀位闭环数据估计）→ 反解开环 plant G(s) = 阀位→温度。
   利用 SP 外生性，绕开"阀位被温度驱动"的内生问题。
2. **工具变量/两阶段法**：以 SP 为 IV，两阶段回归分离前向通道。
3. **导前区+惰性区串联**：导前区已可识别，惰性区用差分/IV 后串联成完整
   阀位→末过通道。
