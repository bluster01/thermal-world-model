## 实验 1: ΔSP 世界模型全量训练与评估 (exp_096 全量)

### 目标
训练"动作=ΔSP"的世界模型 (M5-DSP)，验证 ΔSP 动作通道下的预测能力，
为沙盒 SP 规划场景提供与现场部署对称的模型 (现场只能通过 SP 通道介入)。

### 模型与数据
- 结构: M5-DSP (DirectWM 确定性, RevIN+PerVarTCN+VarAttn, 动作编码器 1维 ΔSP)
- 状态: 前 40 列 (含绝对 SP 水平, 不含 ΔSP 列) — 绝对 SP 作为共因上下文, ΔSP 为控制驱动
- 动作: 未来 18 步 ΔSP 序列 [BS, 18, 1]
- 训练: MSE loss, 100 epoch, LR 1e-3, WD 1e-5, BS 256, Adam
- 数据: 同 exp_025 协议 (train 495407 / val 106159 / test 106159, 10s 采样)

### 评测 (test 段)
| 指标 | 定义 |
|---|---|
| 随机窗口 MAE | 全 test 段随机 200 窗口, 18 步预测 MAE (对标 M5 0.239°C) |
| SP 事件 MAE | 557 个 SP 阶跃事件, onset 起点 180s 预测 MAE (对标 M5 0.301°C) |
| 方向正确率 | 预测 ΔT 方向 vs 实际 ΔT 方向一致率 (对标 M5 85%) |

### 判定标准
- PASS: SP 事件 180s MAE ≤ 0.35°C 且方向正确率 ≥ 80%
- 若 FAIL (MAE > 0.45): 报告瓶颈, 不硬撑 — ΔSP 通道信息不足则回到绝对 SP 状态建模

### 产物
- results/exp_096_dsp_wm/checkpoints/best_model.pth
- 训练曲线 + test 指标 (json)

## 实验 2: 沙盒 vs 现场预测精度对比 (核心实验, exp_095 升级)

### 目标 (论文主结果 1)
世界模型作为 SP 规划仿真沙盒: 输入**相同的 SP 规划动作序列**,
沙盒预测温度 vs 现场实际温度 — 验证"先观察后执行"中观察环节的可靠性。

### 事件集 (同 exp_093/095 筛选协议)
- SP 阶跃事件: |ΔSP| > 1°C, 事件间隔 ≥ 60 步, 工况稳定 (onset±20 负荷变化 ≤ 3MW), SP 阶跃后保持 (61 步内 |ΔSP| ≤ 0.3°C)
- 数量: 557 (全量) / 200 (冒烟)
- 对照基线: 平稳事件 (随机非阶跃窗口, 等量)

### 协议 (关键: 沙盒输入 = 现场实际执行序列)
- 起点: onset − 96 步 (窗口末 = 阶跃前)
- 沙盒输入: 实际 SP 轨迹 + 实际阀位轨迹 (现场执行结果, 与 exp_095 一致)
- 模型: M5 (已有) + M5-DSP (实验 1)
- 预测 18 步 (180s), 对比现场实际温度

### 分层分析
| 层 | 定义 | 论文意义 |
|---|---|---|
| 全事件 | 557 个 | 总精度 |
| 大动作 | \|ΔSP\| > 3°C | 干预最强场景 — 沙盒价值最高处 |
| 中动作 | 2 < \|ΔSP\| ≤ 3 | — |
| 小动作 | 1 < \|ΔSP\| ≤ 2 | 常规调整 |
| 平稳基线 | 非阶跃 | 精度下界参照 |

### 指标
180s RMSE / MAE / p90 / 方向正确率 / 误差分布直方图

### 判定标准 (沙盒成立)
- PASS: 全事件 180s RMSE ≤ 0.4°C 且方向正确率 ≥ 80% (对标 exp_095: 0.301°C / 85%)
- 分层不成立时诚实报告 (如大动作层方向 < 70% — 沙盒在大干预下不可靠, 论文写边界)

### 产物
- 完整指标表 (分层 × 模型) json + md
- 3 个代表 case 时序图 (预测 vs 实际温度 + SP + 阀位, nature-figure 规范):
  A. 大动作阶跃 (沙盒价值) | B. 中动作 | C. 平稳对照

## 实验 3: ΔSP 通道价值验证 (消融, 支撑架构决策)

### 目标
M5 (动作=阀位, 绝对SP在状态) vs M5-DSP (动作=ΔSP) 在 SP 事件场景的预测对比。
验证"ΔSP 作为动作通道"是否比"绝对 SP 仅作为状态"更利于干预场景预测
(共因标记 vs 控制驱动的架构论证, §25.6 理论基础)。

### 协议
- 同一事件集 (实验 2), 同一窗口起点, 相同输入 SP 序列
- 对比: 全事件 MAE / 大动作层 MAE / 方向正确率

### 判定
- M5-DSP 全事件 MAE 不劣于 M5 (Δ ≤ +0.05°C) → ΔSP 架构成立 (信息无损)
- M5-DSP 大动作层更优 (Δ ≥ −0.05°C) → 支持"ΔSP 控制驱动"论证
- 若 M5-DSP 大动作层劣于 M5 显著 (> +0.1°C): 报告差异, 架构决策回到绝对 SP

### 产物
- 对比表 + 差值分布图

## 风险与诚实性声明

- 沙盒预测输入 = 现场实际 SP/阀位轨迹 → 是"条件预测"而非"真闭环" —
  论文定位: 验证 WM 在规划动作条件下的预测可靠性 (观察环节), 执行环节由现场监督模式完成
- 若大动作层精度崩 (方向 < 70%): 论文边界写"沙盒适用于小幅 SP 规划 (现场实际也如此)" —
  与 objective mismatch 文献 (docs/papers/) 的讨论一致, 不掩盖
