# 实施路径规划 (baseline 对比)

> 依赖与并行性、里程碑、验证点。每个阶段结束有明确的"过/不过"标准。

## 依赖图

```
P1 线性MPC ──┐
P2 PETS式 ────┼──→ P6 主表汇总 → 论文表格/图
P3 IQL+TD3+BC┤
P4 消融/M7内SAC┘
P5 扩展(可选) ──────────→ 独立, 不阻塞
```

## P1 内部步骤 (线性MPC)

1. **数据**: 复用 M7 的 train/val/test 划分（exp_025 的 test_raw 等），ARX 只吃 train 段
2. **辨识**: ARX(温度自回归12阶 + 阀位12阶 + SP 6阶) 最小二乘；迟延隐含在阶次里(60-120s=6-12步)；备选 N4SID(若ARX残差大)
3. **验证**: 1-18步 direct MAE（同 exp_057 的 500 固定窗口协议）vs M7 → 记录
4. **嵌入**: LinearARX 类实现 wm 接口 forward(x_hist, a_future)→(mu[1,H], lv)；lv 返回 log(0.01) 常数（线性模型无不确定性，语义=确定性WM对照）
5. **闭环评测**: 复用 exp_027 simulate + grad planner（同框架只换模型，最公平）；150轨迹/3起点/扰动+无扰动/每步SP基准
6. **入主表**: RMSE/IAE/ITAE/TV/超温/Wilcoxon vs PID 和 DWM-MPC

## 关键决策（已定）

- **同框架换模型**：线性MPC/PETS 都用 exp_027 的 simulate+grad(或CEM) planner——对比纯在"模型"，排除规划器/执行协议差异
- **评测协议统一**：150轨迹/3起点/扰动+无扰动/每步SP基准/Wilcoxon（与 exp_064 一致）
- **reward 统一**：r = −|e| − λ_a·|Δa|（RL 方法）
- **训练成本列**：主表必须报告每个方法的训练耗时与推理耗时

## 风险

- ARX 大迟延拟合差 → 提高阶次/N4SID；仍差则如实入表（正是学习型MPC的卖点）
- IQL/TD3+BC 不收敛 → 检查 reward 尺度/状态归一化；改用 M7 仿真器内评估
- CEM 规划慢 → 2维动作下 CEM 成本低，H=18 可接受
