# 实验设计: 可微世界模型 + MPC 主汽温控制

> 版本: v0.1 | 日期: 2026-07-30 | 状态: 设计中

## 0. 架构概述

### 模型公式

```
输入:  x_t = [s_{t-W:t}, a_{t-W:t}]     # W步历史状态 + 动作
输出:  ŝ_{t+1} = f_θ(x_t)                # 下一步全状态预测

训练:  min Σ w_k · MSE(ŝ_{t+k}, s_{t+k}) # 多步展开loss (k=1..H)
推理:  ŝ_{t+1} → 喂回窗口 → ŝ_{t+2} → ... → ŝ_{t+H}  # 自回归展开
```

### 与现有 Exp-0 架构的关系

```
Exp-0 (预测模型):
  [96步状态] → RevIN → Patching → TCN → VarAttn → Decoder → [18步多变量预测]
  问题: 无动作输入, 无自回归展开训练

World Model:
  [96步状态 ‖ 96步动作] → RevIN(s) ‖ Emb(a) → Patching → TCN → VarAttn → Decoder → s_{t+1}
  关键改动: +动作条件化, +单步输出, +自回归展开训练
```

### 变量定义

| 类别 | 变量 | 维度 |
|------|------|------|
| 状态 s_t | 负荷、各级温度(6)、压力、煤量、阀位(2)、设定值等 | 14维 |
| 动作 a_t | 一级减温阀位变化量、二级减温阀位变化量 | 2维 |
| 未来动作 | a_{t+1:t+H} 由MPC求解器生成 | 2×H维 |

## 1. 数据准备

### 1.1 数据源
- 伊敏6号机 A侧主汽温 10s采样
- 14维特征 (同Exp-0): 见 `src/config.py`

### 1.2 数据切分
- 训练: 前70%时间段
- 验证: 中间15%
- 测试: 后15%（时间序列，不打乱）

### 1.3 世界模型数据构造
- 从原始轨迹构造 (x_t, s_{t+1}) 对
- x_t = [s_{t-W:t}, a_{t-W:t}]  (W=96)
- 多步展开训练需额外构造 H 步真值序列

### 1.4 动作定义
- 原始数据中: 一级阀位、二级阀位（绝对值,%）
- 动作 a_t = [Δvalve1, Δvalve2] = [v1_t - v1_{t-1}, v2_t - v2_{t-1}]
- 或直接用绝对值: a_t = [v1_t, v2_t]
- **待定**: 实验对比两种动作定义

## 2. Phase 1: 动力学模型验证

### 实验 1a: 一步预测精度
- 全变量 s_{t+1} 的逐变量 RMSE/MAE
- 重点关注主汽温 (target_idx=10)
- 训练/验证/测试三集指标

### 实验 1b: 自回归展开精度
| 参数 | 值 |
|------|-----|
| 展开步数 H | 1, 5, 10, 18, 30, 60 |
| 评估样本 | 测试集随机 2000 条轨迹 |
| 指标 | RMSE vs 展开步数曲线 |
| 成功标准 | H=18 时 RMSE < 2× H=1 RMSE |

### 实验 1c: 动作因果敏感性
- 固定窗口内状态不变
- 改变窗口后部阀位 Δv = [-10, -5, -3, -1, +1, +3, +5, +10]%
- 观察主汽温响应曲线
- 验证: 阀位↑ → 温度↓ (因果关系方向正确)
- 验证: 响应延迟 ≈ 30-90s (物理延迟正确)

### 实验 1d: 消融实验
| 变体 | 说明 |
|------|------|
| Full Model | 完整架构 |
| No-Action | 去掉动作输入（退化为纯预测） |
| No-RevIN | 去掉RevIN |
| No-VarAttn | 去掉变量间注意力 |
| Mamba Backbone | 用 Mamba 替代 TCN |
| GRU-only | 只用 GRU 做时序编码 |

### 实验 1e: Baseline 对比
| Baseline | 说明 |
|------|------|
| LSTM dynamics | 标准 LSTM 动力学模型 |
| Linear SSM | n4sid 系统辨识 |
| DeepThermal RNN | 复现 DeepThermal 的 RNN 架构 |
| 浙理工 iTransformer-SST | 间接对比（纯预测, 无动作） |
| 现有 Exp-0 模型 | 直接多步预测(无动作) vs 世界模型自回归 |

## 3. Phase 2: 离线 MPC 验证

### 3.1 MPC 求解器设计
- 方案A (先做): 随机采样 M 条动作序列 + Top-K → 评估 → 选最优
- 方案B (后续): 梯度优化 (cross-entropy method / MPPI)

### 3.2 MPC 目标函数
```
min Σ [ (T_main - T_setpoint)² + λ₁·Δv₁² + λ₂·Δv₂² ]
s.t.  540°C ≤ T_main ≤ 575°C     (温度上下限)
      |Δv| ≤ 5%/step              (阀位速率限制)
      0% ≤ v ≤ 100%               (阀位范围)
```

### 3.3 离线反事实仿真
- 从测试集取 50 条完整轨迹（覆盖 11 种工况）
- 每条轨迹: 从初始状态开始, 运行 MPC H=18 步
- 对比: MPC 规划 vs 实际 PID 操作

| 实验 | 指标 |
|------|------|
| 2a. 控制品质 | 温度 RMSE, 超调量(%), 稳态误差 |
| 2b. 约束满足 | 超温次数, 约束违反幅度 |
| 2c. 动作代价 | 总阀位变化量 TV |
| 2d. 分工况 | 按 Exp-0 11工况分类, 逐工况评估 |

### 3.4 Baseline 控制策略
| Baseline | 说明 |
|------|------|
| 实际 PID | 历史数据中的 PID 操作 |
| 线性 MPC | 用线性 SSM 做 MPC |
| 纯预测前馈 | Exp-0 预测模型前馈 + PID |

## 5. 论文核心贡献点

1. **历史窗口 + 动作条件化世界模型**: 解决火电大迟延系统的动力学学习
2. **自回归展开训练**: 匹配 MPC 推理时的使用方式, 减少累积误差
3. **真实工业数据验证**: 伊敏 1000MW 机组 10s 数据, 11 种工况
4. **与纯预测方法的本质区别**: 不只是预测, 能回答"如果这样控, 会怎样"
