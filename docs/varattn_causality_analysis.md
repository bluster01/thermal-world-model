# VariableAttention 与因果性：分析与实验方案

日期: 2026-08-04
动机: exp_025 消融得出「M4 (−VarAttn) 与 M0 几乎无差 → VarAttn 无用」。怀疑该结论用错了指标，VarAttn 在**因果通路**上可能有实质作用。

---

## 1. 架构事实核查（决定性）

`exp_025_unified_benchmark.py::DirectWM.forward` 的实际数据流：

```
x_hist → RevIN → Patch → PerVariableTCN → s_repr [B, 40, d]   (逐变量，无混合)
                                      ↓
                    if use_varattn:  s_repr = VarAttn(s_repr)   ← M4 在此处被移除
                                      ↓
a_future ──→ action_enc ──→ a_feat [B, 2d]                      ← 动作在此处进入
                                      ↓
              z = cat([s_repr.reshape(B, 40*d), a_feat])
                                      ↓
              decoder: Linear(42d → 4d) → GELU → ... → H*2
```

由此得到两个必须先澄清的事实：

**事实 1：动作从不经过 VarAttn。**
VarAttn 只作用于 40 个历史状态 token；`a_feat` 在 VarAttn 之后才拼接进 decoder。
→ **VarAttn 在结构上不可能承担「动作 → 目标」的路由**。原始假设按字面理解不成立。

**事实 2：M4 并非「无跨变量信息流」。**
decoder 第一层 `Linear(40*d + 2d → 4d)` 已经把 40 个变量全部展平做稠密混合。
→ M4 移除的只是**输入自适应（content-adaptive）的跨变量混合**，静态混合原封不动保留。
→ 「−VarAttn」这个标签严重高估了该消融的强度，这是 MAE 几乎不变的**结构性原因**。

补充：`self.varattn = VariableAttention(d, 4, ...)` 只有**单层**（`src/world_model.py` 里是 2 层）。参数差 849,268 − 799,284 = **49,984**，与单层 VarAttn 理论值 ≈49,792 吻合，确认只移除 1 层。

## 3. 现有数据重新解读

### 3.1 MAE 看不见任何东西

| | M0 (含 VarAttn) | M4 (−VarAttn) | 差异 |
|---|---|---|---|
| avg rollout MAE | 0.3104 | 0.3109 | **+0.17%** |

这正是 Phase 1 早已确立的教训在重演：exp_011 证明**动作响应为零的模型照样能拿到好 MAE**（`phase1_report.md` §1.2）。用 MAE 判定 VarAttn 有无用处，犯的是同一个错误。

### 3.2 换成因果敏感性，差异立刻出现

首步扰动 δ=+10（开阀→降温，物理上应为负），单位 °C：

**action_0（一级，长通路）**

| 模型 | t1 | t3 | t8 | t12 | t8→t12 |
|------|------|------|------|------|--------|
| M0 (VarAttn) | −0.027 | −0.068 | −0.122 | −0.081 | **−33%** 衰减 |
| M4 (−VarAttn) | −0.034 | −0.091 | −0.177 | −0.167 | **−6%** 基本维持 |
| M7 (VarAttn, β fixed) | −0.038 | −0.081 | −0.122 | −0.064 | **−48%** 衰减 |
| M9 (TimeXer, 动作 cross-attn) | −0.074 | −0.148 | −0.136 | −0.190 | **+40%** 增长 |

M4 相对 M0：t8 **+46%**，t12 **+105%**。

**action_1（二级，短通路）**

| 模型 | t1 | t3 | t8 | t12 | t8→t12 |
|------|------|------|------|------|--------|
| M0 | −0.065 | −0.191 | −0.436 | −0.468 | +7% |
| M4 | −0.054 | −0.174 | −0.404 | −0.463 | +15% |
| M7 | −0.084 | −0.209 | −0.434 | −0.411 | −5% |
| M9 | −0.102 | −0.209 | −0.222 | −0.329 | +48% |

M4 相对 M0：t1 −16%，t8 −7%，t12 **−1%**。

### 3.3 三个关键观察

**观察 A — 效应量差 270 倍。**
VarAttn 对 MAE 的影响是 0.17%，对 action_0 长时程因果增益的影响是 46–105%。**结论「VarAttn 无用」只在 MAE 这一个盲指标下成立。**

**观察 B — 影响强度随因果通路长度而变。**
长通路 action_0 受影响 46–105%，短通路 action_1 只受影响 1–16%。这个不对称与「跨变量混合负责多跳信息路由」的机制预期高度一致，不像随机噪声。

**观察 C — 方向可能与直觉相反。**
事件研究真值（Fig 1/2）显示阀门阶跃响应在 130s 内**单调增长**（t8→t12 真值比 ≈2.4）。
而含 VarAttn 的 M0/M7 在 action_0 上 t8 后**衰减 33–48%**，不含 VarAttn 的 M4 基本维持（−6%），动作走 cross-attn 的 M9 则**增长 40%**。
→ 在长通路通道上，**当前形式的 VarAttn 似乎在损害长时程物理保真度**，而不是帮助。

**观察 D — M9 才是支持原假设的证据。**
M9 用 cross-attention 把**动作**作为 token 注入，是四个模型里唯一两个通道都单调增长的（+40% / +48%），尽管 MAE 更差（0.347）。
→ 原直觉「注意力对因果有大用」方向是对的，但**起作用的是 action cross-attention，不是 state self-attention**。M4 消融的是后者，所以测错了对象。

## 4. 假设

> **H1（机制）**：VarAttn 的作用不是路由动作，而是让因果增益 **随工况自适应**。
> 其收益应体现为「增益的工况异质性」和「增益与物理调制量（负荷/流量）的相关性」，而不是 MAE。

> **H2（代价）**：单层 state self-attention 在长通路通道上引入了过度平滑，导致长时程响应提前衰减，物理保真度下降。

> **H3（正解）**：真正提升因果保真度的是让**动作参与注意力**（M9 已有初步证据），而非仅状态间自注意力。

---

## 5. 最大的威胁：n=1

**M0 和 M4 各只训练了 1 个 seed。** 46–105% 的差异完全可能来自随机种子。
在做任何结论之前，多 seed 复现是**唯一的准入门槛**。

好消息：`exp_025_unified_benchmark.py::main` 已支持 `TRAIN_SEED` 环境变量，结果落到 `results/exp_025_{MID}_s{SEED}`，无需改代码。

其他需要控制的混淆：
- M0 与 M4 的 `beta_mode` 都是默认 `'warmup'`，这一对是干净的（M7 是 `'fixed'`，不可与 M0 直接比因果差异）。
- `train_min`：M0 18.0 min vs M4 7.7 min，同为 best_epoch=7。6% 参数差解释不了 2.3×，怀疑测量时机器负载不同，任何效率结论都不可用此数据。

## 6. 实验方案

### E1 — 多 seed 因果敏感性（P0，准入门槛）

- **对象**：M0、M4，各 5 seeds（42/7/13/2024/31337）
- **命令**：`$env:TRAIN_SEED=7; python experiments/phase1_dynamics/exp_025_unified_benchmark.py M4`
- **主指标**：`sensitivity_degC.action_0` 与 `action_1` 全曲线（8 个 δ × 4 个 step）
- **统计**：按 seed 配对 Wilcoxon；报告效应量与 95% CI
- **判决**：
  - 若 action_0 的 t12 差异在 5 seeds 下仍显著（p<0.05 且 CI 不跨 0）→ 观察 A/B 成立，进入 E2–E4
  - 若不显著 → 原「VarAttn 无用」结论保留，但**必须改写为「在 MAE 与因果敏感性上均无显著差异」**，并补上 n=5 的说明
- **成本**：10 次训练 ≈ 2–3 h

### E2 — 因果保真度评分 vs 事件研究真值（P0）

现有 Fig 2 只比了 M0/M7/LSTM，且真值曲线是硬编码插值。本实验要把真值做实。

- **步骤 1**：从 `event_study_valve.py` / `event_study_valve_close.py` **分通道**重新导出真值响应曲线（一级、二级各一条），含 bootstrap CI。当前真值只覆盖聚合响应，通道归属未验证——这是必须先补的缺口。
- **步骤 2**：定义**因果保真度评分**（替代 MAE 作为因果指标）：
  1. `SC` 符号正确率：sign(ΔT) = −sign(δ) 的格点占比
  2. `MGI` 单调增长指数：ΔT(t12)/ΔT(t8)，真值 ≈2.4
  3. `TTP` 峰值时刻误差
  4. `SHAPE` 归一化响应曲线与真值的相关系数
  5. `LIN` 小 δ 下 ΔT/δ 的恒定性
- **对象**：M0 / M4 / M7 / M9 × 5 seeds
- **判决**：若 M4 或 M9 的评分显著优于 M0 → 观察 C/D 成立，`phase1_status.md` 的架构结论需要修订

### E3 — 注意力图可解释性（P1，出图）

- **改动**：`DirectWM.forward` 目前用 `s_repr, _ = self.varattn(s_repr)` 丢弃了权重；`VariableAttention.forward` 本身已返回 `(x, attn)`，加一个 `return_attention` 开关即可，`[B, 4, 40, 40]`
- **指标**：目标行 idx=29 的注意力质量分配
  - 一级链集合 {37, 34, 14, 25, 27, 26, 28}，二级链集合 {38, 35, 14, 26, 28}
  - 无关对照集合 {18, 19, 20, 21, 39}（辅汽 / 吹灰）
  - `CAM` = 链上注意力质量 / 总质量，与均匀基线 |chain|/40 对比
- **分层**：按 11 个工况分别统计，看注意力是否随工况迁移（直接检验 H1）
- **产出**：40×40 注意力热力图 + 物理邻接先验对照图（论文级插图）

### E4 — 增益工况依赖性（P0，H1 的决定性检验）

模型可微已由 exp_026 验证（grad cos = 0.9999），因此用 autograd 直接取雅可比，比有限差分更准更快。

- **计算**：`g_k = ∂T_{t+k} / ∂a_0`，逐样本，k ∈ {1,3,8,12}
- **分层**：按 11 个工况（复用 `exp_025_M7_conditions.json` 的工况划分）
- **指标**：
  1. `CV_cond` = 工况间增益的 std/mean —— **H1 预测 M0 ≫ M4**
  2. 增益与调制量的相关性：机组负荷(0)、主蒸汽流量(13)、减温水总流量(14) —— **H1 预测 M0 相关性显著，M4 接近 0**
- **判决**：
  - `CV_cond(M0) > CV_cond(M4)` 且相关性显著 → H1 成立，VarAttn 的价值是**增益自适应**，应据此重写结论，而非「无用」
  - 两者都低 → H1 证伪，VarAttn 在当前架构下确实冗余，M4 应作为更省参数的默认配置

### E5 — 架构改进（P1，取决于 E1–E4）

仅在 E1–E4 确认 VarAttn 有实质作用（无论正负）后执行：

| 变体 | 改动 | 检验目标 |
|------|------|----------|
| M4b | VarAttn ×2 层 | 深度是否为限制因素 |
| M4c | 物理邻接掩码注意力（只允许沿因果链注意） | 物理先验能否修复 H2 的过度平滑 |
| **M4d** | **动作作为第 41/42 个 token 参与 VarAttn** | **直接检验 H3**，是 M9 思想在 DirectWM 内的轻量化实现 |

M4d 最有价值：M9 已提供正面证据但换了整个架构（MAE 0.347 更差），M4d 能在控制其他变量的前提下隔离「动作参与注意力」这一个因素。
