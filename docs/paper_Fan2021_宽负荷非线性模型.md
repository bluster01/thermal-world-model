## 一、模型规模：4 状态 × 3 输入 × 3 输出（回到简洁）

### 状态向量
```
X = [rB, pm, hm, Ne]^T
```
前三个状态 `rB/pm/hm` 与 2017 相同；第四状态由 2017 的金属温度 `Tj` 改为机组负荷 `Ne`，并增加汽轮机功率惯性方程。

### 输入 / 输出
```
U = [uB, Dfw, ut]^T      Y = [pst, hm, Ne]^T
```
**不含喷水**——SST 不作为输出，回归到纯 CCS 建模。

## 二、状态方程（原文 Eq.16）

```
dx₁/dt = −(1/c₀)·x₁ + (e^{-τs}/c₀)·u₁                     # 制粉系统

dx₂/dt = [(hfw−d₁)/c₁]·u₂ + [(d₁−hst)/c₁]·Dst + Q₁/c₁    # pm

dx₃/dt = [(hfw−d₂)/c₂]·u₂ + [(d₂−hst)/c₂]·Dst + Q₁/c₂    # hm

dx₄/dt = −(1/c₃)·x₄ + [k₂(hst−hfw)·Dst + ΔQloss]/c₃      # Ne（新增）
```

### 输出方程
```
y₁ = x₂ − g(x₂)          # pst = pm − Δp(pm)
y₂ = x₃                  # hm
y₃ = x₄                  # Ne
Dst = ut·f(pst, hst)     # 蒸汽流量
hst = λ·hm               # 主蒸汽焓值∝分离器焓值
```

## 三、两大核心创新

### 3.1 能量不匹配函数 Q₁（Energy Mismatch Function）

在异常工况下（给水与燃料不匹配），简单的 k₁·rB 传热模型不够精确。论文引入：

```text
Q₁ = k₁·rB + [m / (Ne + g)]·(Dfw − a·rB)
```

其中 `a` 是稳态给水/煤流量比并随负荷变化，`Dfw − a·rB` 表示给水—煤流量不匹配；`m/(Ne+g)` 表示该偏差对吸热量的影响随负荷而变、在高负荷下减弱。该式对应原文 Eq. (4)/(6)，不是旧版所写的 `+ Ne + γ(...)`。

### 3.2 调门节流损失函数 ΔQloss（Throttle Loss Function）

作者声称这是首次在 CCS 模型中考虑调门节流损失；本项目未做独立领域首创检索：

```
ΔQloss = η·Δut·pst
```

物理含义：调门开度变化 → 蒸汽流过调门的压降变化 → 能量损失变化 → 影响汽轮机功率。这在负荷快速调节时尤为显著（调门频繁动作）。

## 七、对 thermal-world-model 的启发

### 7.1 能量不匹配函数 → 待验证的整炉 closure

Fan 2021 的 Q₁ 函数说明：只用稳态比例项 `k₁·rB` 不足以描述给水—煤流量暂态失配。这与项目中的 free/intervention 分支**可能形成建模类比**，但二者不是同一物理量，也没有证据证明“free path 抢信号”就是能量失配。

可检验的项目假设是：把 mismatch 作为 Fan20 的受约束 closure 候选
```
delta_Q = m/(Ne + g) * (Dfw - a*rB)
```
Fan21 的 `Q1` 是整炉吸热项，而 Fan20 已把热量分成 `k11/k12/k13·rB`。实现前必须预注册它替换哪个热项、如何在三段间分配并保证总能量不重复；不能直接把 `delta_Q` 加到每一段。是否改善宽负荷暂态必须通过组件消融验证，也不应映射成任意 `g_correction(ΔSP, ...)`。

### 7.2 节流损失的边界

`ΔQloss = η·Δut·pst` 在原模型中进入 `Ne` 动力学，描述汽轮机调门变化相关的功率能量项。它不能类推为减温阀的“机械反馈”。如果 SST 子系统把 `Dst` 外生化且不传播 `Ne`/汽轮机耦合，该项没有明确的 SST 路径，即使取得 `ut` 也不应默认加入。

### 7.3 时变参数的实用价值

Fan 2021 报告 Case A/B 间 `k₁` 和 `λ` 不同，并指出运行工况随时间变化会影响模型性能。原文没有把差异唯一归因于设备老化、结焦或积灰；这些只能作为项目待检验解释。对本项目可预注册“时间/负荷相关低维参数是否改善跨时段泛化”，在证据不足前不宣称退化机理，也不直接推出必须在线更新。

## 九、项目使用边界

- Fan 2021 是 4 状态 CCS 模型，输出不含 SST，也没有两级喷水；不能单独作为主汽温模型参赛。
- 只有保留完整 CCS/turbine coupling 且 `ut` 经核实时才讨论 throttle-loss；SST-only/`Dst` 外生模型关闭该项。
- `hfw`、`k₁`、`k₂`、`λ` 的负荷多项式来自原机组辨识，不应直接移植数值到伊敏机组。
- 在 Phase 4 中只把 load scheduling 和有明确能量分配规则的 mismatch 逐项嵌入 Fan20；throttle loss 属于可选 CCS 扩展，不是默认 SST 组件。
