## 二、状态方程（原文 Eq.16）

```
dx₁/dt = −(1/c₀)·x₁ + (e^{-τs}/c₀)·u₁                     # 制粉系统

dx₂/dt = [(hfw−d₁)/c₁]·u₂ + [(d₁−hst)/c₁]·Dst + Q₁/c₁    # pm

dx₃/dt = [(hfw−d₂)/c₂]·u₂ + [(d₂−hst)/c₂]·Dst + Q₁/c₂    # hm

dx₄/dt = −(1/c₃)·x₄ + [k₂(hst−hfw)·Dst + ΔQloss]/c₃      # Ne（新增）
```

### 输出方程
```
y₁ = x₂ − g(x₂)          # pst = pm − Δp(pm)
y₂ = x₃                  # hm
y₃ = x₄                  # Ne
Dst = ut·f(pst, hst)     # 蒸汽流量
hst = λ·hm               # 主蒸汽焓值∝分离器焓值
```

## 三、两大核心创新

### 3.1 能量不匹配函数 Q₁（Energy Mismatch Function）

在异常工况下（给水与燃料不匹配），简单的 k₁·rB 传热模型不够精确。论文引入：

```
Q₁ = k₁·rB + Ne + γ·(Dfw − α·rB)
```

其中 γ·(Dfw − α·rB) 捕捉**给水-燃料不匹配**对传热的额外影响。这是从开环响应数据中发现的——当给水突然增加而燃料不变时，蒸汽吸热量的变化不能用 k₁·rB 单独解释。

### 3.2 调门节流损失函数 ΔQloss（Throttle Loss Function）

**首次在 CCS 模型中考虑调门节流损失**：

```
ΔQloss = η·Δut·pst
```

物理含义：调门开度变化 → 蒸汽流过调门的压降变化 → 能量损失变化 → 影响汽轮机功率。这在负荷快速调节时尤为显著（调门频繁动作）。

## 七、对 thermal-world-model 的启发

### 7.1 能量不匹配函数 → 你的"free path vs intervention path"

Fan 2021 的 Q₁ 函数本质上是在说：**稳态传热模型（k₁·rB）在动态工况下不够**。这和你发现"f_free 抢走 35% 干预信号"是同一种问题——free path 在稳态训练数据上学的规律，在动态阶跃事件中偏差大。

Fan 的解法是加一个**显式的能量不匹配补偿项** γ·(Dfw − α·rB)。你的解法可以是：
```
g_correction(x) = f_free_correction(ΔSP, ΔDfw, ΔuB)
```
——在干预事件发生时，free branch 的输出需要被修正，而不是被冻住。

### 7.2 节流损失 → 阀门动作的快速扰动

ΔQloss = η·Δut·pst 说明：**每次调门动作都会产生瞬时的功率扰动**。在你伊敏的数据中，减温阀动作是否也对 p_st 产生类似的快速扰动（通过改变蒸汽流量分布）？如果是，你的动作输入 a 对温度的影响可能不全是"因果响应"，部分是通过压力-流量耦合的"机械反馈"。

### 7.3 时变参数的实用价值

Fan 2021 报告 k₁ 和 λ 随时间退化（设备老化、结焦积灰），考虑时变性后精度显著提升。这对长期部署的火电 AI 模型有直接意义——模型需要在线更新或至少周期性重标定。
