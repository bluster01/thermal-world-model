# FMTS-BLOCK1：180秒整块回填长程预测与真实历史导出

注册时间：2026-09-15；状态：执行前注册。作者确认：“每次将完整180秒预测块回填，再预测下一块”。不新增训练。

## 问题与适用结论

在相同记录上下文下，已有黑箱、保留GRU融合和独立no-rewet灰箱，把预测主汽温按180秒整块回填后，1,200秒内的预测轨迹和误差如何变化？结果用于展示真实历史→预测起点→递归预测与实际主汽温，不预注册胜负或选模规则。预测误差与阀门响应是两个证据问题：原H18双阀探针保留，不增加长程干预指标或DID口径。

这是**记录上下文条件下、仅主汽温回填的分块递归预测**，不是一次原生H120状态积分，也不是所有状态与外部变量均由模型生成的自主仿真。其他温度含现场系统的同期信息，故本结果不能作为完全开放环部署性能。

## 冻结来源

机器配置见 `experiments/fmts_block_rollout_20260915/protocol.json`。锁定 v0.2 parent、GNR1 的 identity、summary、原indices、canonical v2.2 record 和 IAPWS SHA256。沿用各checkpoint自身训练归一化统计与全部权重，禁止再估计。三个arm：`blackbox_itransformer`、`fusion_gru_norew`、`greybox_steady_none_norew`；每臂seeds 0/1/2，共9个固定权重推理单元。灰箱是原独立GNR1，不替换为同核消融；不包含旧token或VarAttn。

## 递归与信息协议

- dt=10秒；历史96点。第一次调用保持原H18完全相同的历史与记录future action/base boundary。
- 调用起点为相对步0、18、36、54、72、90、108；每次输出18点。前六块各将18个主汽温预测写回历史，窗口向前移动18点；第七块输出仅保留前12点用于达到120点（1,200秒）。不补齐假值、不以真值回填主汽温。
- 每次更新窗口时，其他4个温度、2个阀门、7个base boundary、9个extension从同时间记录更新；每块的未来2阀门+7base boundary使用原记录18点。extension仅作为当块历史输入，不单独提供未来extension张量。后续块使用的原点之后上下文并非在原点已知，必须与图注一起说明。
- 结构模型每块按其原forward重新从更新后的96点历史初始化；不跨块传递未观测状态。学习模块保持eval、无梯度，不更新权重。
- 末块仍需完整18点future input，因此总输入lookahead为126步（1,260秒），评分只有前120步；尾部6点不进入MAE。黑箱读取记录总减温水的原信息差异仍在，物理核沿用原实现。
