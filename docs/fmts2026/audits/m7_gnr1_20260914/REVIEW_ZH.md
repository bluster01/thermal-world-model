## 结论

1. **M7 改善旧 token，但未超过 GRU，不晋级。** 真实历史确认旧 token 的饱和问题；M7 恢复跨历史变化与顺序敏感性，MAE 降低 22.1%，三个种子均优于持续值。但相对 GRU 仍差 15.1%，配对胜出 0/3，不满足冻结门。不能把修复饱和写成预测最优，也不能说 attention 普遍不如 GRU。
2. **no-rewet 灰箱改变了所测响应符号，没有证明幅值恢复。** 两阀 H18 均值变为 −0.000280/−0.002809°C，仍很弱。精度未显示改善；不能写成“物理响应正确”或“现场校准完成”。
3. **保留 GRU 融合。** M7 是观察器组合修复补充，GNR1 是匹配 no-rewet 的灰箱参考。两项均为看到 v0.2 后提出、在各自新训练前注册的探索性补充。旧 12 次结果与旧稿保留；不自动继续训练。

## 观察器真实历史诊断

固定 256 条 W96 历史、四个有效慢状态修正。保持最后一步不变、反转前 95 步作诊断。分数为 tanh(raw)，不是温度误差；范围跨四状态。

GRU 三种子饱和占比 0–2.34%，历史标准差 0.4093–0.6508、反转变化 0.2053–0.4208。M7 局部 tanh 导数均值约 0.497–0.841，不再全面饱和。
M7 每 200 步记录的裁剪前观察器梯度均有限非零，三 seed 范围 0.372–27.985、0.229–75.027、0.385–41.479；不是所有训练步梯度分布，也不证明优化充分。
因此旧 token 低精度伴随具体的观察器退化，不能归结为抽象 attention 能力不足；M7 修复健康问题并改善精度，但健康与最优性能不是一回事。

## 双阀响应：符号、幅值、现场真值分开

64 个固定窗口、13 个 UTC 日，单阀归一化开度 +0.05，另一阀及边界 hold-last。各模型/种子的窗口、剂量及 support 配对一致，两阀各 0 个违规窗口，无删窗。下表是 H18=180 秒模型温差，不是累计误差或测得现场增益。

| 模型 | 一级阀 ΔT °C | 二级阀 ΔT °C |
|---|---:|---:|
| 黑箱 | +0.000097 | +0.000732 |
| 原灰箱 | +0.004479 | +0.033046 |
| 新 no-rewet 灰箱 | −0.000280 | −0.002809 |
| GRU | −0.147273 | −0.121569 |
| M7 | −0.131365 | −0.101275 |
| 旧 token | −0.126733 | −0.109999 |

- M7 每个 seed/阀均 64/64 个末端负向窗口，日块末端区间均在零下，整段保存曲线无正向单元，初始部分单元为零。
- GNR 一级阀末端负向计数 62/64、64/64、64/64，seed0 其余两个为零；二级阀三个 seed 均 64/64。逐 seed 两阀末端均值和日块区间均为负；不能改写成全部窗口严格负向。
- GNR 与 GRU 末端幅值相差约 525/43 倍。这是模型间差异，不能说灰箱只达到现场真实响应的某个百分比，也不能把 GRU 当标定真值。
- GNR float32 温度约 567°C 处的量化间隔约 0.000061°C，一级阀效应仅数个间隔。Linux 对绝对温度使用 rtol=1e-5、atol=1e-5，未保存差分最大重放偏差；绝对温度回放通过本身不能认证微小差分幅值精度。仅描述保存数组的弱负向趋势，不宣称微小增益精度或跨设备数值鲁棒性；本轮不因此改判据/补跑搜索。

消融隔离的是“关闭再润湿并以原预算重新辨识”的整体效果，不是固定旧参数的瞬时偏导。灰箱仍有拟合物理/观察参数，不是未经数据辨识的解析真值。
