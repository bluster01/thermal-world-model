# FMTS-VD1：阀门动作时间位置与输入路径诊断（2026-09-20）

作者本轮授权“可以，做一下诊断”。本注册先于新增真实推理，属于在已查看旧响应结果后提出的探索性诊断，不追溯宣称确认性预注册。目标是检验黑箱、GRU融合与独立no-rewet灰箱在哪些输入位置/条件下产生响应，允许任一模型推翻原来的叙事。不训练、不选模、不改论文，不把“负响应更大”设为胜负判据。

## 输入与窗口

严格使用FMTS v0.2/GNR1原九个检查点，三个arm各seed0/1/2；来源身份沿用已冻结BLOCK1协议，包含record、IAPWS、indices、parent/GNR identities和summaries哈希。原64响应窗口和256预测窗口的顺序、重复项全部保留，不新增事件筛选，不访问锁定test评分。真实推理只在Linux进行，本地只做工程夹具测试。

历史96点、预测18点、间隔10秒；以最后一个历史观测为0秒，未来输出标作10…180秒。未来动作索引s作用于离散推进区间[s×10,(s+1)×10]；“开始0/60/120秒”指输入生效区间起点，不是最终温度采样时刻。历史末点标作0秒，lag=0的三点历史片段为-20/-10/0秒，lag=90为-920/-910/-900秒。

只用父训练bank各窗口历史末阀位的1/3、2/3分位数定义两阀各自的低/中/高开度。阈值不参考响应或温度误差；相等阈值可以导致空箱，照实报告。分层不改变总体窗口；样本量按窗口和UTC日分别记录。

## 固定78个场景/检查点

1. **历史位置（24）**：两阀分别，历史三点片段的末点滞后900/600/300/180/60/0秒，±5个百分点。仅改历史动作，观测温度、其他历史、扩展变量不变。未来动作/边界从原始历史计算一次，不随改过的历史末值重建。重新运行原模型的历史编码/初态逻辑。这是输入敏感性，不是完整历史物理反事实。
2. **未来时间位置与剂量（48）**：两阀分别，开始0/60/120秒，±2/±5个百分点；30秒脉冲或保持至窗口末端的阶跃。原基准为双阀和全部七边界hold-last。分别记录动作前预测变化及动作后60秒温差；晚动作180秒终点较弱本身不算失败，后续未观测尾段不补零。脉冲时长一致，晚开始阶跃累计作用时间不同，不能直接拿固定终点幅值排序时间正确性。
3. **喷水输入路径（6）**：W-only为未来总流量±2 t/h，阀位不变（2）；joint为分别对一阀±5个百分点，同时W按同方向±2 t/h（4）。计算joint−valve-only−W-only的非加性。±2 t/h不是校准的阀位—喷水转换，joint不是物理一致性真值、真实中介效应或恢复后的公平黑箱。不开训练、不把W置零/删除、不用融合模型的喷水增益给黑箱制造答案。

所有开度扰动截断到[0,1]，W截断到[0,400] t/h，保存逐点实际剂量；不剔除小剂量/饱和样本。原历史范围±0.05检查仅是边际范围检查，不充当条件支持域或外生性证明。两阀不同时动作，本轮不加入更大的交叉网格。

## 输出与判读

- 保存每场景每窗口原始预测、基准、实际阀位/喷水剂量及support；完整历史、真实未来动作/边界、五温度标签与扩展历史作为私有输入快照回传，以便复核和后续画图。不向公共Git上传逐时真实输入或轨迹。
- 主汽温响应同时报告signed mean与mean absolute，不让异号抵消伪装成无响应；先UTC日内平均，再日等权，各种子单列并报告三种子均值/样本SD。开度三箱单独报告窗口数/日数和曲线；本轮没有显著性搜索或通过率阈值。
- 未来非零起点记录动作前max/mean absolute ΔT和同elapsed=60秒响应。这是模型时间一致性诊断，不是独立现场增益门。黑箱提前响应、弱响应、关阀表现不同都保留，不作为停止或重跑理由。
- 原256记录上下文预测重新推理并重放，报告level MAE、相对同一真实历史末温的逐步increment MAE及pooled increment correlation；按训练开度箱和该窗口实测阀位相对历史末值的最大偏移<2、2–5、≥5个百分点分层。后者仅描述动作活跃度，不是由模型表现选择的事件，也不是外生干预。pooled correlation不把时间点当独立统计重复。
- W-only和joint只定位输入使用，不能据此断言弱阀位响应完全由喷水通道引起；现有W是总量代理且可靠性有限。也不能将结构模型的非零/负响应直接认证为现场正确。
- 对真实温度链路的背景解释仍以已有Phase3.5局部点位证据为边界；本轮不重做DID、现场辨识、局部测点新训练或H60扩展。
