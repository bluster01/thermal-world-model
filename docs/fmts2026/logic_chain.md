## 总论点（一句话）

在任务关键热工过程上，**预报精度不传递为世界模型资格**：一个精度 0.7-0.9°C MAE 的纯数据
预测器对控制动作的响应弱 25-450 倍（近似失效），而物理结构世界模型以精度为代价
（~3.5°C）换回动作响应保真与可反事实性；我们同时给出度量这套资格的评测协议
（判别矩阵）与误差来源诊断（参数自由度/初态锚定/喷水动力学），并指出两段式架构
（learned 提案 + 可验证处置）为合流方向。

## 逻辑链（节 → 主张 → 证据 → 图）

### §1 Introduction
- **主张**：预测模型被提升为决策系统内模时，遇到的是资格问题而非精度问题；闭环下
  动作通道失效是纯预测模型的已知失败模式（外部佐证）。
- **证据**：Forecast Collapse (2608.14106)；ROM-mother Claim 2（可验证性中心论、
  "静默失效是失格行为"）；闭环辨识混杂（Forssell & Ljung 1999）。
- **图**：无（文字立论）。

### §2 测试床与两条线
- **主张**：超临界锅炉主汽温是任务关键热工过程的代表测试床；两条线同数据同协议训练。
- **证据**：82 天双侧现场数据（A/B 回路）、五观测温度+四动作（交叉阀位映射）；
  Direct WM（纯数据多步头，teacher-forced 口径如实标注）vs 物理 WM
  （三段集总焓 + IAPWS 物性 + UDE 参数 + action-blind closure）。
- **图**：Fig 2（过程示意+矩阵流程图）。

### §3 张力证据（三个测头）
- **主张 3a**：数据线精度高但动作响应近死；物理线动作响应保真。
- **证据 3a**：Direct WM F0/F1 精度 0.712/0.927 vs ±2% 阀位响应 −0.005~−0.015°C
  （物理同尺度约 −0.45~−0.87°C/2%）。
- **图**：Fig 3(a) 响应轨迹对比。
- **主张 3b**：物理线以精度为代价——且误差来源可定位。
- **证据 3b**：H1 输 persistence 12-32×；残差分箱箱间方差占比 0.49-0.71、均值残差随
  负荷单调（+2.1→+5.4°C）；分通道地板估计。
- **图**：Fig 3(b) persistence 对比、Fig 3(c) 分箱单调签名。
- **主张 3c**：两条线在"精度×动作响应"平面上构成张力曲线（当前三点：Direct WM、
  物理 WM 各结构点）。
- **图**：Fig 1 张力散点。

### §4 判别矩阵（评测套件）
- **主张**：张力需要可复现的评测协议——判别矩阵 = P5 型诚实基准的落地实例：
  同型可辨识性门禁（D-SYN）→ 逐层结构消融（O1/T1/B1/J1）→ 动作盲/泄漏审计（R1），
  bootstrap 判决 + 收敛诊断。
- **证据**：D-SYN 3/3 PASS；O1 hybrid 一致最优；T1 closure 稳健正贡献 / latent 训练
  预算敏感；J1/B1/R1 待 v0.2 判决。
- **图**：Fig 2 下半（流程图带判决标注）。

### §5 讨论与合流议程
- **主张**：物理线的精度代价不是黑箱——参数自由度（指数仿射+残差 MLP）、AR 一致性
  修复（全五点初态锚定、增量损失）、喷雾动力学升级（与动作通道同一杠杆）；两段式
  架构（learned WM 提案 + 可验证 ROM 处置）是任务关键部署的近期综合。
- **证据**：分箱天花板 0.49-0.71、地板三锚点、sh1_out σ=11.6 定位喷水瞬态。
- **图**：无新图（引用 Fig 3）。
