# FMTS-CORE1：同核固定权重对照（2026-09-14）

在查看 GNR1/M7R1 后提出，作者确认先做同核固定权重对照、再决定是否重辨识。
本注册先于 CORE1 真实记录推理，不追溯覆盖旧实验。无新训练/选模/现场校准。

每个 seed0/1/2 使用父 v0.2 MAE 选出的 `fusion_gru_norew` checkpoint：
C00=原物理参数+稳态锚点，无观察器修正/无闭合；C10=观察器开/闭合关；
C01=观察器关/闭合开；C11=两者开，必须复现原 GRU。
物理参数、IAPWS、物理读出、no-rewet、时间离散完全不改；C00 无神经网络参与预测均值。
C00 是从融合联合训练提取的物理核心，不是独立辨识基线。GNR1 独立辨识灰箱原样保留，必须重放。
固定物理参数下的 2×2 组件依赖可含交互；不解释为重新训练后的组件因果贡献。

数据 record/mapping/properties、normalization、indices 必须与父 v0.2 和 GNR1 一致。
W96/H18/10 s；原256预测窗、64响应窗。oracle预测/hold-last边界双阀+0.05；
保留所有窗口、实际剂量与support。整个反事实对只由历史计算一次初态，扰动不改初态。
三 seed 全部保存，无新checkpoint、优化器、超参搜索、H60扩张或test评分。

报告累计H1…H18 MAE、持续值、equal-day then equal-seed、sample SD；
响应曲线及1000次日块区间（rng11000），四配置各自原始数组、初态和两阀/基准物理状态轨迹。
报告同核C00对GNR1的差、观察器/闭合在各自另一开关条件下的差及2×2交互。
所有结果均描述性，不因符号/幅值/MAE从四格挑“赢家”，不自动替换论文主baseline。

工程门：C11和原GNR1检查点重放绝对温度 rtol=1e-5/atol=1e-5；
另外对两阀 step-minus-base 温差记录最大偏差，atol=1e-4°C、rtol=1e-4。
后者是预先固定的复现工程门，不是现场增益精度门，尤其不能单凭此门认证微小GNR幅值。
当前same-run零动作身份必须严格相等，数组全有限。失败保留并停止，不改阈值补过关。
不在此包混入float64/步长改动；需要数值精度研究时另注册，不把工程对齐当物理正确。

候选extension为2026-03-16至05-11，现有13通道数据包不等于FMTS的23通道合同。
