## 0. 设计原则 (从 5D 教训提炼)

1. **分段是硬性要求**: 导前区 (阀位→二过减温器出口) 与惰性区 (二过出口→末过出口)
   必须分开估计, 不得合并成单一"阀位→末过" 通道 (旧 85%/74% 的错误来源)。
2. **交叉配对是预注册事实**: A 阀喷水注入右(B)管道, B 阀注入左(A)管道 (用户现场确认
   + 5D exploratory 一致)。所有配对按此执行, 不事后切换。
3. **事件不足时不得升级结论**: V0 显示严格门禁下闭环数据 A=7/B=6 事件, held-step=2。
   未来正式证据必须来自新时间块或预注册现场试验, 且达到本文 §5 样本量。
4. **方向/时标/幅度分离**: 每个 estimand 输出 (方向率, 峰值时滞, 响应幅度, CI),
   不合并为单一数字。
5. **双向 common support 是硬门槛**: 只有开阀或只有关阀 → INCONCLUSIVE (5D 实证:
   12 open / 1 close)。

## 1. 物理模型与信号层级 (冻结)

```
层级: SP(温度设定) → 主调输出(PID) → 阀位反馈 → [喷水混合: 代数块] → 二过出口温度(导前区)
      → [金属蓄热: 惰性区] → 末过出口温度 → (反馈回 PID)
配对 (冻结):
  导前区: A阀位 → 右侧二过出口温降 drop_R = T_in_R − T_out2_R
          B阀位 → 左侧二过出口温降 drop_L = T_in_L − T_out2_L
  惰性区: 右二过出口 → 右末过;  左二过出口 → 左末过 (直连, 无交叉)
测量: drop (近端物理温降) 为导前区主输出, 末过温度为惰性区输出。
```

## 2. 主 Estimand (预注册): 稳态 held-step 因果响应

### 2.1 目标量 (导前区, 冻结)

对侧 s ∈ {L,R}、horizon h ∈ [30s, 300s] 的有符号温降响应:

```
R_s(h) = sign(Δv) · [drop_s(t+h) − median(drop_s, pre 60s)]
```

主终点: **30–300s 响应面积** `A_s = mean_h R_s(h)`。
配对主对比: A 阀: `A_R − A_L`; B 阀: `A_L − A_R` (交叉配对, 方向应 > 0)。

### 2.2 处理与对照

- **处理**: 单侧阀位 held-step, 剂量 `Δv = median(post 30–60s) − median(pre 60s)`,
  主阈值 `|Δv| ≥ 3%` (2%/5% 预声明敏感性)。
  held-step 定义: 剂量完成后 300s 内阀位保持在 `max(0.5%, 0.2·|Δv|)` 范围。
- **对照**: 处理前 600s 匹配的 quiet control (无任何单侧 ≥3% 剂量事件),
  匹配变量: 负荷均值/变化, 主汽压力, 两侧末过温度水平, 阀位水平。
  不用另一侧作负对照 (两侧共享炉膛扰动, 5D 已证伪其合法性)。

### 2.3 稳态门禁 (全部必须满足, 事件前 600s)

| 变量 | 限值 |
|---|---|
| 负荷 | > 250 MW; range ≤ 15 MW |
| 主汽压力 | range ≤ 0.4 MPa |
| 两侧末过温度 | range ≤ 3 °C |
| 动作阀位 | range ≤ 0.3% |
| 另一阀 | 同期变化 < max(1%, 0.5·|Δv|) |
| 数据网格 | 10s 连续; 缺口前后窗口排除 |

### 2.4 推断与统计

- 聚类: 按 UTC 日或连续 episode 聚类; 样本单位 = 日块均值, 非事件。
- CI: 日块 bootstrap (n=2000, seed 冻结), 双侧 95%。
- 判定 (冻结):
  - **PASS**: 双侧配对对比 `A_R−A_L` (A阀) / `A_L−A_R` (B阀) 95% CI 均 > 0;
    方向率 ≥ 80%; 开/关各满足 §5 样本量; balance SMD ≤ 0.20; pre-trend 无显著差异。
  - **INCONCLUSIVE**: 事件数或日块数不足 / CI 含 0 / 任一方向样本不足。
  - **FAIL**: CI 显著 < 0 (方向与预注册相反), 或 balance/pre-trend 无法修正。

## 3. 次 Estimand (预注册): 动态 trajectory 响应

### 3.1 目的

真实闭环中阀位几乎不保持恒定 (5D: held-step 仅 2 个)。次 estimand 回答:
"给定观测到的真实阀位轨迹 u(t), 温度轨迹中有多少是阀位可解释的"。

### 3.2 模型 (冻结)

- 导前区: ARX(na∈{1,2}, nb∈{1,2}, d∈{0,3,6} 步) 输入=有符号阀位增量序列,
  输出=drop 增量; 阶次/延迟仅在 development 块选择, validation 块单次评估。
- 惰性区: ARX(2, 双侧二过温度+负荷+压力, d 扫描), 同侧系数占优检验。
- 报告全部拟合参数 (含 fit failure, 边界命中), 禁止先筛符号再报中位数。

### 3.3 判定 (冻结)

- **PASS**: trajectory 模型在独立时间块 held-out NRMSE 优于 no-action 基线,
  且同侧系数占优, 最优延迟 > 0 (非 0s 同步假象)。
- **INCONCLUSIVE**: 无 held-out 优势或样本不足。
- **FAIL**: 系数符号与物理相反且显著。

## 4. Placebo 与敏感性 (冻结, 每个 estimand 必报)

1. 时间错移: 处理窗整体前移/后移 1h, 2h (共 4 个 placebo)。
2. 日内置换: 事件内 30–300s 顺序打乱 (破坏时序)。
3. 错侧配对: A 阀事件配 drop_L (应弱于真配对)。
4. no-action 基线: 同门禁无事件时段。
5. 分层: 负荷 (250-400 / 400-550 / >550 MW); 开/关; 月份。任何主要分层反号即降级。
6. 真配对必须同时优于全部 placebo 排名前 95% (单侧)。

## 5. 样本量预注册 (冻结, 引用 5D 实证)

| 指标 | 门槛 (每个 estimand, 每侧) |
|---|---|
| 事件数 | ≥ 30 (主) / ≥ 20 (次) |
| 开/关各自 | ≥ 10 且双向均存在 |
| 独立日块 | ≥ 8 |
| held-step 子集 (仅主) | ≥ 10 |
| 事件跨度 | ≥ 独立 14 天 |

5D 实证: 现有数据 A=7/B=6 (3%), held-step=2 → **现有数据不可能达到门槛**。
未来路径 (二选一, 均需预先注册):
- **新时间块** (未查看数据, 如 2026-06 后), 按本协议原样执行;
- **预注册现场试验**: 每侧 2–3 次/天 × 3–5 天, 剂量 ±2–5%, 600s hold, 960s 前稳定,
  双向交替; 这是唯一能解锁双向 common support 的路径。
