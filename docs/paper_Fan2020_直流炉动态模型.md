## 二、物理分段（比 2017 细得多）

```
给水 ─→ [省煤器+水冷壁+分离器+低温过热器] ─→ [一级喷水] ─→ [屏式过热器]
  Dfw        ↓ 状态: pm, hm                    Dsw1            ↓ 状态: h₃
            吸热: k11·rB                                     吸热: k12·rB
                                    ↓
                              [二级喷水] ─→ [高温过热器] ─→ 汽轮机
                                Dsw2          ↓ 状态: pst, hst     ↓ 状态: Ne
                                             吸热: k13·rB
```

### 三个传热系数（新增核心机制）
- **k11**：省煤器+水冷壁段吸热系数
- **k12**：屏式过热器段吸热系数
- **k13**：高温过热器段吸热系数

三者均表示为 rB 的二次函数（数据回归），且论文提出了**修正因子**（correction factors）来处理煤质变化和燃烧过程的不确定性。

## 三、核心创新 vs 2017

### 3.1 SST 的物理路径（原文最大卖点）

2020 版的关键方程是**蒸汽焓值的逐段传递**：

```
h₅ = λ·hm                          # 低温SH出口焓 ∝ 分离器焓值
h₄ = (D₅h₅ + Dsw1·hsw1) / D₄      # 一级喷水混合 → 屏式SH入口焓
h₂ = (D₃h₃ + Dsw2·hsw2) / D₂      # 二级喷水混合 → 高温SH入口焓
Tst = f(pst, hst)                   # 主汽温由压力+焓值反算
```

这揭示了 **SST 的两条调节路径**：
- **快速路径**：Dsw2↑ → h₂↓ → hst↓ → Tst↓（喷水秒级响应）
- **慢速路径**：Dfw↑ → hm↓ → h₅↓ → … → hst↓ → Tst↓（给水分钟级响应）

### 3.2 修正因子机制

2017 版的 k11 是固定参数，2020 版引入了**时变修正因子**来应对煤质波动和燃烧效率变化：

```
k11_corrected = k11(rB) × Correct_hm
k12_corrected = k12(rB) × Correct_T₃
k13_corrected = k13(rB) × Correct_Tst
```

修正因子在 5 个稳态工况下取值（0.77~1.14），通过 IGA 从动态数据优化得到。

### 3.3 系统惯性分析（开环阶跃响应）

| 扰动 | Tst 时间常数 | pst 时间常数 |
|---|---|---|
| 燃料 +14 kg/s | **1139s** | 358s |
| 给水 +40 kg/s | **949s** | — |
| 调门 +5% | **9s**（初段）→ 缓慢恢复 | 26s |

SST 是系统中最慢的变量（~1000s），而调门影响 SST 仅需 9s——这解释了为什么 SST 控制需要前馈（调门对 SST 的快速扰动必须被喷水补偿）。

## 五、对 thermal-world-model 的关键启示

### 5.1 SST 的多路径建模

伊敏 6 号机的减温系统同样是多级喷水。你的数据中有：
- 一级减温阀位 → 对应 Dsw1（保护屏式过热器）
- 二级减温阀位 → 对应 Dsw2（精确控制 Tst）

Fan 2020 的核心 insight 是：**SST 的动态由喷水（快）和给水（慢）共同决定**。你目前的模型把 ΔSP（设定值变化）当作单一动作输入——这丢失了快/慢双路径的时标差异。

### 5.2 修正因子 = 可学习的物理偏差项

Fan 2020 的修正因子本质上是一个**低维补偿项**（5 个工况 × 3 个系数），用 IGA 优化。这恰好可以被你的物理分支替代：
```
g_correction(x, a) = MLP_correction(load_feature)  → 修正 k11/k12/k13
g_physics(x, a) = Fan_structure(k11_corrected, ...) → 守恒律 ODE
```

### 5.3 多输出正则化

Fan 2020 **同时预测 5 个输出**。这比单独预测 Tst 强——因为 pst, hm, Tst 之间有物性函数约束（Tst = f(pst, hst)）。如果你把模型扩展为多输出，这些物性关系就是天然的正则化项。
