Fan 课题组围绕直流炉动态建模发了三篇核心论文：

| 年份 | 期刊 | 引用 | 核心贡献 |

## 二、研究动机

**背景**：可再生能源大量并网 → 火电机组需要快速、大幅度变负荷。直流炉内没有汽包缓冲，给水/燃料/蒸汽参数耦合极强。SST 是安全经济运行的关键参数——超温损坏管材，低温降低效率。

**现有模型的缺陷**（论文直接指出的 gap）：
> "the models of OTBT units in existing literature have not reflected this essential interrelationship"

现有 CCS 模型只关心功率和压力，把 SST 当成独立回路单独建模，**没有反映 SST 同时受给水流量和喷水流量双重影响的物理事实**。

**控制含义**：
- CCS 调节给水时，会无意识地扰动 SST
- SST 控制系统响应时，又可能干扰 CCS 的功率/压力调节
- 两个控制回路的耦合被模型假设掩盖 → 控制性能劣化

## 三、模型结构

### 3.1 物理分段

直流炉沿工质流向分为若干换热段：

```
给水 → [省煤器 ECO] → [水冷壁 WW] → [过热器 SH1/SH2/SH3] → 汽轮机
         ↑ 单相液态      ↑ 相变区         ↑ 单相汽态
```

每个换热段建立**集总参数模型**（lumped parameter），基于三大守恒：

- **质量守恒**：`d(ρV)/dt = ΣD_in - ΣD_out`
- **能量守恒**：`d(ρVh)/dt = ΣD_in·h_in - ΣD_out·h_out + Q`
- **动量守恒**：压差 ∼ 流量关系

其中 Q 是烟气侧传热量，与燃料量 u_B 相关。

### 3.2 关键状态变量

| 变量 | 物理含义 | 所属子系统 | 动态特性 |
|---|---|---|---|
| p_m | 汽水分离器出口压力（中间点压力） | 水冷壁 | 中等惯性 |
| h_m | 分离器出口焓值 | 水冷壁 | 中等惯性 |
| p_st | 主蒸汽压力（汽轮机前） | 过热器 | 较快 |
| T_st | 主蒸汽温度 | 过热器 | **大惯性** |
| N_E | 发电功率 | 汽轮机 | 较快 |

### 3.3 控制输入

| 输入 | 符号 | 作用路径 | 时间常数 |
|---|---|---|---|
| 燃料量 | u_B | → 烟气传热量 Q → p_m, T_st, N_E | 分钟级 |
| 给水流量 | D_fw | → 工质流量和焓值 → p_m, h_m, p_st, **T_st** | 分钟级 |
| 汽轮机调门开度 | u_T | → 蒸汽流量 → p_st, N_E | 秒级 |
| **喷水流量** | **D_sp** | → 过热器入口焓值 → **T_st** | **秒级** |

### 3.4 SST 双重调节机制（论文最核心的 insight）

```
T_st = f( p_st, h_st )
h_st = h( D_fw, D_sp, Q_SH, p_m, h_m )
```

**两个并行路径**：

1. **给水路径**（慢）: D_fw↑ → 蒸汽流量↑ → 单位质量蒸汽吸热↓ → T_st↓
2. **喷水路径**（快）: D_sp↑ → 直接降温 → T_st↓

**关键差异**：两种路径的时间常数差约 2 个数量级（喷水秒级 vs 给水分钟级）。这对控制策略有本质影响——快速扰动用喷水，稳态偏调用给水。

## 四、方法论

论文采用的是**灰箱建模**思路：

1. **模型结构**（白箱）：从质量/能量/动量守恒推导微分方程框架，包含物性参数（密度、焓对 p/h 的偏导数 ∂ρ/∂p, ∂ρ/∂h 等）
2. **静态参数**（黑箱）：利用运行数据，通过非线性回归和优化算法辨识传热系数、摩擦系数等经验参数
3. **动态验证**：开环仿真对比实际运行数据

论文报告"满意精度，反映本质动态特性"——未在摘要中给定量精度指标。

## 五、对 thermal-world-model 的启发

### 5.1 物理分支的升级路线

当前 A1phys 的物理先验只有一阶惯性级联（K, τ），和 Fan 的建模层次对比：

```
当前:        g(x, a) ≈ Σ K_i / (τ_i·s + 1) × a    （纯黑箱参数化）
Fan 2020:    d(ρV)/dt = ...                           （守恒律约束结构）
```

**中间路线**（可行且合理）：
1. 把 Fan 的守恒方程写成简化的状态空间形式作为物理分支的结构先验
2. 不要求精确求解 PDE——用 ODE + 数据驱动辨识参数
3. 物理分支输出完整的 T_st 动态响应曲线，而非标量增益

### 5.2 SST 不能独立建模

这是 Fan 2020 最核心的教训——**SST 必须和 CCS 耦合建模**。

你的模型输入包含 40 列变量（给水、燃料、喷水都有），但没有显式建模 T_st 与 p_st（压力）和 h_m（焓值）的耦合关系。Fan 2020 提示：如果你只预测 T_st 而不考虑 p_st 对 T_st 的物性影响，你会丢失一个关键物理约束。

### 5.3 伊敏数据对应

| Fan 2020 变量 | 伊敏 40 列中可能对应的列 | 状态 |
|---|---|---|
| p_m（分离器压力） | 需确认 | 待查 |
| h_m（分离器焓值） | 需从 p, T 反推 | 待查 |
| T_st（主汽温） | idx=29 ✓ | 目标变量 |
| D_sp（喷水流量） | 减温阀位/流量 | 有 |
| D_fw（给水流量） | 给水流量列 | 有 |
| u_T（调门开度） | 汽轮机调门 | 待查 |
| u_B（燃料量） | 给煤量 | 有 |

### 5.4 可操作的建议

1. **先读 2017 版论文**（Applied Energy, 3 入 3 出）——方程更简洁，先提取状态空间结构
2. **从 40 列数据中确认 p_m, h_m, D_fw, D_sp**——确认数据覆盖了 Fan 模型需要的全部物理量
3. **物理分支升级方向**：把守恒律写成可微分形式，作为 g(x,a) 的结构先验
4. **多输出建模**：考虑同时预测 p_st 和 T_st，利用两者之间的物性耦合作为隐式正则化

## 六、局限（批判性阅读）

1. **集总参数假设**：每个换热段只有一个温度/压力，忽略空间分布——对过热器这种大惯性对象精度可能不够
2. **灰箱参数辨识依赖数据质量**：如果训练数据工况覆盖不全，外推不可靠
3. **目标是仿真平台而非控制算法**：论文没有给出基于该模型的控制器设计结果
4. **锅炉结构差异**：需确认伊敏锅炉的过热器级数、喷水位置是否与论文假设一致
5. **超临界 vs 亚临界**：伊敏是超临界，Fan 2017/2020 模型适用于超临界，但相变区处理在近临界区可能不准确
